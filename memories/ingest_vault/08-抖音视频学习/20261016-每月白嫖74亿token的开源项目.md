## 💡 关键要点

**项目：FreeLLMAPI** —— 把一堆免费额度的 LLM 平台拧成**一个 OpenAI 兼容端点**，自托管在本机。

- **仓库**：`tashfeenahmed/freellmapi`（MIT，★36,083 / fork 4,859，2026-04-21 建，2026-10-16 仍在推提交）
- **怎么用**：自己把各家平台的免费 key 加进面板，请求打到本机一把统一的 `freellmapi-…` key；路由器按请求挑当下最合适的模型，某家被限流就自动切下一家，并跟踪每个 key 的用量防止超额。
- **官方口径（README 原文，已逐项核对）**：34 家平台 · 474 个模型系列 · **635 个免费端点**（584 对话 / 41 向量 / 7 转写 / 3 视频）· 约 **每月 74 亿 token** 免费额度。
- **密钥不出本机**：AES-256-GCM 加密后落 SQLite，请求前在内存里解密；客户端永远拿不到上游平台的 key。
- **响应头签名**：每个响应都带 `X-Routed-Via: <平台>/<模型>`，一眼看出这次是哪个模型出的力。
- **路由策略**：`auto` / `auto:fast` / `auto:smart`（或指定 profile / 具体模型 id）；最能打的模型白天被抢光就自动降档顶上，额度每日重置后满血复活。
- **目录自动更新**：每天两次从 freellmapi.co 拉签名模型目录（Ed25519 验签），新增模型/额度变化自动落到本地 DB；免费版目录落后约 30 天（约 303 个模型）。
- **部署**：Docker Compose 一条命令（默认 3001 端口，SQLite 持久化，Node 20+ 可跑，含 macOS/Windows/手机 App）。个人实验用途。
