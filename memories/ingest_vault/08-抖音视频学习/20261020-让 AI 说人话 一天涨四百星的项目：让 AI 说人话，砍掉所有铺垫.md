## 一句话

不是新模型，是一套**提示词技能 + token 压缩层**：逼 agent 砍掉客套和铺垫，只留结论和事实，同时把日志/网页/记忆文件先压小再喂给模型 —— 号称省 33% 输入 token、54% 成本。

## 项目是什么（不是"让 AI 变笨"）

仓库 `JuliusBrussee/caveman`，六块能力，装一次全开、各自可关：

| 模块 | 作用 | 官方实测 |
|---|---|---|
| Say less | 回复变短，代码保持逐字不变 | 63 → 20 token，答案等价 |
| Read less | 日志/JSON/CSV/测试输出先压缩再给模型看 | 输入 token −33.2% |
| Auto | 按问题自动选模型与推理档位 | 比 Opus 5.5 xhigh 便宜 54%，分数相同 |

| Waste fixes | 找 token 花在哪，逐条给 diff 让你点同意 | 未量化 |
| Browse | 网页压缩后返回 | 15,704 → 121 token（200 行表格） |

## 视频漏说（README 里的边界）

- **主要面向写代码的 agent**。官方支持 30+ 个（含 Hermes、Claude Code、Codex、Gemini CLI、OpenCode），非编码场景收益小。
- **只压表达，不压事实**。它反复强调「砍掉的否定词比省下的 token 贵得多」—— 压缩过度会改变语义，这是它自己划的红线。
- **Caveman Cloud 是商业闭源**，不在 Apache 授权范围内。
- **Hermes 在官方支持名单里，但标注 "not verified"**：委派出去的子任务可能仍话多，需要在任务里点名 caveman。

## 怎么用

```
caveman mode              # 进入说人话模式，本会话持续
stop caveman / 正常模式     # 退出
/caveman ultra            # 极简
/caveman wenyan           # 文言文
/caveman-compress MEMORY.md   # 压记忆文件，自动留备份
```

装/卸：`node installer/install.js --only hermes` / `--uninstall`。

## 对我们的实际价值

1. **省 token = 省钱**，尤其是 MEMORY.md 这种每轮都注入的文件（`caveman-compress` 实测 4138 vs 6198 token，−22.8%~−49%）。
2. **群里刷屏变少**：13 个 bot 都话痨的话，管理群没法看。
3. **不改模型智力**：只改表达层，代码/命令/报错逐字保留。
