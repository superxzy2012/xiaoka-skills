## 🎯 核心价值

**一句话**：把一整家华尔街对冲基金塞进 AI 里——十几个 AI 角色分工协作，从分析到交易全流程自动化，原属对冲基金核心资产，现已开源。

## 🏢 组织架构（十几个AI角色）

### 分析师团队（4人）

| 角色 | 职责 |
|------|------|
| **基本面分析师** | 评估公司财务和业绩指标，识别内在价值和风险信号 |
| **情绪分析师** | 汇总新闻、StockTwits、Reddit 讨论，形成情绪读数 |
| **新闻分析师** | 监控全球新闻和宏观经济指标，解读事件影响 |
| **技术分析师** | 用 MACD、RSI 等技术指标识别交易模式和价格走势 |

### 研究团队（多空辩论）

| 角色 | 立场 | 职责 |
|------|------|------|
| **看涨研究员** | Bullish | 收集买入证据，论证做多逻辑 |
| **看跌研究员** | Bearish | 收集卖出证据，质疑做多假设 |

> 两方当场「吵架」、互相拆台，确保决策不片面。

### 执行团队

| 角色 | 职责 |
|------|------|
| **交易员** | 汇总多空观点，拟定交易方向和策略 |
| **风控团队** | 激进/中性/保守三派辩论，管理风险敞口 |
| **投资组合经理** | 最终拍板，批准或否决交易提案 |

---

## 🔄 决策流程

```
分析师团队（4人）→ 各出报告
       ↓
研究团队（多空辩论）→ 互相质疑、平衡观点
       ↓
交易员 → 汇总定方向、出策略提案
       ↓
风控团队 → 激进/中性/保守三派评审
       ↓
投资组合经理 → 最终审批
       ↓
模拟交易所 → 执行订单
```

---

## 🛠 技术栈

- **框架**：LangGraph（状态图 + checkpoint 断点续跑）
- **语言**：Python 3.12+
- **模型**：几乎所有主流 LLM（OpenAI 兼容格式直接接）
- **数据源**：Alpha Vantage、FRED、Polymarket 等
- **部署**：本地 / Docker
- **特性**：
  - 结构化输出 Agent
  - 持久化决策日志
  - 回测支持
  - 代理配置
  - 多语言
