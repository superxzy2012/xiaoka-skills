> 抖音「空格之外」《每天一个神级网站》第 34 期

## 🎯 一句话定位

**Scrapling** = 一个**自适应**的 Python Web 抓取框架。最大杀手锏：**网站改版了，元素位置全变了，爬虫依然能抓对**（`adaptive=True`）—— 传统 Scrapy/BeautifulSoup 一改版全废，Scrapling 用 AI 记忆元素特征自动重新定位。

## 💡 杀手锏：adaptive=True（视频没说但 README 重点）

```python
from scrapling.fetchers import StealthyFetcher

# 第一次抓：网站结构 X
p = StealthyFetcher.fetch('https://example.com', headless=True)
products = p.css('.product', auto_save=True)

# 网站改版后：传 adaptive=True 自动重新定位
products = p.css('.product', adaptive=True)  # 即使 selector 全变了也能找到
```

**核心原理**：第一次抓取时自动保存元素的多维特征（class、id、父子结构、文本、位置），改版后用特征匹配而非简单 CSS selector。

## ⚠️ 安装注意

- 需要 `playwright`（自动装）+ Chromium 浏览器（~150MB）
- Python 3.9+ / MIT
- `pip install scrapling` —— **不是 `scrapling` 不在 BOSS sandbox 黑名单**，直接 pip 装应该 OK
