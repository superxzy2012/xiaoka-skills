# Hermes Agent 零 KEY 启动：v0.20.5 发布

> [!abstract] 摘要
> Hermes Agent v0.20.5（2026-08-21 发布）实现「零 KEY 启动」：官方内置 **5 家厂商免费模型组成轮转池**，API Key 全部不用填，网页搜索开箱即用；老版本要过的三关（API Key / 模型选择 / 故障处理）全砍。三周 6 版、累计 6800+ 提交，节奏凶猛。这正是 BOSS 当前最想落地的「0 token 方法」——**装完就能用**。

## 要点

- **核心定位**：Hermes Agent v0.20.5 标语「零 KEY 启动」，告别 API Key + 信用卡 + 注册充值的老三样。**一行密钥不填，5 个免费大模型自动切换**。
- **GitHub 23.4 万 Star**，v0.20.5 发布日 2026-08-21。
- **「以前装 Hermes 要过三关」**（THE OLD WAY）：
  - ① API KEY 关卡：海外信用卡、注册实名充值、粘密钥——**卡掉八成人**；
  - ② 模型选择关卡：20 多个厂商，选错要么报错要么烧钱；
  - ③ 故障处理关卡：服务商挂了要手切，长任务半夜停掉前功尽弃。
- **「三关全砍：免费模型环形轮转」**（KEYLESS WEB TIER）：
  - **Ring Failover 环形故障转移**：哪家挂了自动切下一家，无需人工干预；
  - **网页搜索开箱即用**：不用再配 Brave / Tavily / Firecrawl 密钥；
  - 模型选择器内置 **OpenCode Free 免费模型组**（画面里能看到 Pony Alpha、K2 Free、GLM 4.6、Hermes 4.7 Flash / Lightning Free、Model Spark 1.2、CodexSpark V4 Flash、DeepSeek V4 Flash、Sarvamone L4、Mistral Nvidia 等多个免费档）。
- **v0.20.5 单版本数据**：**746 次提交合并、323 个 PR、1250 个文件改动、11.15 万行新增代码**。
- **三周 6 版节奏**：
  - 08.03 v0.20.0「信使版本」：流式语音对话、本地唤醒词、A2A 互通；
  - 08.13–18 连发 4 个 patch，几乎每周滚动；
  - 08.21 v0.20.5「零 KEY 启动」上线；
  - **系列累计 6800+ 提交、2100+ PR、1250 个文件改动**；顺手更新了群聊室多智能人房间、PDF 拖拽上传、命令面板。
- **GET STARTED 四步上手**：
  1. **已安装**：命令行跑一句 `hermes update`；
  2. **新用户**：官网下载桌面安装包（Windows / macOS / Linux 三大系统）；
  3. 聊天窗口输入 **`/model free`** 切到官方免费模型池；
  4. 日常对话、写代码、查资料完全够用；**真要跑重度推理再接付费模型也不迟**。
- **「零 KEY」面前，其他都成了配菜**——这是对 BOSS 「0 token 方法」最直接的落地版本：把官方已封好的免费模型池当成"现成 API"，不用再自建代理/网页端转 API。

开源 AI 智能体圈最近有个大动作——Hermes Agent 更新到了 **0.20.5 版**。**以前 API Key 都不用填，装完就能用，还内置了五个免费大模型自动切换**。今天咱们就来聊聊 Hermes Agent 是怎么把上手门槛砍到 0 的。

以前想用 Hermes 得过三关。第一关是 API Key——用海外模型得有海外信用卡，用国产模型也得注册实名充值，再把那串密钥粘进配置文件，**光这一步就卡掉了八成人**。第二关是模型选择——它支持的厂商有 20 多个，新手对着配置文件一脸懵，选错了要么报错要么烧钱。第三关是故障处理——服务商一挂就得自己手动改配置重启，长任务半夜停了，第二天起来前功尽弃。

这次的 **Hermes v0.20.5 版把这三关全砍了**。官方内置了五家厂商的免费模型接口，做成一个**环形轮转池**，哪家挂了自动切下一家。**网页搜索也是开箱即用**，不用再去三个平台注册账号配密钥。看屏幕上这个模型列表——这一排免费模型，装完就能直接用。

这次更新的数字也很硬：**746 次提交、323 个 PR、改了 1250 个文件、新增 11 万 1500 行代码**。再看它的发版节奏，就知道这项目有多猛——**8 月 3 号发信使版本**，加了流式语音对话和本地唤醒词；之后几乎每周都在更新；**8 月 21 号发到 0.20.5**，三周 6 个版本。整个系列累计超过 **6800 次提交、2100 多个 PR**。顺手还更新了群聊室多智能人房间、PDF 拖拽上传、命令面板这些功能，但在「零 KEY」面前都成了配菜。

那怎么用呢？**已经装过的命令行跑一句 `hermes update` 就行**；新用户去官网下载安装包，三大系统都有，装完下一步就能用。进聊天窗口输入 `/model free`，**一条命令切到官方免费模型池**——不用配密钥、不用注册、不用充值，日常对话、写代码、查资料完全够用。真要跑重度推理再接付费模型也不迟。
