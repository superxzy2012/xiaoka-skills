# 腾讯 TencentDB Agent Memory：让电脑里所有 Agent 共用一份记忆

> 🎬 抖音 · 流萤加德 · 46 秒 · 2026-10-19 入库 · 已回源核查

## 💡 关键要点

1. **四类记忆资产**：Chat Memory（对话）、Skill（技能）、LLM-Wiki（文档知识）、Code-Graph（代码图谱）——不是傻存聊天记录，而是分类沉淀成可治理、可共享的资产。
2. **本地优先（local-first）**：数据存本地，不出机器，这点对隐私敏感场景关键。
3. **接入方式很轻**：Memory Proxy 同时兼容 Anthropic 和 OpenAI 两种协议，把 Claude Code 的 API 地址改指向本机 Proxy 即可，**Agent 用法完全不用改**。
4. **三服务架构**：`memory-core` + `memory-hub` + `proxy`，`./start-all.sh` 一键起，面板 `http://localhost:8125`。要求 Node >= 22.16。
5. **npm 包**：`@tencentdb-agent-memory/memory-tencentdb`。
6. **🔴 跟我们直接相关**：README 致谢里明确写，它的 **Skill 资产管理用了 Hermes Agent 的部分 Skill 相关代码**并在此基础上做优化——也就是说 Hermes 生态和这个项目是双向的。

## 🧭 和我们自建 Hive 的关系（重要判断）

我们 10-18 刚在 NAS 上搭的 Hive 是**文档级共享**：Obsidian vault（7933 篇 md）+ MCP 读写，靠 Agent 自己决定写什么。
它做的是**记忆级共享**：自动捕获会话、提炼成资产、向量检索召回，Agent 不用手动记。

两者**互补不冲突**：
- Hive = 团队知识库（人可读、可审计、Git 版本化）
- TDAI Memory = Agent 工作记忆（自动沉淀、语义召回）

真要融合，可行路径是让 TDAI 的 Memory Hub 把资产也落成 Markdown 进 Hive，或者 Hive 的 MCP 作为它的一个存储后端。**建议先观望**：772 个 open issue、v2.0.0 还是 Beta 期，别急着替换现有 Hive。

## 📝 转录原文

腾讯最近又放出一个开源狠活，它能让你电脑里面的各种 agent 工具共享同一份记忆库，让你每个 agent 的工作都能完美交接。今天要说的项目是它能统一管理 WorkBuddy、Codex、Hermes 等十种主流 AI 工具的会话历史，所有工具共享同一份个人记忆。你跟 A 工具说过的项目需求、代码规范、个人偏好，工具直接就能调用，不用再反复交代。而且是本地优先存储，数据安全有保障。Mac 桌面端和 CLI 都能用的记忆框架，不是傻存聊天记录，而是自动提炼关键信息、关联上下文，记得住还不占空间。实测跨工具调用记忆的准确率超高，处理长期任务不用再反复喂上下文，代币成本直接省。
