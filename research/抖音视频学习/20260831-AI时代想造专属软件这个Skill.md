# AI 时代想造专属软件？这个 Skill 从零手把手教你

> [!abstract] 摘要
> GitHub 爆款仓库 `codecrafters-io/build-your-own-x`（50万 stars）收录了「从零开始造软件」的系统化分步教程，覆盖 3D 渲染器、操作系统、Bittorrent 客户端、数据库、JSON 解析器、游戏、机器人等。**核心思想**：你不需要先精通 C++/Python/Java，你只需有想法和概念——挑一个最想造的东西，让 AI Agent 帮你啃细节。

### 3. AI 时代使用法（口播原文 + OCR 帧 01 实证）
- **口播原文**（whisper 转写）：
  > "什么是 C 语言 / 什么是 Python —— 不懂没关系，直接扔给除了豆包以外的 AI agent，他们都能懂。你只需要有你的想法、你的概念，先挑一个你最想做的东西，跟着它直接开造。你也有机会打造一个世界上最高级的项目。"
- **方法论**：把仓库的某个项目（例：build-your-own-redis）作为**skill/教程底座**，让 Cursor / Codex / Claude Code 这种带工具能力的 AI 沿分步指南带路，**不需要先精通底层语言**。
