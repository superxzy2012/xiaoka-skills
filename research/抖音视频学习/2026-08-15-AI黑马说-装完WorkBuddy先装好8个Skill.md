# 装完 WorkBuddy，先装好 8 个 Skill

> [!abstract] 摘要
> 装完 WorkBuddy 一定要把这 8 个 Skill 安装好——把数据、网页、浏览器、视频、资讯、文案、安全和个人偏好一次配齐。**不是收藏几百个 Skill，而是少做重复劳动**：把每天重复的步骤交给 WorkBuddy 自动完成。

## 8 个 Skill 速览

| # | Skill | 类别 | 一句话 |
|---|-------|------|--------|
| 01 | **SmartCharts** | DATA | Excel/CSV → 交互式图表，输出可继续处理 |
| 02 | **Frontend Dev** | BUILD | 一句话生成可修改可部署的页面（结构/视觉/动效/文案/素材） |
| 03 | **Web Access** | BROWSER | 浏览器自动化：搜索/整理/重复网页任务 |
| 04 | **yt-dlp** | CAPTURE | 多平台视频/音频/字幕一句话下载 + 摘要/观点/结构拆解 |
| 05 | **AI Hot** | NEWS | AI 资讯自动整理（模型发布/产品更新/行业动态） |
| 06 | **HumanizerZH** | COPY | 把工整 AI 文案改成更自然的中文表达 |
| 07 | **Scanner** | SECURITY | 安装前扫描文件访问/权限/外部请求/风险点 |
| 08 | **Self-Improvement** | MEMORY | 把纠错/习惯/工作方式沉淀成规则，越用越懂你 |

## 要点

- **DATA - SmartCharts**：把 Excel、CSV 直接交给 WorkBuddy，自动识别数据结构并生成交互式图表（字段/类型/趋势/建议 + 上传表格/识别字段/选择图表/生成看板/周报/竞品分析）。
- **BUILD - Frontend Dev**：让 WorkBuddy 接管重复步骤——从结构、视觉、动效、文案到素材，一次生成可继续修改和部署的页面（活动页 / 个人作品级 / 数据看板都可用）。
- **BROWSER - Web Access**：在授权范围内读取和操作真实网页，把搜索、整理和重复浏览器任务串起来（打开网页 / 读取内容 / 搜索话题 / 整理信息）。
- **CAPTURE - yt-dlp**：一句话抓取视频、音频和字幕，支持多个平台（视频链接 → 音频 / 字幕 / 摘要 / 观点提炼）。
- **NEWS - AI Hot**：按模型发布、产品更新、行业动态自动整理资讯（中文简报 / 定期整理 / 内容选题），适合做 AI 内容、产品研究或行业跟踪的人。
- **COPY - HumanizerZH**：把过于工整的 AI 文案优化成更自然的公众号、邮件和短视频脚本表达（Before 太公整像标准答案 → After 更自然像人说话）。
- **SECURITY - Scanner**：分析文件访问、权限调用、外部请求和风险点，先做一轮安全筛查——至少能帮你做第一轮风险筛查。
- **MEMORY - Self-Improvement**：把纠错记录、稳定偏好、命名习惯、工作方式、规则沉淀为可复用的规则，让 WorkBuddy 越用越懂你——你还可以逐渐把自己的工具偏好沉淀进去。
- **金句**："不是收藏几百个 Skill，而是少做重复劳动。真正有价值的是把每天都会重复的步骤，交给 WorkBuddy 自动完成。"
