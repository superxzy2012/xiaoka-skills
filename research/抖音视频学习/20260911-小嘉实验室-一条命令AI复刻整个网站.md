# 一条命令 AI 复刻整个网站（小嘉实验室）

> 来源：抖音 @小嘉实验室｜入库 2026-09-11｜置信度 A（口播清晰，项目名口播为音译）

## 🎯 核心观点

一个 GitHub 约 **3.4 万星**的开源项目：给一个网址，AI 自动扫描网站，把**颜色、字体、动效、布局**全部精准提取，然后**多个 AI Agent 并行开工各写各的模块**，最后自动合并、逐项比对，产出与原站几乎一模一样的完整项目，代码干净规范可直接跑生产。全程一条命令，不需要懂设计、不需要懂前端。

## 📋 主要内容

| 环节 | 内容 |
|---|---|
| 输入 | 一个网址 + 一条命令 |
| 提取 | 自动扫描：颜色/字体/动效/布局精准提取 |
| 重建 | 多 AI 代理并行开工，各写各的模块 |
| 合并 | 自动合并 + 逐项比对，还原度接近原站 |
| 产出 | 干净规范的完整项目代码，可直接生产运行 |
| 星标 | GitHub 约 3.4 万星 |

## 💡 关键洞察

1. "扫描→拆解→并行重建→比对合并"是多 Agent 工程化的典型落地范式，与我们 13BIT 的多 Agent 协作框架同构。
2. 潜在用途：竞品独立站（Shopify 等）的页面结构/设计模式分析参考——注意仅作设计参考，**严禁直接抄袭他人站点**用于商业用途（合规红线）。
3. 项目名口播音译不清晰，已核验：最匹配项目为 `CloveSVG/One-Click-Clone`（AI Skill，一条命令复刻网站→Next.js+TS+Tailwind，扫描页面→下载资源→提取样式→多 Agent 并行编码→组装比对，还原度 70-80%），与口播"3.4万星/自动扫描/多代理并行/逐项比对"特征吻合
4. **SkillSpector 扫描**：99/100 CRITICAL → **DO_NOT_INSTALL** ❌。人工复核：HIGH 多为静态误报（woff2 字体实为 GitHub HTML 页、提取样式的 JS 被判"Context Leakage"），项目本体是 600 行方法论 SKILL.md，无恶意代码
5. **裁定**：不装为常驻技能（保守）。理由：我已有 agent-browser + impeccable 等可组合能力覆盖同类需求；若 BOSS 明确要复刻站点场景，可指定仓库路径按需调用 `~/WorkBuddy/tools/One-Click-Clone/.claude/skills/site-clone/SKILL.md`
