# GitHub这周都在白嫖AI：74亿免费token太香了

> [!abstract] 摘要
> 本周GitHub热门AI趋势：两大方向——**把付费AI变免费**（聚合免费接口）和**把单打独斗的AI变团队**（多Agent协作）。视频精选5个项目详解，片尾附18个完整项目榜单。

## 核心要点

### 本周两大趋势
1. **白嫖AI**：把要花钱的AI变成免费的（聚合免费模型接口）
2. **AI组团打工**：把单个AI变成团队协作（多Agent工作空间）

## 5个重点项目详解

### 1️⃣ Awesome GPT Image2 — 工业级提示词库

![[douyin_hwPA4BbH2ak_frame004.jpg]]

- **定位**：GPT 出图提示词库
- **核心思路**：不教你从零写提示词，而是拆解社区 530+ 个成功案例，整理成**结构化提示词模板**
- **特点**：
  - 像代码一样可复用、可修改
  - 提炼了 20+ 套工业级模板，照着用就能出图
  - 配可视化网站，搜索/筛选/复制都很方便
- **适用人群**：做 AI 出图、追求效果稳定的人
- **热度**：周涨 1000+ Star

---

### 2️⃣ Apache Mac — Apache 基金会的 AI Agent 工作空间

![[douyin_hwPA4BbH2ak_frame010.jpg]]

- **定位**：本地优先的 AI Agent 工作空间，Apache 基金会孵化
- **核心卖点**：**可审计、可回放**
  - AI 做的每一步都会记下来（模型回复、调用工具、权限使用、最终结果）
  - 全部追加写入日志，出了问题能回放排查
- **三种形态**：Web 面板、命令行版、评测专用入口
- **适用场景**：想把 AI Agent 用在正经工作里，又怕它乱来的团队
- **价值**：可审计可回放的思路非常正确，是 Agent 落地生产环境的关键

---

### 3️⃣ FreeLM API — 34家免费模型聚合，月74亿Token

![[douyin_hwPA4BbH2ak_frame016.jpg]]

- **定位**：免费大模型接口聚合器
- **核心能力**：
  - 聚合 **34 家**免费大模型接口到一个地址
  - 兼容 OpenAI API 格式，直接按 OpenAI 格式调用
  - **635 个**免费模型端点随便用
  - 官方宣称月 **74 亿 Token** 免费额度
- **智能路由**：哪家接口挂了自动切到下一家，无需手动修改
- **安全**：密钥加密存在本地
- **定位**：个人做实验、做原型用
- **热度**：21000+ Star

---

### 4️⃣ FreeCloud Code — 免费跑编程智能体，月13亿Token

![[douyin_hwPA4BbH2ak_frame022.jpg]]

- **定位**：免费运行付费级编程智能体的平台
- **比 FreeLM API 更狠的地方**：不只是聚合接口，而是让你**免费跑本来要花钱的编程智能体**
- **背后**：接入 50 家合规模型提供方，月 **13 亿+** 免费 Token
- **全端覆盖**：Web、桌面、IDE、手机都能用
- **额外功能**：支持语音输入写代码
- **热度**：Star 增长最猛，总计 5 万+ Star，本周涨 4600+

---

### 5️⃣ Manda DeFran — AI 办公室，多 Agent 协作

![[douyin_hwPA4BbH2ak_frame028.jpg]]

- **定位**：AI 办公室（名字来自美剧《办公室》梗）
- **核心玩法**：
  - 把多个中端编程 Agent 包装成**员工**
  - 安排一个你的"克隆体"当**经理**，统一分派任务、调解矛盾
  - 2D 办公室平面图，直观看到每个 AI 员工在干嘛
- **记忆系统**：用 Markdown 做长期记忆，还能与你互动，越用越懂你
- **热度**：5000+ Star

## 个人思考

- **免费 Token 聚合的意义**：对个人开发者和小团队来说，74亿 + 13亿免费Token基本能覆盖绝大多数实验和原型需求，大幅降低 AI 创业门槛
- **Agent 工作空间的趋势**：从"能用"到"可控"——Apache Mac 的可审计可回放思路，是 Agent 走向生产环境的必经之路
- **多 Agent 协作是下一步**：从单个编程 Agent 到 AI 办公室，Agent 团队化是明确方向，值得持续关注
- **注意风险**：免费接口稳定性无保障，生产环境还是要用付费接口；免费额度是否可持续也要打个问号
