## 三个仓库（按口播顺序）

### ① EvoAgentX（Whisper 转写为 "Reven"，原标题为 "Raven"）
**"自进化的多智能体生态系统"**——解决多 Agent 协作时的状态丢失问题

- **仓库**：[EvoAgentX/EvoAgentX](https://github.com/EvoAgentX/EvoAgentX)（原组织 `ANative-Lab/EvoAgentX`）
- **Stars**：3,250+ ⭐
- **定位**：开源框架，自动化生成 + 评估 + 进化 LLM-based Agents / Agentic workflows
- **核心能力**：
  - **Workflow Autoconstruction**：从一句 prompt 自动组装多智能体工作流
  - **Self-Evolution Engine**：用 SOTA 算法（TextGrad / AFlow / MIPRO）持续优化 prompt、工具配置、工作流拓扑
  - **五层架构**：basic components → agent → workflow → evolving → evaluation
- **基准表现**（EMNLP 2025 demo paper）：HotPotQA F1 +7.44%、MBPP pass@1 +10%、MATH +10%、GAIA 整体 +20%
- **适合**：需要构建**复杂多智能体工作流**的开发者

### ② LeanCTX（Whisper 转写为 "Lean CTX"）
**用 Rust 写的 AI 上下文智能层**——大模型上下文窗口再大，也不如精准投喂

- **仓库**：[yvgude/lean-ctx](https://github.com/yvgude/lean-ctx)
- **Stars**：3,705+ ⭐
- **定位**：本地 Rust 二进制，**Context Engineering Layer for AI Agents**
- **核心能力**：
  - **Context Compression**：50-80% token reduction
  - **10 种 Read Modes**：`full` / `map` / `signatures` / `diff` / `lines:N-M` / `density:X`...
  - **缓存读取**：~13 tokens vs 原始 ~2000 tokens
  - **Session Memory**：跨会话持续记忆，避免 cold start
  - **CPAO 指标**：Cost per Accepted Outcome（按"有效产出"算成本）
  - **Context Proof**（`ctx_proof`/`ctx_verify`）：4 层验证 + CI drift gate
- **接入方式**：
  ```shell
  brew tap yvgude/lean-ctx && brew install lean-ctx
  lean-ctx wrap cursor   # 一行命令接入 Cursor/Claude Code/Codex/Windsurf
  lean-ctx gain          # 看节省效果
  ```
- **支持 30+ Agent**：Cursor / Claude Code / Copilot / Windsurf / Codex / Gemini...
- **适合**：Coding Agent 上下文爆炸、成本飞涨的团队

## 关键洞察 / 行动建议

1. **趋势信号**：AI 编程的下一波红利不在"换个模型"或"加个 prompt"，而在**底层基础设施**——状态/记忆/上下文/协作。
2. **门槛排序**：EvoAgentX < LeanCTX < Claude Code 源码——按你想做的深度选。
3. **快速试水**：`brew install lean-ctx && lean-ctx wrap claude` 一行命令就能立刻见效（50-80% token 节省）。
4. **战略对照**：BOSS 当前的小豆体系（Hermes + skill_manage + memory）走的是 EvoAgentX 同款"自进化多智能体"路径；LeanCTX 的"上下文工程"理念可借鉴进我们的 skill 体系。
5. **学习优先级**：Claude Code 源码解析是当下最值得读的 AI Agent 教科书（甚至比 LangGraph 文档实战）。
