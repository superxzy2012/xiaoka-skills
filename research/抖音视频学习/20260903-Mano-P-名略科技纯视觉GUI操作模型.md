## 核心信息

- **项目名**：Mano-P（Mano 意为"手"，P = Private）
- **出品方**：名略科技（Mininglamp）
- **GitHub**：[Mininglamp-AI/Mano-P](https://github.com/Mininglamp-AI/Mano-P)
- **Stars**：~2.6k（上线四周）
- **许可**：Apache 2.0
- **定位**：专为边缘设备设计的 GUI-VLA（视觉-语言-动作）Agent
- **一句话**：纯视觉、像人一样看屏幕操作电脑，数据不上云，M4 Mac mini 就能本地跑

## 核心亮点

### 1. 纯视觉驱动
- 不靠 MCP 协议、不靠 HTML 解析、不靠 DOM
- 跟人一样：看屏幕 → 理解界面 → 动手操作
- 能操作老旧系统、闭源软件、任何 GUI 应用

### 2. 本地运行，数据不上云
- 最低配置：**Apple M4 芯片 + 32GB 内存** 的 Mac mini / MacBook
- 也支持 Mano-P 算力棒（USB 4.0 连接）
- 所有截图和操作都在本地处理，完全不上传云端

## 安装与使用

### CLI 安装（brew，已验证）
```bash
brew tap Mininglamp-AI/tap
brew install mano-cua
```

### 安装本地模型
```bash
mano-cua check          # 检查本地模式依赖
mano-cua install-sdk    # 安装本地推理 SDK (mlx-vlm + cider)
mano-cua install-model  # 下载模型
```

### 使用
```bash
# 云端模式（默认，需要 API Key）
mano-cua run "打开 Safari 搜索 Python"

# 本地模式（M4+ 32G 以上 Mac）
mano-cua run "打开 Safari 搜索 Python" --local
```

### 支持的操作类型
点击、输入、热键、滚动、拖拽、鼠标移动、截图、等待、应用启动、URL 跳转

### 跨平台
- macOS（稳定）
- Windows / Linux（Beta）

## 工作原理

### 云端模式
1. 捕获当前屏幕截图
2. 发送截图和任务描述到云端视觉模型（mano.mininglamp.com）
3. 云端模型分析并返回下一步操作指令
4. 本地客户端执行操作
5. 循环执行直到任务完成

### 本地模式
1. 捕获当前屏幕截图
2. 在本地设备运行视觉模型推理
3. 输出操作指令，本地执行
4. 循环直到完成 — 全程数据不出设备

## 对 13BIT / Hermes 的价值

### 直接价值
1. **补充 MCP 覆盖不到的场景**：老旧系统、闭源软件、纯 GUI 应用
2. **隐私敏感场景**：财务系统、内部后台、客户数据，数据不上云
3. **跨平台自动化**：macOS/Windows/Linux 统一视觉方案

### 与现有工具的关系
| 工具 | 定位 | Mano-P 补充 |
|------|------|------------|
| Hermes browser_exec | 网页自动化（DOM 级） | 纯视觉兜底，反爬强的网站 |
| OpenClaw agent | 飞书 / 办公自动化 | 扩展到桌面级操作 |
| Computer Use (Anthropic) | 云端 GUI 自动化 | 本地方案，数据不出门 |

### 风险与局限
- ⚠️ 本地 4B 模型能力有限，复杂任务（C级）成功率只有 33%
- ⚠️ 云端模式数据还是要上传，只是提供本地选项
- ⚠️ 项目很新（上线四周），稳定性待验证
