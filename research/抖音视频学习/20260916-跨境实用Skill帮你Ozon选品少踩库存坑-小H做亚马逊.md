# 跨境实用Skill：帮你 Ozon 选品少踩库存坑

> 作者：小H做亚马逊 ·「一天认识一个强大的 Skill」第 9 期 · 33 秒口播
> 演示工具：**Linkfox Seerfar Ozon 产品报表搜索**（丢一个竞品 SKU，拉全套商品报表字段）

## 🎯 核心观点

Ozon 选品最大的坑不是找不到爆品，而是**前台看着好卖、一备货才发现对手早已低价重仓压仓**——你轻库存进去就是给人垫背。
解法：跟品前先丢竞品 SKU 进 Seerfar 产品报表，把售价、评分、销量趋势、销售额、库存、类目排名、发货模式、上架周期全拉出来，**用数据判断它是「新店起量 / 老店压货 / 轻铺货试品 / FBO 重仓硬砸」，再决定跟不跟**。选品不靠运气，先查清楚再动手。

## 📋 一个 SKU 能拉出的字段

| 维度 | 说明 |
|---|---|
| 卢布售价 | 当前价格带，判断是否适合规模化成交 |
| 评分 / 评论数 / QA | 口碑与历史销量沉淀 |
| 销量趋势 / 月销量 / 销售额 | 需求强度与增长方向 |
| 购物车转化率 / 下单转化率 | 成交效率质量 |
| 库存余量 / 类目排名 | 压货程度（**本次接口未返回，明确标注、不硬补**）|
| 发货模式 | FBO / FBS / RFBS 等，判断轻重资产 |
| 上架周期（月数/天数/时间戳）| 区分新品测款 vs 成熟长销款 |
| 品牌 / 卖家 / 变体数 / 退货取消率 | 铺量规模与风险 |

## 🔎 视频实跑案例（SKU 1419043699）

Ozon 前台一件 **CHELEBI TEXTILE 足球T恤**（Футболка，类目 Clothing > T-Shirt）：

| 字段 | 实际值 |
|---|---|
| SKU | 1419043699 |
| 卢布售价 | **₽458** |
| 评分 / 评论数 | **4.9 / 131,592** |
| 月销量 / 趋势 | **5,173 件 / +51%** |
| 月销售额 | **₽2,625,103** |
| 购物车转化率 | 10.34% |
| 下单转化率 | 54.8% |
| 发货模式 | **FBO** |
| 上架周期 | **29 个月 / 889 天** |
| 变体数 | 83 |
| 退货取消率 | 28.3% |
| 品牌 / 卖家 | CHELEBI TEXTILE / CHELEBI TEXTILE |
| 库存余量 / 类目排名 | ⚠️ 报表未返回该字段（不硬补值）|

**AI 给出的结论：高置信度 → FBO 重仓压货**，更像「成熟爆款 + 平台仓备货」，而不是「自发货轻铺货」。

## 💡 关键洞察：FBO重仓 vs 轻铺货 判断配方

跟品前用这 3 个结构性信号判型（可直接复用到本地技能调用后）：

1. **发货模式 = FBO** —— 判断「重仓压货」最直接的结构性信号；自发货（FBS/RFBS）才偏轻铺货。
2. **上架周期长（29个月/889天）** —— 不是短平快测款，是成熟长销款，硬刚成本高。
3. **评论 13万+ / 评分 4.9 / 月销 5,173（+51%）/ 83 个变体** —— 历史沉淀极强、按变体批量铺量；新人轻库存跟进几乎没有窗口。

> 反向即「可跟」信号：**自发货 + 上架时间短（creationDate 1/3 月）+ 评论少但增速快**，更像新店起量的蓝海测款。
>
> 数据纪律（视频明确演示）：**接口没返回的字段（库存余量/类目排名）必须标注缺失，绝不硬性补值编造**。退货取消率 28.3% 偏高，跟品时也要单列风险。
