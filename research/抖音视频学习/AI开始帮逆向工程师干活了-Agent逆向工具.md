# AI 开始帮逆向工程师干活了

## 核心内容

介绍一款把**整套逆向工程流程 Agent 化**的工具：配好环境后，用自然语言描述需求，AI 自动完成逆向分析。

## 核心要点

| # | 要点 | 说明 |
|---|------|------|
| 1 | **逆向流程 Agent 化** | 传统逆向 APK 需 JADX、IDA 等工具整套流程，人工折腾数小时；现在一句话描述需求，AI 自动选工具分析 APK/EXE 文件 |
| 2 | **多专业 Agent 协作** | 内置几十个专业逆向 Agent（口播"逆向SG"），每个模块负责擅长的任务，相当于给 AI 配上一整套逆向工程师的工作方法 |
| 3 | **自动产出报告** | 辅助分析完成后自动整理逆向报告，覆盖破解软件、绕过会员限制、修改金币数量、分析运行逻辑等场景 |
| 4 | **适用人群** | 安全逆向、打 CTF、漏洞研究者：让 AI 跑工具和分析，人只做需要判断的部分 |

## 可执行 Takeaway

- [ ] 核验该工具的开源仓库地址（视频未口播名称/链接，需回看评论区或画面确认 → **待核实**）
- [ ] 本机沙箱环境实测：输入一个测试 APK，验证"自动选工具→分析→出报告"链路
- [ ] 若可用，封装为 Hermes 技能 `ai-reverse-engineering`，纳入网安工具链（关联 skill `bug-hunting-workflow`）

## 完整口播转写

> 现在AI已经开始抢逆向工程师饭碗了。怎么破解一个软件、绕过会员限制、修改金币数量、分析一个软件搞清楚它的运行逻辑。以前逆向一个APK要用到JADX、IDA整套流程，折腾下来可能就是几个小时。现在有人直接把这些逆向流程做成了一套Agent，配好环境一句话描述需求，AI自动选工具，辅助分析APK、EXE文件，最后还能整理逆向报告。重点来了，这里面有几十个专业的逆向Agent，每个模块负责自己擅长的任务，相当于给AI配上了一整套逆向工程师的工作方法。做安全逆向、打CTF、研究漏洞的可以让AI帮你选工具、跑分析、整理报告吧，时间留给真正需要你判断的地方。简单收藏，需要的时候直接回来抄作业。
