# 双非本科入行网安：学历、技术栈、项目三维拆解

> [!abstract] 摘要
> 针对双非背景想入行网络安全的攻略：①学历方面攻防方向相对宽容、人人靠自学站在同一起跑线；②技术栈分三层递进（基础 → Web 渗透核心 → 工程能力）；③项目要做透真实渗透流程（SRC/复现 CVE），这是双非简历翻盘的真正筹码。

## 要点

### 学历维度
- 网安攻防方向对学历要求**相对不高**（对比纯算法/研发岗），更看重实战能力。
- 学校教的往往还是枯燥理论或基础防火墙配置，真正对抗性的黑客技术基本接触不到；计算机专业或跨专业入行基本都靠自学，站在同一起跑线。
- **双非不用一开始就觉得自己没机会**；学历重要，但实战能力与技术深度影响更大。

### 技术栈三层（找工作核心）
1. **基础能力**：计算机网络（TCP/IP、HTTP 协议，渗透测试/流量分析都会碰到）、Linux 操作（常用命令、权限管理，基本功否则连提权都做不了）、Web 安全原理（SQL 注入、XSS、CSRF、文件上传，搞懂基本覆盖大部分基础面试题）、脚本语言 Python 或 Go（写端口扫描脚本、批量 PoC 验证脚本）。
2. **Web 渗透测试（必备核心）**：信息收集 → 漏洞发现 → 利用 → 提权 → 后渗透，**整条链路最好自己完整搞过**；Burp Suite、CS、MSF 工具要熟；漏洞验证、权限获取、内网横向移动、口令爆破考得比较多；进阶为内网渗透与权限维持（域环境结构、票据攻击如 PTT/PTK、复杂场景绕过技巧）。
3. **工程能力**：代码审计或日志分析至少懂一些（能看懂 PHP/Java/Go 常见漏洞代码逻辑）；自动化脚本是加分项；了解应急响应与日志分析。**不要求会写编一期或造轮子、不用刷算法题**——公司真正关心的是：你能不能发现系统漏洞并给出解决方案。

### 项目维度（双非翻盘关键）
- 双非简历不会因学历让面试官眼前一亮，但**一个扎实的攻防项目会**。
- 别停留在 DVWA 这类基础靶场阶段（一问原理说不上来就露馅）。
- 真正有价值的项目：有明确的漏洞挖掘过程——建议**去挖 SRC 或复现真实 CVE 漏洞**；针对一个 CMS 或中间件完整做一次渗透测试（信息收集 → 漏洞利用 → 提权 → 写渗透报告），全程跑一遍。
- **一个做透的漏洞复现或 SRC 挖掘记录，很多时候比三个普通靶场练习更有价值。**
