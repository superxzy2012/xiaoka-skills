## 是什么

**Firecrawl** 是一个专为 AI Agent / RAG 管道设计的网页抓取与数据提取工具。
丢给它一个 URL，它就能把网页转成**干净的 Markdown / JSON / 截图**，自动处理动态加载、反爬、格式清洗。

- GitHub 总榜前 100，**~13 万 Star**（增速极快，2024 年底才 2 万星）
- 知名客户：**Apple、Shopify、Zapier、Replit、Kaena**
- YC 背景，已融资 $14.5M Series A

---

## 核心能力

### 1. 网页转干净数据
- 输入 URL → 输出干净 Markdown / JSON / 截图
- 自动过滤广告、导航、无关按钮（比原始 HTML 少 **67% token**）
- 处理 JavaScript 动态渲染页面

### 2. AI 浏览器操作（Actions）
- AI 自动点击、填表、翻页、走完登录流程
- 像真人一样操作网页，然后结构化提取结果
- **天生为 AI Agent 设计**

### 3. 深度爬取
- 整站爬取，可配置深度和 URL 模式
- Map 端点：快速分析网站结构，不用全爬
- 自然语言爬取提示词替代手动参数配置（v2）

### 4. 搜索 + 抓取一体化
- 搜索关键词 → 自动抓相关页面 → 结构化输出
- 适合 RAG 和研究场景

### 5. MCP 原生支持
- 可直接接入 Cursor / Claude Code / 任何 MCP 客户端
- 实时网页数据直接喂给 AI Agent

## 与 Crawl4AI 对比

> 我们本地已装 Crawl4AI（81k stars，Python 开源）。两者对比：

| 维度 | Firecrawl | Crawl4AI |
|------|-----------|----------|
| **GitHub Stars** | ~130k（增速更快） | ~81k |
| **开源协议** | AGPL-3.0（开核） | MIT（完全开源） |
| **自托管功能** | ⚠️ 阉割版（无 Fire-Engine / 代理轮换 / Actions） | ✅ 完整功能 |
| **云服务** | ✅ 成熟（$16/月起） | 有商业版但社区为主 |
| **反爬能力** | 🔥 Fire-Engine 专有技术，成功率高 | Playwright 标准方案 |
| **MCP 支持** | ✅ 官方原生 | ✅ 社区/官方 |
| **本地 LLM** | ❌ 不支持 | ✅ 支持 Ollama 等 |
| **语言** | Python / Node.js / Go / Rust SDK | Python |
| **适合场景** | 生产级、大规模、高反爬站 | 本地实验、隐私敏感、成本敏感 |

### 结论
- **Crawl4AI 够我们日常用** — 本地部署、完全免费、功能完整
- **Firecrawl 是升级版** — 遇到反爬强的网站、大规模爬取、需要 MCP 原生接入时考虑付费
- 两者互补，不是替代关系
