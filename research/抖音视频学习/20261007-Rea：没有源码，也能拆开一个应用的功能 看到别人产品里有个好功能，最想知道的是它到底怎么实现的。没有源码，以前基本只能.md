## 💡 关键要点

- **REA（Reverse Engineer Anything）**：给 agent 用的逆向工程工具，无源码也能拆解应用功能实现
- **三段工作流**：`Decompile`（反编译恢复可读代码/字符串/符号）→ `Understand`（跨模块追调用链直到能解释功能）→ `Recreate`（在你的技术栈里做出类似功能）
- **给 agent 用**：装 MCP 之后直接对 agent 说「搞清楚 Notes 应用里搜索是怎么做的，给出证据，并在我的项目里做一个类似功能」
- **CLI + MCP 双入口**：`npx rea-agents setup` 一次装好（MCP 注册 + 路由 skill 一起）
- **本地分析**：分析跑在本机，不上传应用到托管服务（与视频说法一致）
- **自带逆向工具链**：REA 通过 Provider Adapter 接入已有工具（Hopper、Ghidra、radare2），自己不重写反编译器
- **诚实边界**：官方明确「不声称能恢复原始源码，也不自动克隆应用」——视频没提这点，是重要限制
