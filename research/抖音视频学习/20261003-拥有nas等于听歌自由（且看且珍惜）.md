## 💡 关键要点

**项目：[lyswhut/lx-music-desktop](https://github.com/lyswhut/lx-music-desktop)** ★54,137 / Apache-2.0（落雪音乐）

### 视频演示的流程（飞牛 fnOS + Docker）
1. 进落雪项目 GitHub 仓库 → 翻到 **Docker** 章节 → 复制 docker-compose
2. fnOS「Docker」应用 → 「项目」→「编排」→ 新建项目
3. 粘贴 compose → **自己创建音乐文件路径**（视频强调「记住这个路径，后面有用」）
4. 填端口（不能重复占用）+ 设密码（登录用）
5. 创建成功 → 容器列表点进去 → 「设置」→ 用刚设的密码登录
6. 添加歌曲 → 播放
7. 回第 3 步创建的那个文件夹 → 里面出现音乐文件
8. 打开音乐 App → 订阅 → 「转换/本地」→ 选那个文件夹 → 完成

### 关键机制
第 7-8 步是整个技巧的核心：**LX Music 在 NAS 上播放时会把音频缓存成真实文件落到指定目录**，
所以任何能扫这个目录的播放器（本地音乐 App、foobar2000、群晖 Audio Station 等）都能当曲库用。
相当于**用自己的 NAS + 订阅做本地音乐库**，不依赖各平台的曲库限制。

### 项目背景
- 桌面版是 Electron 应用，Windows/macOS/Linux 都能装
- 从 v1.17.0 支持 Scheme URL，可被浏览器调用（配套油猴脚本 `lyswhut/lx-music-script`）
- 从 v2.2.0 起有独立的**数据同步服务** `lyswhut/lx-music-sync-server`，可自部署做多端同步
- 官方文档：https://lyswhut.github.io/lx-music-doc/
