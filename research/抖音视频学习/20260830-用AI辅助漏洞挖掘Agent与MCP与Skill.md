# 用AI辅助漏洞挖掘：Agent、MCP、Skill的正确打开方式

> [!abstract] 摘要
> 讲透"AI 辅助挖洞"的正确姿势：AI 是处理重复工作的助手而非自动挖洞机器；网页 AI 因无持续上下文不适合挖洞，应转向 AI Agent（Claude Code / Codex）；并按任务选择模型（Claude/GPT vs DeepSeek）；高手用 CLAUDE.md + MCP + Skill 三件套定制 Agent；AI 结果必须人工验证与审核报告。

## 要点

### AI 在挖洞中的正确定位
- **AI 不是自动挖洞机器，而是安全助手**：真正会用 AI 的人不是让 AI 替自己思考，而是让 AI 处理大量重复工作，把时间花在漏洞分析和判断上。
- **反例**：新人一上来就说"帮我扫描这个网站把所有漏洞找出来"，最后得到几十个漏洞，一验证 90% 都是误报（Wubalk）——从一开始就搞错了 AI 的用途。

### 为什么网页版 AI 不适合挖洞
- 挖洞不是"问一个问题等一个答案"，而是**持续推进的过程**：了解项目结构 → 分析接口 → 查看代码 → 判断攻击面 → 验证漏洞 → 根据新结果继续深入。
- 传统网页 AI（ChatGPT / DeepSeek / 豆包）记不住完整上下文，需不断复制代码、结果、重述背景——最终你变成"AI 和项目之间的搬运工"。
- 学习原理、解释技术、优化漏洞报告等单点场景，网页 AI 依然好用。

### AI Agent 带来的变化
- 普通 AI = 咨询专家（问-答）；**Agent = 真正参与工作的助手**（如 Claude Code）：直接进入项目环境、读取项目文件、分析代码结构、执行命令、调用工具，并根据执行结果持续推进任务。
- 例子：以前发现接口要复制代码发给 AI 问有没有漏洞；现在 Agent 直接读取整个项目、分析接口调用关系、结合代码逻辑判断是否存在权限问题，再辅助验证。
- 核心：AI 从"回答问题"变成"参与完成任务"——这也是安全人开始用 Claude Code、Codex 的原因。

### 模型怎么选（没有"最强模型"）
- **只有最适合具体任务的模型**，没有标准答案：
  - 分析大型项目/多文件调用关系/判断业务逻辑漏洞 → 推荐 Claude 或 GPT（代码理解、复杂逻辑分析、上下文处理更强，成本也更高）。
  - 日常练习、写辅助脚本 → DeepSeek 等低成本模型完全够用。
- 高手不是绑定单一模型，而是**让不同模型负责不同工作**。

### AI 参与挖洞的完整流程（示例：授权项目）
1. 先让 AI **理解目标**：项目是什么、测试范围、重点关注的功�能。
2. Agent 读取项目代码、分析目录结构、整理接口信息（如发现 `GET /salary?id=` 用户信息接口）。
3. AI 分析出潜在漏洞（如横向越权）——**但只是参考**。
4. **人工验证**：修改用户 ID、用不同权限账号测试、观察返回结果；普通用户真能访问到其他用户数据，漏洞才算成立。
5. AI 整理漏洞描述、复现步骤、风险说明，生成测试报告。
- 分工：AI 负责分析/整理/重复性工作，人负责判断方向、验证结果、确认漏洞价值。

### 高手的三件套：CLAUDE.md + MCP + Skill
- **CLAUDE.md**：写给 Agent 的"工作说明书"——项目是什么、测试范围、重点关注哪些漏洞、哪些危险行为绝对禁止；每次启动 Agent 先读它，不用重新摸索。
- **MCP**：给 AI 增加连接能力——连接浏览器、代码仓库、外部工具（读 GitHub 项目、访问测试页面、辅助执行具体操作）。
- **Skill**：一套固定的方法流程——如 SQL 注入分析流程、XSS 分析流程、越权检测流程；把自己的经验整理进去，Agent 遇到类似任务直接按成熟方法执行。
- 真正高级的 AI 安全工作流 = **模型 + Agent + 一套标准工作流程**，而不是单纯换更强的模型。

### 三个关键提醒
1. **不要盲目相信 AI 直接给的漏洞结果**（AI 极易误报）：标准流程 = AI 发现可能性 → 人工验证 → 确认漏洞成立。
2. **AI 生成的报告必须亲自审核**：AI 可能凭空编造不存在的请求、夸大漏洞影响、错误描述利用方式；提交前自己重查一遍。
3. **别把 AI 当无所不能的外挂**：没有扎实安全基础时 AI 只能生成"看起来挺专业的内容"；真正理解 Web 原理、漏洞机制与攻击流程后，AI 才能成为能力放大器。

### 结论
- 真正的 AI 挖洞：让 AI 深度参与分析流程（分析代码、整理信息、调用工具、减少重复工作），但**漏洞成不成立、风险是否真实、攻击路径是否有效，最终由人判断**。
- "未来会被淘汰的不是不会用 AI 的人，而是只会死板使用工具、却不会独立思考的人。"
