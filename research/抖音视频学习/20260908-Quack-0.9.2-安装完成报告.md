## 🛡️ 经验固化：sandbox 下 GitHub release 拉取三路径

| 路径 | 状态 |
|---|---|
| `curl -L https://github.com/.../releases/download/...` | ❌ HTTP/2 framing error + 75s timeout + HTTP/1.1 也 0 字节 |
| `gh release download` | ✅ **秒过**，且自动选 `codeload.github.com` 走 GitHub 自己的 codeload CDN |
| `wget` | ❌ 未测（curl 不通 wget 大概率也不通）|

**结论**：**GitHub release 下载永远首选 `gh release download`**——`gh` 走 GitHub 自己的 CDN 端点（codeload），不受 sandbox 的 GitHub 主站 HTTP/2 限制。
