# 零基础转行网安三个月路线：别碰代码、先练手感、再上实战

> [!abstract] 摘要
> 作者 18 年裸辞转行时啃 700 多页教材六个月连 SQL 注入都找不到，后来按行业 8 年白帽师傅的规划三个月拿到 8K offer；去年一个高中文凭粉丝照此路线第三个月挖到第一个通用漏洞拿 1200 赏金。路线核心：网安入门重实操、一开始不需要会写代码。

## 要点

### 三个月路线总览
- **第一个月：别碰代码，只干一件事——搞懂电脑之间怎么通信**
  - 概念直觉化：IP = 电脑门牌号；端口 = 门牌号下的窗户和门（80 号看网页、3306 放数据库）；TCP 握手不用全背，但要懂数据怎么发出去。
  - 100 道必考题，每天背 20 道，15 天基础打牢；剩下 15 天练基础命令：装虚拟机 + Kali Linux 系统，每天敲 ping（看网络通不通）、netstat（看谁连着你的电脑）、cd / ls（翻文件夹）——不用懂底层原理，先把手感练出来。
- **第二个月：开始实战，核心就三样——Kali 系统、Burp 抓包、Nmap 扫描器**
  - 用 DVWA 靶场（练手的沙包）每天练两个实操题：
    - **SQL 注入**：不用会写代码，输入框打个单引号报错说明有漏洞，再用 Kali 自带 sqlmap 照着网上命令一抄，直接把账号密码拔出来（爆库）。
    - **XSS 跨站**：输入框打一串 `<script>alert(1)</script>`，网页弹窗即复现成功。
    - **越权漏洞**：用 Burp 抓包，把自己的用户 ID 改成别人的 ID 放包，别人的数据（钱）就到你这了。
  - 就像拼乐高照着步骤操作，根本不需要会写代码；**能独立把漏洞复现出来就算及格**。
- **第三个月：脱掉新手保护装，直接上实战**
  - 直接去众测平台挖小漏洞 + 练写漏洞报告；挖够三个就能写进简历投安全岗，起步薪资最少 7K；不想上班也可以拿赏金当副业。

### 避坑要点
- 别一开始就啃大部头教材（作者啃 700 多页教材六个月连 SQL 注入都找不到）。
- 学了一两年入不了门不是笨，是**一开始就被误导、学了堆没用的东西**。
- 网安入门注重实操，**根本不需要一开始就会写代码**。
