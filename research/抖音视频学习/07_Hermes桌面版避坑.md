# Hermes官方桌面版新手避坑指南来了~

## 核心内容（276字）

Hermes Agent 桌面版（Electron 应用）的安装与配置避坑指南。桌面版相比 CLI 版本提供了更友好的图形界面，但也伴随着一些常见的陷阱。视频总结了新手最容易遇到的几个问题：模型提供者配置错误导致无法对话、网络代理设置影响 API 调用、文件路径包含中文导致的编码问题、多平台消息网关的认证配置遗漏，以及版本更新后配置不兼容的处理方法。逐个讲解了问题表现、根因分析和解决方案。

## 关键操作步骤

1. **模型配置**：检查 config.yaml 中的 provider 配置是否正确
2. **代理设置**：如果使用代理，需在环境变量中正确配置
3. **中文路径**：避免在 Hermes 工作目录中使用中文名称
4. **网关认证**：飞书/Telegram 等平台需要正确的 App ID 和 Secret
5. **版本更新**：更新后运行 `hermes doctor --fix` 修复配置兼容性

## 适用场景
- 首次安装 Hermes 桌面版的用户
- 遇到配置问题无法正常使用的场景

## 注意事项
- 桌面版与 CLI 版共用同一套配置文件
- 升级前建议备份 config.yaml
