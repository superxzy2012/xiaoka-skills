# 新手也能用上主动型hermes智能体团队了！

## 核心内容（278字）

Hermes Agent 的多 Agent 团队协作模式——不再是单 Agent 被动响应，而是多个专业 Agent 主动协作完成任务。视频展示了如何利用 Hermes 的子代理（Sub-agent）和技能系统构建一个主动型 Agent 团队：设置不同角色的 Agent（规划者、执行者、审查者）、定义 Agent 间的协作流程、让 Agent 主动监测条件并触发行动。通过实际案例演示了从"用户提问→Agent 主动规划→拆解任务→多 Agent 并行执行→汇总结果"的完整工作流。

## 关键操作步骤

1. **角色定义**：创建不同专业方向的 Agent 角色（分析/执行/审查）
2. **技能分配**：为每个 Agent 加载不同的技能集
3. **协作流程**：定义 Agent 之间的任务交接和数据传递规范
4. **主动触发**：配置 Cron 和 Webhook 让 Agent 主动工作
5. **结果汇总**：设计多 Agent 输出的统一汇总格式

## 适用场景
- 需要处理复杂多步骤任务的场景
- 希望 AI 从被动响应升级为主动服务的用户

## 注意事项
- 多 Agent 协作会增加系统复杂度和 Token 消耗
- 需要合理设计 Agent 间的通信协议
