# 各类网盘最严厉的父亲，网盘豆包也可以加速

## 核心内容（一句话）
用豆包桌面端（具备本地电脑操作能力）一句话指令，让它自动从 GitHub 安装开源变速工具 **OpenSpeedy（game1024/openspeedy）**，再用该工具给网盘客户端进程加速，实测可加速网盘下载。

## 操作步骤
| 步骤 | 操作 |
|---|---|
| 1 | 对豆包说：「GitHub 上有个叫 game1024/openspeedy 的开源项目，帮我安装到桌面」 |
| 2 | 选择「工作任务」，本地电脑发送给豆包（需授权本地操作权限） |
| 3 | 等待自动安装完成（实测装到 `C:\Program Files\OpenSpeedy\`，自动创建桌面快捷方式） |
| 4 | 打开 OpenSpeedy，在「变速」页选择加速挡位（预设 1×/2×/5×/10×/100×，滑条最高约 1000×，视频实测拉到 117.49×） |
| 5 | 在进程列表中找到网盘进程并开启加速开关，然后打开网盘下载 |

## 关键项目：OpenSpeedy
- **仓库**：https://github.com/game1024/OpenSpeedy
- **描述**：🎮 An open-source game speed modifier（开源变速工具）
- **Stars**：18,609（截至 2026-09-30，活跃维护中）
- **语言**：TypeScript
- **平台**：Windows（视频实测环境 Win10 19045 / RTX 4060）
- **原理**：注入指定进程修改进程内时钟速率，实现单进程快放/慢放，不影响系统全局时间；支持 x64/x86 进程
- **界面要点**：变速倍率滑条（0.001×～1000×）、进程列表搜索、进程详情/模块查看

> ⚠️ 注意：视频作者口播「给网盘进行供选商」为语音识别误差，实际是给网盘进程**挂上加速（注入）**；工具本质是变速齿轮，对网盘下载是否真有效取决于网盘客户端限速机制，视频作者称「实测非常好用」，**第三方效果未独立验证**。
