## 是什么

**TikHub** 是一个社媒数据基础设施平台，提供 **16 个社媒平台 × 1000+ API 端点** 的统一访问，原生支持 **MCP 协议**（990+ MCP tools），AI Agent 可以直接通过 MCP 调用所有社媒数据。

> 定位：**为 AI 时代而生** —— 面向具身智能的社交推理与情感智能数据集，以及驱动量化交易、政府国防、营销广告领域 AI 智能体的实时社媒数据 API。

### 3. 990+ MCP 工具（⭐ 核心亮点）

**直接通过 MCP 协议接入 Claude Desktop / Cursor / VS Code / LangChain：**

```bash

```

> 一套 MCP 协议接入所有 API 接口，不用逐个平台对接

### 4. 其他能力

## ⚠️ 注意事项（视频提到）

1. **稳定性差异**：不同平台的 API 稳定性不一样，微信/LinkedIn 反爬逻辑强，接入阻碍多
2. **微信的边界**：TikHub 的微信 API 只覆盖**公众号 + 视频号**，不是微信聊天（企业微信已全开放 MCP 和 CLI）
3. **LinkedIn 反爬强**：有 10 种解决方案（搜索/职位/发现/话题/留言/评论等），但稳定性需实测
4. **合规风险**：批量抓取社媒数据可能涉及各平台 ToS，商用需评估法律风险
