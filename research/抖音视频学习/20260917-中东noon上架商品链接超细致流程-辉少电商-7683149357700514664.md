# 中东跨境电商 noon 上架商品/链接 · 超细致实操

> 作者：**辉少讲电商**｜来源：[抖音原视频](https://www.douyin.com/video/7683【手机号】4664)｜5分31秒
> 主题：用第三方**采集上架 ERP**（AI 自动上品）从 Amazon 等货源采集商品，批量铺到 **noon** 店铺。

## 一句话流程
noon 后台「上架商品」看状态 → AI 采集 ERP 里先做**采集过滤条件**（货源/发货模式/到货时效/价格/月销）→ 再做**上品基础设置**（库存/加价倍数/去重/AI标题/违禁词/侵权检测）→ 每天铺 2000–3000 个测品 → 半个月后清滞销 → 跑出稳定品再转 FBN。

## 一、noon 后台上架状态判定
- 商品列表右侧状态：
  - **绿色 Live / Buy Box Won** = 上架成功，消费者可见、可下单（以此为准）。
  - **红色** = 审核中 或 被驳回，需处理。
- 界面字段：`+ Add Products`、`All Filters`、`Saved Views`、`Seller Status`、`Live Status`、`Buy Box`。

## 二、采集过滤条件（上品前必做）

| 设置项 | 推荐值 | 原因（口播要点） |
|---|---|---|
| 货源渠道 | Amazon 为例；也可 Shein、Fordeal（佛姆蒂湾）等中东隔壁平台 | 把成熟平台当货源 |
| **多 SKU 上品** | 开启 | 上传多规格 |
| **采集价格** | **原价**（不要活动价） | 若按 2–3 倍活动价采，活动恢复原价后定价可能亏损 |
| **过滤发货模式** | **过滤掉 FBM**（商家自发货），只留 **FBA / Amazon 自营(AMZ)** | 自发货慢且不稳；自营发货一般 **1–3 天到中东海外仓**，物流时效直接影响店铺权重、评价、退货率 |
| 禁采到货时间 | **≤ 3 天** | 货到中东仓后还要重新转面单、贴 noon 面单再发给客户 |
| 限制价格区间 | 高客单可设 50 / 100 / 200（示例 50） | 价格是货盘显示价，不做汇率换算 |
| 尺寸/重量/评论数/评分 | 按需设 | 超限过滤 |
| **限制月销量** | **≥ 30 单/月**（必设） | 月销不足 30 的品在别的平台都吃力，上了也是零流量零曝光，浪费库容；选"已验证能出单"的品 |
| 关键词过滤 | 英文分号分隔 | 标题含指定词的过滤掉 |

## 三、上品基础设置（ERP「上品中心」）

| 设置项 | 推荐 | 说明 |
|---|---|---|
| 最小库存 | **≥ 10 件** | 防止客户一次拍多单突然断货 |
| 固定上品库存 | 约 10–20 件 | — |
| 默认尺寸/标题长度 | 按平台限制（标题约 170 字符） | — |
| 上品时间间隔 | 0 秒（可调） | 控制铺货节奏 |
| **上品价格上浮** | **2–3 倍**，保证 ≥50% 利润 | 货源 100 → 店铺卖 200/300/400；支持阶梯式上浮、标题前后缀 |
| 汇率互换 | 自动更新开启 | 界面含 CNY/USD/EUR/GBP/JPY/AUD/CAD/CHF/HKD |
| **去重** | **必开** | 平台厌恶同质化铺货，现在可用 AI 自动去重 |
| **AI 标题** | **必开** | 自动抓类目/属性的热门词、飙升词、潜力词堆进标题，提升搜索权重 |
| 过滤多规格 0 库存 SKU | 开 | — |
| AI 提取规格名称 / 自动分类目 / 增强类目 | 全开 | — |
| 采集详情 | 文字+详情图号一口气抓全 | — |
| **违禁词过滤** | **必开** | 中东禁忌多，违禁词/禁售品绝不能碰 |
| **侵权检测** | **必开** | 不碰假货、不碰品牌侵权（国内外电商底线） |
| 合并图片 | 随机 4–5 张图（可选） | — |

## 四、铺货节奏与运营策略
- **前期大力出奇迹、大量测品**：每家店每天上 **2000–3000 个品**。"我一天上 3000 个，顶你只上 100 个一个月的曝光"。
- 上的都是**别的平台已验证能出单**的品（月销≥30），不是盲目精选。
- **半个月后定期清滞销品**，保店铺动销率，不要盲目铺到底。
- 稳定爆品跑出来后：从**一件代发（轻装快测）转 FBN / 同货备货**模式。
- 逻辑：铺货测品拿曝光 → 数据筛选 → 精细化 → 爆款备货。

公公跨境電商論，知道我們要上架商品怎麼上架鏈接。這可能是你在全網能找到的最最最最最強氣的、關於 noon 上架商品上架鏈接的完整實操教程，我將要花三分鐘為你拆解的透透的，不信教不明白。

**第一步：** 登入咱們 noon 的店鋪，點擊上架商品界面。右邊一列綠色的 Live 顯示的是已經上架成功的商品；如果顯示紅色，要麼在審核中，要麼被駁回。一定以綠色上架成功為准，只有綠色，消費者才能看到商品、才能下單。

現在是 AI 時代，演示一下：鼠標在這裡，後台一直在 AI 自動設置商品屬性、標題，包括圖片詳情圖號，不斷提交建品、上架商品，全部自動化。可以看到有成功有失敗，原因是自動化之前必須做一些基礎設置跟過濾。

**過濾條件（兩大部分）：** 以 Amazon 作為貨源渠道為例（也可以是 Shein、Fordeal 等中東隔壁平台）。
1. **多 SKU 商品必須開啟**；
2. **采集價格建議用原價**——若采活動價（2倍3倍），它一恢復原價你的定價可能虧；
3. **過濾發貨模式**：一定要過濾掉 FBM（商家自營自己發貨，物流慢不靠譯），我們要極致物流，必須要 FBA / Amazon 自營發貨，一般 1–3 天到中東海外倉。物流達標→店鋪權重高、客戶評價好、少退單少變卦；
4. **進采到貨時間設 3 天內**必須到中東海外倉（還要重新轉面單貼 noon 面單再發給客戶）；
5. **限制價格區間**：想做高客單可設 50/100/200；
6. **必須設月銷量數**：一個月至少賣 30 單。月銷 30 都沒有的品在別的平台都吃力，零流量零曝光零場克，浪費內存。上"大概能出單的品"；
點擊確定。

**上品基礎設置：**
- **最小庫存得有 10 單**，防止客戶一次拍多單沒貨；
- **上品價格**：貨源 100，店鋪可賣 200/300/400，建議 2–3 倍，保證至少 50% 以上利潤；
- 固定上品庫存設置一下；
- **去重一定要打開**（平台不喜歡同質化撲貨，現在 AI 可實現）；
- **AI 標題一定要點開**：自動抓取商品內幕、屬性、熱門搜索詞/飆升詞/潛力上升詞堆到標題，搜索權重更高；
- **過濾多規格零庫存 SKU**、使用自動分內幕、增強內幕全部打開；采集詳情文字、詳情圖號一口氣抓到位；
- **違禁詞一定要過濾**，中東忌諱多，違禁詞和禁售商品絕不能碰；
- **侵權檢測一定要打開**：不碰假貨、不碰品牌侵權，國內外都一樣，最基本操作。

**鋪貨節奏：** 以上設置做完後，每天保證一家店上 **2000–3000 個品**。前期大量測品階段一定是大力出奇跡，上得多店鋪流量反客曝光才高。一天只上 100 個品，我一天上 3000 個就頂你一個月工作量，你拿什麼拼曝光？而且我上的是別的平台驗證過能出單的品。不要扯精選，你只是懶、不懂用 AI。上半個月後要定期清自銷品，保證店鋪動效率，跟國內差不多，不要盲目撲貨，慢慢精細化。有穩定品跑出來後可轉 FBN、銅貨背貨模式；前面快速測品階段可做一件代發，輕鬆上陣。
