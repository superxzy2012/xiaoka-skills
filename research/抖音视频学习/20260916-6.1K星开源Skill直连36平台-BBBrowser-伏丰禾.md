# 6.1K星开源Skill直连36平台：BB Browser

> **A级置信·已核验仓库存在**。核心工具 = **BB Browser**（`epiral/bb-browser`），GitHub **6,213 星**，TypeScript，**MIT** license。Adage：**「Your browser is the API」**——CLI + MCP server，让 AI agent 用你的登录态操控 Chrome。

## 它解决什么问题

AI 要跨平台找资料时，传统硬抓（爬虫）会被平台限制/风控；逐个申请 API 又繁琐。BB Browser 反过来——**复用你已登录的浏览器真实会话**，让 AI 像你本人一样浏览和操作，更接近真人，账号更安全，且免 API 申请。

## 六大卖点（口播转述）

1. **平台限制更少**——不是普通爬虫硬抓，而是附用登录态，接近真人浏览，账号更安全。
2. **不用逐个平台申请 API**——省掉申请权限和调用额度的麻烦。
3. **官方覆盖 36 个平台 / 103 条命令**——小红书、微博、B站、YouTube、知乎等现成用法。
4. **返回结构化数据**——AI 可直接分析/对比/整理，高效整理目标数据。
5. **兼容主流智能体**——接近 Codex / Warebody / Cloud Code 等；作者实测跑通 **Codex**。
6. **可扩展新网站**——把网址+想取的数据告诉智能体，它能继续新增网站用法（社区驱动，`bb-sites` 一个 JS 文件一个站）。

## 安装与使用（帧OCR确认）

- 装法：`npx bb-browser --mcp`（CLI + MCP server，一条命令）
- 定位：`epiral/bb-browser`，MIT，TypeScript
- 理念：`Your browser is the API`；"页面读取不等于验证所有能力，你本人必须坚持真测才作数"

## 作者实测演示（B站+小红书，同词搜"AI工具"）

| 项 | 值 |
|---|---|
| 平台 | B站 + 小红书 |
| 关键词 | "AI工具" |
| 数量 | 各取前 10 条 |
| 结果 | 两平台均跑通，返回真实内容：标题 / 作者 / 热度数据 |

小红书返回样例：`大AI工具！避免你被时代淘汰`（22.8万）、`大模型，从夯到拉依次排名！`（9.8万）。作者用此做选题挖掘。

## 选型对照（与我手上工具的取舍）

**BB Browser 与本环境已有 `agent-browser`（browser_exec）高度同源**——都是「浏览器即API + 登录态复用 + 结构化输出 + MCP」。差异点：

| 维度 | BB Browser | 本机 agent-browser |
|---|---|---|
| 形态 | CLI + MCP server、`npx` 一条装 | Rust CLI、独立 harness |
| 平台预置 | 36 平台 103 命令（bb-sites 社区维护） | 无预置，逐站写 |
| 定位 | 独立开源工具（6.2K星） | 内嵌于 Hermes/OpenClaw 自动化栈 |
| 适合 | 想用独立开源方案、跨平台开箱即用 | 已深度整合本 agent 流程 |

**结论**：本项目功能已被本机 agent-browser 覆盖，**无需重复安装 duplicate skill**；双边可互补——BB Browser 的 `bb-sites` 平台适配表可作为我们扩展 agent-browser 平台覆盖的参考清单。

## 避坑 / 要点

- 仓库是 **TypeScript + MIT**，桌面端 Chrome 依赖登录态；无登录 web 页渲染空，抓不到视频元素。
- 结构化数据是闯片既得，但**页面读取 ≠ 能力验证**——要真用前先测通过再说（作者自己都强调）。
- 36 平台是"官方覆盖清单"（原项目列示），**不代表已逐一实测**，选型时按需验证目标平台。
