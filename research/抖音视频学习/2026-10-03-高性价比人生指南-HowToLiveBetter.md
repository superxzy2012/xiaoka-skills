## 📌 官方定位（README 原文）

> 高性价比人生指南 —— 用最少的钱、时间和精力，换回最多的寿命、金钱和人身自由

> 讲怎么活得久、怎么少生病，出了意外怎么救。讲怎么少花冤枉钱，哪些事会让人被骗、
> 摊上官司。讲没工作没钱时能去领什么，开店、开公司、做网站要办什么手续。
> 也讲恋爱结婚生孩子、出国和学手艺。**法律、医保、社保这些制度上的内容，
> 按中国大陆的现行规定写。**

> **654 条建议，每条写明花掉什么、换回什么、证据有多硬，
> 来源只引期刊论文与官方文件。**

> **不用全做：这是按性价比排好的备选单，不是任务清单**
> ——挑走一两条就算数，作者自己也没做到其中大部分。

## 🔍 核心设计：证据分级 + 性价比排序

这是它区别于普通「人生建议」的关键：

**证据分级**（README badge 实测）：**A 级 429 条 · B 级 174 条 · C 级 51 条**
（合计 654，与条目数吻合 ✅）

**性价比档** —— 不告诉你「什么是最好的」，而是帮你**算清楚某件事值不值**。
每条建议都写明：花掉什么 / 换回什么 / 证据有多硬 / 原始出处。

**33 个主题**（部分实例）：
```
32. 出国留学：身份、打工、保险和回国认证
33. 残疾之后怎么活
…
（另有长寿防病、急救、省钱理财、法律红线、失业与工伤、
  医保社保、恋爱婚育、怀孕育儿、创业与做平台合规、出国与技能）
```

## 🔌 可装进 AI Agent（视频重点，已核实）

README 明确提到支持 **Claude Code** 和 **Codex** 的 skill 安装，
装好后「它先查书里的条目再回答，并注明出自哪一条」——
即**回答带出处引用**，不是凭空生成建议。

这正好对上本机 `ground-truth-discipline` 的回源纪律：
输出必须能追回原始条目，不能凭记忆补全。

> 注：视频说「装进豆包电脑版的技能库」，README 里提到的是 Claude Code 和 Codex。
> 豆包是否支持未核实，但 skill 机制是通用的。

## 💡 对 BOSS 的实际价值

**跨境电商方向可用的主题**：
- 「创业与做平台合规」—— 平台规则红线，和本机 `ozon-compliance-gate` 技能直接相关
- 「开店、开公司、做网站要办什么手续」—— 主体资质
- 「法律红线」—— 哪些事会摊上官司
- 「失业与工伤/医保社保」—— 跨境创业的兜底

⚠️ **重要限制**：README 明确写「**法律、医保、社保这些制度上的内容，
按中国大陆的现行规定写**」。做 Ozon/美客多等跨境业务时，
**俄罗斯/巴西/美国的法规部分不适用**，只有「性价比决策方法论」是通用的。
