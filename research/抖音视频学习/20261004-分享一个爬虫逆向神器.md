### 六大核心功能（README 已回源核实）
| 功能 | 说明 |
|---|---|
| **scrape** | 抓单页。只保留核心正文，过滤导航栏/广告/评论/推荐 |
| **crawl** | 整站抓取。按网站结构自动发现子页面，批量抓 |
| **map** | 只拿全站 URL 清单，不抓正文。适合先筛选再定向抓 |
| 内容转换 | 输出 Markdown / HTML / 结构化 JSON（可预定义字段提取商品、价格、评分） |
| 动态网页 | 处理 JS 渲染的页面（**注意：视频原话说「处理一部分」，不是全部**） |
| API / SDK | 云端 API + JS/Python SDK + MCP server，可集成进自己的产品 |

### 典型场景
- 建 AI 知识库：抓一批网页 → 转 md → 切块 → 向量化 → 检索
- 竞品分析：批量抓对手网站全站
- 商品监控：预定义字段提取价格/评分/库存
