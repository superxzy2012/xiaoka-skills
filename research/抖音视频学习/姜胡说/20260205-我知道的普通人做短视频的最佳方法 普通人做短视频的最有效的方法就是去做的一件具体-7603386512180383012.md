# 我知道的普通人做短视频的最佳方法 普通人做短视频的最有效的方法就是去做的一件具体事。哪怕是一件很小的事。
拍短视频也行，写文章也行，做个小生意也行。
半年或一年，选一件值得做的事，专注去做。 
同时，把你的学习曲线分享出来。
本身就可以
且应该是
你最重要的副产品。 
为什么？
你做事的过程中必然会遇到卡点。
比如拍短视频拍着没灵感了，做生意发现产品卖不出去。
你就给大家讲:我遇到什么问题，试了哪3种方法，哪个失败了，哪个成功了。最后用哪个方法解决了。 
这种分享有4个价值:
1. 产生共鸣
你遇到的问题,别人也会遇到。
"原来你也有这样的问题?"——共鸣是短视频的核心。 
2. 知识可用
你在行进中,会把大事拆成若干小事。
那些小事恰恰是可以行动的力度。
这样的知识把知和行连接起来,是最有用的知识。 
3. 触发灵感
你做实验、突破、获得结果——这是人们真正要学的。
"你是怎么获得灵感的?怎么突破的?"
观众会顿悟,产生新想法。 
这是短视频最重要的3个作用:共鸣、有用、启发。 
还有一个隐藏价值
因为你持续做事,总遇到卡点。
相当于把做事地图里的关键卡点都分享了；
这种连载会让人持续关注你,影响力自然会积累下来，形成复利。 
真正做起来，其实就四步：
真实过程：先做一件真实的事，别为了学习而学习。
卡点与尝试：遇到卡点，自己尝试解决（可以向他人学习，但以自学、主动学习为主）。
公布与信任：learn in public，用户会共鸣、会借鉴、会信任你。
突破与转化：突破带来“开窍”，同时也会带来行动转化，这是连接用户的关键。 
这是一套完整的方法论：
真实过程 (卡点 + 尝试) → 用户信任 (共鸣 + 借鉴) → 认知升级 (突破) → 行动转化 (线头) → 持续关注 (连载) 
这是我知道的普通人做短视频最好的方法。
