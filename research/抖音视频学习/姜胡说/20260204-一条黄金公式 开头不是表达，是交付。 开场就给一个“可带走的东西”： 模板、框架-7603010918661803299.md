# 一条黄金公式 开头不是表达，是交付。
开场就给一个“可带走的东西”：
模板、框架、工具清单、避坑指南。
先给结果，再解释 
一条视频就用这个结构：
先承诺 → 再证明 → 最后为什么。 
1）承诺怎么写（开头第一句）
承诺不是“我来讲讲”。
承诺是：X时间内，让你得到Y结果，用Z方法。
一个固定的公式就能搞定：
A 时间 + 结果
“给我60秒，我让你___。”
B 人群 + 结果（顺口版）
“如果你是***，用***，你就能___。”
C 最小结果 + 可复制
“我给你一个可以直接抄的___。”
D 错误对照 + 结果
“别再了，改成，你会___。”
 
再加一条硬性标准：
承诺必须可交付，否则就是空话。 
2）证明怎么给（让人信“照做能成”）
证明不是“我很厉害”。
证明是：观众看完相信“这招能用”。
最短三句就够：
1）我也踩过这个坑。（对标）
2）我现在现场给你写一条/做一遍。（示例）
3）你发出去看信号。（可验）
能现场演示，就别讲经历。
现场演示的效果永远是最好的。 
3）为什么怎么讲（因果链，别讲道理）
只讲一条因果链：
为什么：观众要在前三秒下注。
你不给结果＝不确定性高＝划走。
先给模板/清单/框架＝不确定性下降＝愿意停留。
先承诺，就是先降低不确定性。 
⚙️ 背后机理
没做功课 → 交付不清 → 开头铺垫 → 3秒拿不到结果 → 划走
做足功课 → 人群清晰+交付清晰 → 开头先给最小结果 → 不确定性下降 → 停留上升 → 互动与收藏上升 
记住这个公式：
先承诺 → 再证明 → 最后为什么。 
开头不是表达，是交付。
