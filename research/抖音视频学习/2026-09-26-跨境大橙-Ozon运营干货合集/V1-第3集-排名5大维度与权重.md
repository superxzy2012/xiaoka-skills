# V1-第3集｜Ozon排名不是拼价格：5大维度与权重

> [!abstract] 摘要
> 90% 的卖家以为排名靠低价，但**价格在 Ozon 排名算法里只占 5%~10%**。真正决定排名的是 5 个维度：内容相关性、销售转化率、用户行为信号、物流履约速度、评价信任。算法只关心两件事：**商品能不能卖出去 + 买家体验好不好**。

## 一、排名权重全景（实测屏幕数据）

![[ep03-排名权重占比全景图.jpg]]

| 维度 | 权重 | 含义 / 优化要点 |
|------|------|----------------|
| **销售转化率** | **30%** | 点击率+详情页转化+加购率，直接决定流量变现效率，算法最看重 |
| **内容相关性** | **30%** | 关键词+属性+详情页文字，决定你能拿到哪部分流量，是"入场券" |
| **用户行为信号** | **15%** | 收藏/加购/复访/复购，代表用户认可度，影响实时排名浮动 |
| **物流履约速度** | **15%** | FBO/FBS 模式+发货时效+取消率，代表平台履约体验 |
| **价格竞争力+评价信任** | **10%** | 价格权重其实很低，别搞错重点；评价是基础门槛，不是加分项 |

> 一句话：**内容相关 + 销售转化 = 60%**，是命脉；价格只是噪音。

## 二、五个维度详解

**① 内容相关性（30%）— 入场券**
- 标题：**前 3 个词必须放流量最大的核心词**，中间放属性词，后面放长尾词/人群词
- 属性字段：颜色、尺寸、材质、用途**能填全填**，每个字段都在给算法"打标签"
- 长尾词转化率通常高于品类词（如"户外用的水壶" > "水壶"）

**② 销售转化率（30%）— 核心引擎**
- 点击率是第一道关：**点击率低于 2% 的主图直接换**（作者实测换图后 1.2%→3.5%，流量翻 3 倍）
- 详情页首屏：**3 秒内**让用户知道"这东西能解决我什么问题"，别一上来堆参数
- 加购率能到 **8% 以上**，算法会加权
- 转化漏斗：曝光100% → 点击(2-5%) → 加购(8-15%) → 下单(2-5%) → 收货好评(~1.5%)；每层提升 1%，整体产出能提升 30-50%

**③ 用户行为信号（15%）— 实时助推器**
- 收藏、加购、分享、**复购率**（复购权重很高）
- 算法不是每天算一次，是**实时浮动**：某时段收藏加购猛，接下来几小时会给更多曝光测试

**④ 物流履约速度（15%）— 基础保障**
- FBO（入官方仓）排名权重本身高于 FBS（自发货），同等条件排更前、有 FBO 标识、多流量入口
- **平均发货 48h→24h，排名平均上 10-15 位**
- 取消率 >5% 直接降权，>10% 可能限流

**⑤ 评价 + 价格（10%）— 信任门槛**
- **4.5 星是推荐池入场券**，低于 4.5 基本进不了算法推荐；4.5-4.7 正常，4.8+ 优质
- 评价数 0-50 条边际效益高，50-200 放缓，200+ 边际很低
- 慎用"快速收评价"（一条几卢布，毛利低就别买）；**利润 <30% 的老实做产品和评**
- 1 个差评要 5-10 个好评才能拉回；发货前质检 + 感谢卡 + 及时回复可挡 80% 差评

## 三、7 天提升排名执行计划

| 天 | 动作 |
|----|------|
| D1 | 导出竞品前10标题对比，重写标题（前3词核心大词）；晚上填满所有属性字段 |
| D2 | 主攻主图+详情首屏：点击率<2%的主图标出来，做3组不同风格（卖点型/场景型/对比型）测试 |
| D3 | 物流+评价自查：查近3天发货/取消/退货率，取消率>3%立即排查；评分<4.5想办法拉 |
| D4 | 深度优化详情页：加场景图/细节图/对比图，问答区埋5个常见问题自问自答；设加购立减，目标加购率18%+ |
| D5 | 开搜索广告测词，预算每天300卢布即可，重点看点击率和转化 |
| D6 | 能报的活动都报（免费流量）；包裹放感谢卡+复购优惠码；给加购未下单客户发邮件提醒 |
| D7 | 数据复盘：对比7天前后排名/点击率/转化率，记录哪些动作有效 |

## 四、10 题排名健康度自测

**内容与流量**：①标题前3词是核心关键词吗？②属性字段填满了吗（含场景词）？③主图点击率>2%吗？④详情页3秒内能看到核心卖点吗？⑤加购率能到8%以上吗？
**履约与信任**：⑥平均发货≤3天吗？⑦取消率<3%吗？⑧评分>4.5星吗？⑨有入FBO仓的计划吗？⑩每周看几次数据、知道自家排名吗？

> 答对 8+ = 健康；5-7 = 有明显短板，重点突破最弱的 1-2 个维度；<5 = 按 7 天计划系统重做。**排名是木桶效应，最短的板决定装多少水。**

## 六、心法（结尾）

人和人最大的差距不是选品能力，也不是运营技巧，而是**决策方式**：感觉驱动（我觉得这图好看/越便宜越好/这品能爆） vs 数据驱动（用点击率选图、按利润定价、看供需差选品）。**每周至少看一次完整数据，每月做一次竞品分析。**
