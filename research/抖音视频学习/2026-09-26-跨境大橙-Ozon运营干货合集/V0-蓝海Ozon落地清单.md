# V0-蓝海Ozon落地清单（学以致用）

> 适用：深圳市蓝海世纪科技有限公司（Ozon 跨境店）
> 用法：照着勾，每周滚动执行；`[P0/P1]` 为优先级。

## 0. 一句话心法
**价格不是排名主因（权重约 10%）；排名只看两件事——商品能不能卖出去 + 买家体验好不好。** 降本先砍"隐性扣费"，增收先攻"5大维度"。

## 1. 排名优化（按权重排序做 · V1 第3集）
- [P0] **内容相关性 30%（入场券）**：标题前 3 词放核心大词、中间属性词、后面长尾/人群词；属性字段能填全填；埋长尾场景词
- [P0] **销售转化率 30%（核心引擎）**：主图点击率 <2% 立即换（做3组A/B：卖点型/场景型/对比型）；详情首屏 3 秒讲清卖点；加购率冲 8%+
- [P1] **用户行为信号 15%**：引导收藏/加购/分享，做复购（实时浮动，某时段数据猛会被加推）
- [P1] **物流履约 15%**：能走 FBO 走 FBO；平均发货压到 24h 内（48h→24h 排名约上 10-15 位）；取消率 <3%（>5%降权，>10%可能限流）
- [P2] **评价信任**：守住 4.5 星（推荐池入场券）；慎开"快速收评价"（利润<30% 别开）；1 个差评要 5-10 个好评补

## 2. 成本风控（每周一巡检 · V6 第8集）
4 个**新店默认开启**的付费开关，建《后台开关巡检表》，每周一巡检：
- [ ] 好评返现 / 积分活动（默认开，买家好评系统自动返现，一单至少扣 20 元起）
- [ ] Premium 会员自动续费（免费体验期后自动续，持续扣款）
- [ ] 自动促销（平台自动打折，不关就一直压低售价）
- [ ] 好评置顶（按天收费，好评一多系统可能自动开启）
> 每周留 10 分钟检查"促销设置有没有被改、会员有没有自动续费、营销开关有没有新增"。事前排查 > 事后捶胸。

## 3. 标题优化（V7 第9集）
- **手写标题 > 自动标题**：自动标题（系统抓属性生成）语序乱、没卖点、易撞车，只适合铺货测款；主推款/利润款必须手写，点击率提升 30-50% 很常见
- **四步法**：核心词 → 关键属性 → 差异化卖点 → 技术参数
- **官方三大规范**：① ≤255 字符（建议 120-200）② 首字母大写、格式整洁 ③ 仅俄语/英语/数字（禁中文、emoji、特殊符号）
- [ ] 标题自查 5 条：前3词是核心大词 / 含型号规格颜色等属性 / 至少1个差异化卖点 / 字符 120-200 / 无堆词·全大写·乱符号

## 4. 选品与上架（V4第6集 / V5第7集）
- [ ] 测款阶段一律**独立单品链接**，少碰多变体（变体操作笨重、拖累测款、数据混）
- [ ] 仅当"单品已稳出单"或"尺码/颜色是购买核心"时才用变体
- [ ] 选品用**后台免费工具**（商品 → Ozon上的商品）：28天 / 二级三级内幕 / 价格≥2000卢布（高客单卡6000）/ 只看跨境店可上架
- [ ] 潜力款标准：动态涨幅≥50% + 单量 5-50 单 + 三转化率达标
- [ ] **不买付费选品工具**，先把免费逻辑跑通

## 5. 履约红利（V8 第10集 · 8万自提点改迷你仓）
- 履约网分布式变革：跨境卖家获**时效红利 + 成本优化**
- [ ] 评估 FBS 微仓铺货：**先测后铺**（选 2-3 个爆款 SKU 先试 1-2 个城市）、盯紧数据、用好时差

## 6. 工具效率（V9 第11集 · 国内加速线路）
- [ ] 切到**国内加速线路**：后台访问提速、ERP/API 对接更稳、运费计算器/帮助文档/物流查询同步适配
- [ ] 切换时**重新验证账号**，避免新旧入口同时操作冲突
- [ ] 原有店铺直接可用，零成本上手

## 7. 认知与自查（V2第4集 / V3第5集）
- [ ] 保证金 = **品牌认证徽章**的押金（可选），非店铺收费；不申请认证一分不交
- [ ] 不出单先自查 12 件事：主图详情/数据/细节优化/精准广告/关键词/搜索排名/选品/起店权重/差评处理/流量入口/售后数据/日常巡检

## 8. 建议周节奏（可直接排进日历）
- **周一**：§2 开关巡检 + §3 标题自查
- **周二~周四**：上新用单品链接（§4）；补属性冲内容相关性（§1-P0）；盯 FBO 占比（§1-P1）
- **周五**：数据复盘（销售/加购/转化/评分），评履约红利动作（§5）
- **持续**：评分守 4.5+（§1-P2）；切加速线路保 API 稳定（§6）
