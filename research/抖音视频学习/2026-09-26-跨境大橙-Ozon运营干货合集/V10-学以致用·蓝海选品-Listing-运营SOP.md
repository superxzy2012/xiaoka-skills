# V10-学以致用｜蓝海 Ozon 经营 SOP（选品 · Listing · 运营）

> 适用：深圳市蓝海世纪科技有限公司（Ozon 跨境店）
> 来源：跨境大橙《Ozon运营·干货合集》第3~11集（每条标注出处集数）
> 用法：作为日常经营的操作手册，配合 [[V0-蓝海Ozon落地清单]] 勾选执行。

## 0. 总原则（先定调）

1. **价格不是排名主因**——权重只占约 10%，别死磕最低价（V1）
2. **追利润，不追单量**——爆单但每单亏钱=搬砖，选品先卡利润（V5/V1）
3. **数据驱动，不靠感觉**——用点击率选图、按利润定价、看供需差选品（V1）
4. **先守现金流，再谈赚钱**——先把后台扣费开关关掉（V6）
5. **先合规，再精细化**——平台现在只看"精细化+合规+稳数据"（V3）

## 1. 选品 SOP

### 1.1 渠道与参数（用后台免费工具，不买付费工具 · V5）
后台 → 商品 → **"Ozon上的商品"**，固定 5 个参数：
| 参数 | 设定 | 理由 |
|------|------|------|
| 时间 | **28 天** | 过滤短期波动/偶发促销，看稳定需求 |
| 内幕 | **二级/三级细分类目** | 越垂直越精准（如"家具"→"抽屉柜/橱柜"） |
| 价格区间 | **下限 2000 卢布**，高客单**卡 6000 卢布** | 避开低价内卷，留利润空间 |
| 产品类型 | 只选**能勾选的**（跨境店可上架） | 不可勾选=FBO/本土店，上不了 |
| 数据维度 | 动态指数 + 单量 + **三个转化率** | 判断潜力与可卖性 |

### 1.2 潜力款筛选公式（V5）
> **动态涨幅 ≥ 50% + 单量 5~50 单 + 三个转化率达标** → 刚上不久的潜力新款、爆发前夕，跟进成功率最高。

### 1.3 利润与竞争门槛（V1 / V4）
- **毛利 ≥ 30%**（低于 30% 连"快速收评价"都别开，V1）
- 避开**本土大卖扎堆**的赛道（服饰鞋等），先问自己"竞争优势在哪"（V4）
- 选品四看：**看需求（供需差）、看竞争、看利润、看供应链**（V3）

### 1.4 上架形态：单品优先（V4）
- **测款阶段一律做独立单品链接**（变体操作笨重、拖累测款、数据混）
- 仅当"单品已稳出单"或"尺码/颜色是购买核心"时才上变体

### 1.5 选品决策清单（逐条打勾）
- [ ] 来自后台免费工具、28天/细分内幕/≥2000卢布
- [ ] 动态涨幅≥50% 且 单量 5-50 单
- [ ] 毛利率 ≥ 30%，能覆盖物流+推广
- [ ] 不是本土大卖垄断赛道，或有差异化点
- [ ] 供应链稳定、可小批量测
- [ ] 决定用**独立单品链接**上架

## 2. Listing SOP

### 2.1 标题（主推款必须**手写**，V7）
- **一秒三分**：1 秒内让买家看懂——这是什么 / 是不是我要的型号 / 有什么不同
- **四步法**：①核心词（搜索量最大的）→ ②关键属性（品牌/型号/规格）→ ③差异化卖点（1-2个）→ ④技术参数（数字/规格）
- **框架**：`品牌 + 商品核心词 + 关键属性 + 技术参数`
- **官方规范**：≤255 字符（建议 120-200）；单词首字母大写；仅俄语/英语/数字
- **禁忌**：堆砌关键词（直接降权）、滥用全大写/符号、非规范语言

### 2.2 主图（点击率的生死线 · V1）
- **点击率 < 2% 的主图立即换**（作者实测换图 1.2%→3.5%，流量翻 3 倍）
- 做 **3 组 A/B**：卖点型 / 场景型 / 对比型
- 首图 = 核心卖点 + 场景，3 秒讲清"能解决什么问题"

### 2.3 详情页（转化率 · V1）
- 首屏 3 秒见核心卖点（别一上来堆参数）
- 加**场景图 / 细节图 / 对比图**
- 问答区埋 **5 个用户常问问题**，自问自答降低决策阻力

### 2.4 属性与关键词（内容相关性 30%，最大头 · V1）
- **属性字段能填全填**（颜色/尺寸/材质/用途，含场景词）——每个字段都在给算法打标签
- 标题前 3 词放核心大词，中间属性词，后面**长尾词/场景词**（长尾词转化率通常更高）

### 2.5 定价
- 利润导向，别死磕最低价（价格权重仅 ~10%，V1）
- 正常定价 + 适度折扣；只在"高于竞品池 80%"时才需要动价

### 2.6 上架自查清单
- [ ] 标题：前3词核心大词 / 含型号规格 / 有差异化卖点 / 120-200字符 / 无堆词·全大写·乱符号
- [ ] 主图：点击率≥2%，首图讲清卖点（备 3 组 A/B）
- [ ] 详情页：首屏3秒见卖点 + 场景/细节/对比图 + 问答区5问
- [ ] 属性字段全填（含场景词）
- [ ] 类目放对（错放=判不相关）
- [ ] 独立单品链接（非变体）

## 3. 运营 SOP

### 3.1 排名 5 维度周优化（V1）
| 维度 | 权重 | 每周动作 |
|------|------|---------|
| 内容相关性 | 30% | 补属性、优化标题关键词 |
| 销售转化率 | 30% | 测主图（点击率）、优化详情首屏、引导加购（目标 8%+） |
| 用户行为 | 15% | 引导收藏/加购/分享，做复购 |
| 物流履约 | 15% | 盯 FBO 占比、发货时效（目标 <24h）、取消率（<3%） |
| 评价+价格 | 10% | 守 4.5 星、及时处理差评 |

### 3.2 成本风控：每周一巡检 4 个开关（V6）
- [ ] 好评返现 / 积分活动
- [ ] Premium 会员自动续费
- [ ] 自动促销（自动打折）
- [ ] 好评置顶（按天收费）
> 每周 10-20 分钟，事前排查 > 事后捶胸。

### 3.3 不出单先自查 12 项（V3）
主图详情 / 数据分析 / 细节优化 / 精准广告 / 关键词 / 搜索排名 / 选品 / 起店权重 / 差评处理 / 流量入口 / 售后数据 / 日常巡检。

### 3.4 履约与评价（V1 / V8）
- 能走 **FBO 走 FBO**（权重更高）；自发货把发货压到 24h 内
- 取消率 >5% 降权、>10% 可能限流 → 守 3% 以下
- 评分守 **4.5+**；慎开"快速收评价"；发货前质检+感谢卡挡差评
- 评估 **FBS 微仓**红利：先选 2-3 个爆款 SKU 试 1-2 个城市，先测后铺（V8）

### 3.5 数据节奏（V1）
- **每天 15 分钟**看核心数据；**每周**一次完整数据复盘；**每月**一次竞品分析
- 用 **7 天排名提升计划**（D1标题/D2主图/D3物流评价/D4详情/D5广告测词/D6活动/D7复盘）滚动作战（V1）

### 3.6 效率与工具（V9）
- 切**国内加速线路**：后台/API/ERP 更稳更快，零成本

---

## 4. 节奏与路线图

**每周固定动作**
- 周一：扣费开关巡检（3.2）+ 标题/主图自查（2.6）
- 周二~周四：选品+上架（§1、§2），补属性冲内容相关性
- 周五：数据复盘 + 履约动作评估
- 持续：守评分 4.5+、切加速线路

**30 / 60 / 90 天**
- **30 天**：关掉 4 个扣费开关；现有 SKU 全部按 §2.6 重做标题+主图；切加速线路
- **60 天**：按 §1 跑通选品-上架-测款闭环；建立"点击率/加购率/转化率"数据看板
- **90 天**：沉淀 3-5 个稳定出单单品；评估 FBS 微仓红利；形成周复盘机制

## 5. 关键指标看板（KPI）
| 指标 | 目标 |
|------|------|
| 主图点击率 | >2%（追 3-5%） |
| 加购率 | ≥8%（追 18%） |
| 转化率 | 2-5% |
| 评分 | ≥4.5 星 |
| 取消率 | <3% |
| 平均发货 | <24h |
| 毛利率 | ≥30% |
| FBO 占比 | 越高越好 |
