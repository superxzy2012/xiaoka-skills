## 5 个 Skill 详解

### ① SpecFirst — 先问清需求，再开始干
- **工作流拆解**：CAUSE 不是 AI 不够聪明 → SPEC 是一开始需求没清楚 → ACTION 先反问，再开干
- **口播关键**：很多任务做不好，不是 AI 不够聪明，而是一开始连需求都没搞清楚。它不会拿到任务马上开干，而是**先反过来问你**：要解决什么问题？对谁用？想要什么结果？有什么限制？—— **先把需求问清楚再开始干**。

### ② Summerize（画面作 SAMURAI）— 把资料整理成能用的东西
- **工作流拆解**：SOURCE 网页 / PDF / 视频 / 播客 → SAVE 不用自己慢慢翻 → OUTPUT 提取重点和关键信息
- **口播关键**：网页、PDF、视频、播客，一堆资料不用自己慢慢翻。直接丢给它，它会**提取重点、关键数据和核心信息**，把一堆零散内容整理成后面真正能用的东西。
- （注：画面标题"砍刀"武士 SAMURAI，口播说"Summerize"——是同音字/同义翻译差异，按画面为准是 SAMURAI 风格命名，按口播为准是"摘要"。）

### ③ Prompt Optimizer — 把模糊表达变成清晰任务
- **工作流拆解**：INPUT 帮我做个页面 → RISK 需求太模糊 → FIX 整理成清晰任务
- **口播关键**：比如你只说一句"帮我做个页面"，这个需求太模糊，AI 很容易自己乱猜。Prompt Optimizer 会把这种模糊表达**重新整理成清晰任务**，让后面的 AI 知道到底要做什么、做到什么程度。

### ④ Show Options — 先选方向，再继续做
- **工作流拆解**：MISTAKE 别先要最终答案 → COST 方向错了会返工 → CHOICE 先给方案再选择
- **口播关键**：很多人用 AI 最大的问题，就是一上来让它直接给最终答案。方向一旦错了，后面全得返工。这个 Skill 会**先给你几个不同方案，先选方向，再让它继续往下做**。—— **先选对，再做细，效率会高很多**。

### ⑤ UR Router（口播 UI Router）— 判断任务，再自动分工
- **工作流拆解**：READ 判断现在是什么任务 → ROUTE 决定交给哪个 Skill → CHAIN 把前面几个串起来
- **口播关键**：**这个才是把前面几个 Skill 真正串起来的关键**。它会先判断你现在是什么任务，再决定应该交给哪个 Skill 去处理。

## 把 5 个 Skill 串起来 = FULL CHAIN

口播原话：
> 问清需求 → 整理资料 → 明确任务 → 选择方向 → 自动分工。

这就是 5 个 Skill 串起来后的完整工作流：
1. **SpecFirst** 问清需求（解决什么、对谁、什么结果、什么限制）
2. **Summerize** 整理资料（网页/PDF/视频/播客 → 重点+关键数据）
3. **Prompt Optimizer** 明确任务（模糊表达 → 清晰任务）
4. **Show Options** 选择方向（先给方案、再选、再做细）
5. **UR Router** 自动分工（判断任务类型 → 路由到对应 Skill 接力跑）
