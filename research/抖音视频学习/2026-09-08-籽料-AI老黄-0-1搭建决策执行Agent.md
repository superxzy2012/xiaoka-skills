# 手把手带你从 0-1 搭建一个决策执行 Agent

> 来源：抖音 @籽料👀主页简介-Ai老黄  |  1m42s 教学  |  置信度 A

## 摘要
**6 步用 Python + Ollama 搭一个能"自主决策 + 调工具执行"任务**的本地 AI Agent。
教程使用 Ollama 拉 Mistral 模型做底座，自己写模型层 + 工具层 + Agent 主体。
**重点**：这是个**纯本地**的决策 Agent（不依赖 OpenAI / Anthropic API）。

## 6 步流程

| 步骤 | 内容 | 关键命令 / 概念 |
|---|---|---|
| **第 1 步** | 搭建运行环境 | `pip install -r requirements.txt` + `ollama pull <模型名>` |
| **第 2 步** | 定义模型层 | 对接 Ollama Mistral，封装模型调用逻辑 |
| **第 3 步** | 为 Agent 创建专属工具 | 根据任务需求开发功能工具（agent 完成任务的核心基础）|
| **第 4 步** | 构建工具箱 | 把所有工具统一整合管理，方便 agent 随时调取 |
| **第 5 步** | 编写 Agent 主体类 | **核心环节**——整合模型 + 工具箱，实现决策逻辑、工具选择、任务调度 |
| **第 6 步** | 运行 Agent | 启动程序，输入任务指令，agent 自主思考 + 选工具 + 执行 |

## 详细分析

### 第 1 步：环境搭建
```bash
# Python 依赖
pip install -r requirements.txt

# Ollama 本地大模型
ollama pull mistral
# 或其它推荐模型（取决于 RAM）：
#   ollama pull llama3.1:8b   # 6-8GB RAM
#   ollama pull qwen2.5:7b    # 工具调用好
#   ollama pull mistral-nemo  # 12B 工具调用强

# 验证
ollama list
```

**⚠️ 模型选择关键**：不是所有模型都能调工具。Mistral Nemo / Llama 3.1 / Command-R+ / Qwen2.5/Qwen3 是可靠选择。

### 第 2 步：模型层（Ollama 集成）
```python
import ollama

class Model:
    def __init__(self, model_name="mistral"):
        self.model_name = model_name

    def chat(self, messages, tools=None):
        response = ollama.chat(
            model=self.model_name,
            messages=messages,
            tools=tools  # tool definitions
        )
        return response
```

**关键点**：
- Ollama 0.5.2+ 原生支持 `tools` 字段
- 模型自动判断要不要调工具
- `ollama.chat()` 返回的 `response['message']` 包含 `tool_calls`

**工具本质**：函数 + 描述（让 LLM 知道何时用）

### 第 4 步：工具箱
```python
class ToolBox:
    def __init__(self):
        self.tools = {
            "search_web": search_web,
            "calculator": calculator,
            # ... 其它工具
        }

    def get_tool(self, name):
        return self.tools.get(name)

    def list_tools(self):
        return list(self.tools.keys())
```

**为啥要工具箱**：
- ✅ 统一管理（注册/反注册/版本）
- ✅ 描述标准化（给 LLM 看）
- ✅ 调用日志（debug）
- ✅ 权限控制（防 agent 调危险工具）

### 第 5 步：Agent 主体类（核心）
```python
class DecisionAgent:
    def __init__(self, model: Model, toolbox: ToolBox):
        self.model = model
        self.toolbox = toolbox
        self.memory = []  # 对话历史

    def run(self, user_input: str, max_iterations: int = 10):
        """ReAct 循环：观察 → 思考 → 行动 → 重复"""
        self.memory.append({"role": "user", "content": user_input})

        for i in range(max_iterations):
            # 1. 调模型（可能返回 tool_calls）
            response = self.model.chat(
                self.memory,
                tools=self._get_tool_schemas()
            )
            msg = response['message']
            self.memory.append(msg)

            # 2. 如果没工具调用 → 完成
            if not msg.get('tool_calls'):
                return msg['content']

            # 3. 执行工具
            for tool_call in msg['tool_calls']:
                tool_name = tool_call['function']['name']
                tool_args = tool_call['function']['arguments']
                result = self.toolbox.get_tool(tool_name)(**tool_args)
                self.memory.append({
                    "role": "tool",
                    "content": str(result)
                })

        return "达到最大迭代次数"
```

**核心能力**：
- 🎯 **决策逻辑** —— 用 LLM 判断下一步该干嘛
- 🔧 **工具选择** —— 让 LLM 选合适的工具
- 📋 **任务调度** —— 多步任务自动推进
- 🧠 **记忆** —— 保留历史 context

### 第 6 步：运行
```python

toolbox = ToolBox()
agent = DecisionAgent(model, toolbox)

# 用

```

## BOSS 价值评估

✅ **强推荐（自学 + 内部工具）**：
- **零 API 成本** —— 用 Ollama 本地跑，断网也能用
- **隐私友好** —— 数据不出本机
- **完全可控** —— 工具白名单、决策日志都能加
- **M4 Mac mini 跑得动** —— Mistral 7B / Qwen 8B

⚠️ **限制**：
- **小模型多步推理弱** —— 7B 模型 2-3 步就容易乱
- **工具描述要写好** —— 模型对工具描述很敏感
- **context 不长** —— 长任务需要额外压缩机制
