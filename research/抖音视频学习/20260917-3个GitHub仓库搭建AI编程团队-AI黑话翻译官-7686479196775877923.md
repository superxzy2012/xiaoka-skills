# 3 个 GitHub 仓库，搭建一整支 AI 编程团队

> 作者：**AI黑话翻译官**｜来源：[抖音原视频](https://www.douyin.com/video/7686479【手机号】3)｜28.7 秒
> 思路：把 Codex、Claude Code 等多个 coding agent 组织成一支"团队"——一个统一调度界面、一个能长跑/派子任务的执行体、一个实时监控看板。

## 三个仓库（均已逐一核验真实存在，2026-09-17）

| # | 仓库 | 定位 | 视频标注⭐ | License |
|---|---|---|---|---|
| 1 | **[stablyai/orca](https://github.com/stablyai/orca)** | **多 Agent 并行的 ADE（Agent Development Environment）**——把 Codex、Claude Code 等多个 agent 放进一个界面同时处理不同任务；用你自己的订阅跑任意 coding agent；支持桌面/移动端/远程 runtime | 56.5K | MIT |
| 2 | **[PrimeIntellect-ai/prime-agent](https://github.com/PrimeIntellect-ai/prime-agent)** | **自我改进的 RLM agent**，面向 coding 工作流和**长时间运行的自主任务**；可调用子 agent（subagent），交代任务后在后台持续推进；有 arXiv 论文（arXiv:2608.23552） | 19K | 开源 |
| 3 | **[herdrdev/herdr](https://github.com/herdrdev/herdr)** | **coding agents 的运行时/监控层（herdr.dev）**——实时显示每个 agent 状态：谁在工作、谁空闲、谁卡住，一眼看清；Rust 编写，支持 Homebrew 安装，有中文文档 | 33.3K | Apache-2.0 |

## 三者如何组成"一支团队"
- **Orca = 统一指挥台/IDE**：多 agent 同屏，任务分发给不同 agent 并行（写代码 / FIX 改 BUG / RUN 跑流程）。
- **Prime Agent = 能干长任务的主力**：RLM（递归语言模型）把上下文当变量、把子 agent 当函数调用，任务交代后后台长跑、自动派子任务。
- **Herdr = 运维看板/运行时**：监控整支 agent 舰队的实时状态与调度。
- 合起来：**拆任务 → 多 AI 并行写代码/改 bug/跑流程 → 看板盯状态**，效率拉满。
