## 核心升级：Tool Routing 按需加载机制

### 问题背景
以前 Agent 使用工具，必须**加载全部工具信息**（名称、功能介绍、参数说明）。每接入一个新工具，这些信息就会不断占用上下文，token 消耗越来越高。

> **比喻**：
> - 以前 = 厨师把**满汉全席全部端上来**让你挑一道菜
> - 现在 = 先告诉厨师需求，再去**菜单里找对应做法**

### 解决方案
**AI 不再提前加载所有工具，而是在需要时搜索对应工具。**

效果：Agent 拥有更多能力的同时，**不会因为工具增加而消耗大量 token**。

## 三大升级点

| # | 升级 | 说明 | 价值 |
|---|------|------|------|
| **1** | **Tool Routing 机制** | 工具按需搜索加载，不再全量塞入上下文 | 🌟🌟🌟🌟🌟 解决 token 爆炸核心问题 |
| **2** | **内置更多服务连接** | 内置 Cloudflare、Datadog、Metabase 等服务连接能力 | 🌟🌟🌟🌟 降低接入成本，覆盖更多真实场景 |
| **3** | **长期运行体验优化** | Cron 定时任务增加故障确认、外部结果增加缓存、桌面端交互优化 | 🌟🌟🌟🌟 提升长期稳定性 |

### 升级一：Tool Routing（最核心）
- 解决「工具数量增加 → token 消耗线性增长」的问题
- 从「全量加载」变为「按需检索」
- 是 Agent 平台走向规模化的关键基础设施

### 升级二：内置服务连接
- 新增内置：Cloudflare / Datadog / Metabase 等
- 以前：自己找工具 + 配置连接
- 现在：Hermes 准备好了连接入口，Agent 直接调用
- 意义：从「AI 聊天工具」走向「真实工作场景的 Agent 平台」

### 升级三：长期运行稳定性
- **Cron 定时任务**：增加故障确认机制
- **外部结果缓存**：减少重复调用，提升速度 + 降低成本
- **桌面端交互优化**：日常使用更顺滑
- 意义：从「让 Agent 完成任务」→「让 Agent 更可靠地长期工作」
