# Token节省神器 · 子栩「左脑」Skill 演示

> [!abstract] 一句话摘要
> 子栩做了一款 WorkBuddy 桌面端的「左脑」Skill，把对话做成**本地长期记忆 + 图关联 + 实时纠错 + Token 监测悬浮窗**，核心卖点是**让普通用户随时看到左脑帮自己省了多少 token / 多少钱**，已在评论区开放索取（非免费）。

## 核心要点

- **产品形态**：WorkBuddy 桌面端 v1.24.7 的一个 Skill，安装路径 `C:/Users/子栩/.workbuddy/skills/左脑/ToKen监测助手.py`（V0.02）。
- **三大核心价值**（WorkBuddy 自己回答）：
  1. **本地长期记忆** — 学过的就不丢，下次直接召回
  2. **上下文关联** — 把零散对话串成知识图谱
  3. **降本（token 减缩）** — 本地化把云端调用压下去
- **「/左脑 auto on」自动联动**（开启后每次对话被自动增强）：
  - 自动纠错：「反许预警」→「反诈预警」实时修正
  - 自动学习：把对话关键词写进本地记忆库
  - 自动推荐：当前话题相关历史记忆主动提醒
- **记忆与检索（跨会话持久化）**：
  - 学会就记住 → 纯本地哈希表，毫秒级查询
  - 图扩散搜索 → BFS 图算法（如「天渣系统」自动关联「河图洛书」反诈预警）
  - 上下文消歧 → 「苹果是手机还是水果」按语境判断
  - 智能纠错 → 中英拼音输入错误率高也能秒纠正
- **隐私完全本地化**：所有数据存本地 `data/` 目录，零云端。
- **零额外成本**：不需付费 API、不需 GPU、纯 Python 标准库、一次买断永久用。
- **数据分析帮你做决策**：长文草/报告/标书丢进去自动解析关键字段（举例：投标文件提取 预算 500 万 / 工期 180 天 / 评分标准 7 项 / 资质要求 3 类）。
