# 网安简历项目含金量分级：垃圾项目删掉、王炸项目这样写

> [!abstract] 摘要
> 作者转行时踩过坑（半页练习项目投几十份简历零面试），换掉项目后一周拿 5 个 offer。基于面过 20 多场 + 当两年面试官的经验，给出网安 HR 选项目的底层逻辑：项目按含金量分三类，配写法技巧与两个雷区。

## 要点

### HR 的判断标准
- **网安岗招你是来干活的，不是让你来学习的**——所有没有落地结果、没有产出证明的项目全是无效项目，写了反而减分。

### 项目含金量三类分级
1. **垃圾项目（直接删掉）**：所有跟着教程一步一步做、没有任何自己思考和产出的纯练习项目——搭靶场、基础工具使用演示、跟教程做漏洞复现但没写复现报告。练习不是没用，而是写在简历上毫无竞争力（招实习生时 10 份简历 8 份写"搭建 DVWA 靶场"）。

2. **标准加分项目（写了至少拿 3 个面试邀请）**：
   - **众测实战项目**：不用挖高危，哪怕挖了 3 个低危验证码逻辑漏洞/信息泄漏拿 1800 元赏金，也比 10 个靶场项目有用。写法示例："参与某电商平台众测项目，独立挖掘未授权访问、验证码逻辑绕过漏洞共三个，获得赏金合计 1800 元，漏洞均已被厂商确认修复"——有具体场景、具体结果、可查的平台记录。
   - **CNVD / CNNVD 漏洞报送证书**：对在校生尤其友好，不需要多强技术，找合规靶场或有授权的小站点测漏洞（中低危即可），报送成功就能拿官方证书；国企/央企网安岗认可度极高，同等条件直接优先面试。新手努力 1-3 个月就能出成果。

3. **王炸项目（写上去 90% 概率进面，薪资至少多谈 2000）**——核心是证明技术深度与研究能力，甩开 90% 竞争者：
   - **独立复现 CVE 高危漏洞 + 完整复现报告**（甚至提交过 PoC）：不用挖新 CVE，找近一年公开的中高危 CVE，自己搭环境复现，写清复现步骤、影响范围、修复方案；报告放 GitHub 或博客，简历附链接，HR 一看就知道有自主研究能力。
   - **有授权的真实渗透测试项目**：如给学校或亲戚开的小公司做全站渗透测试，拿正式授权书，输出完整渗透测试报告，写清发现多少漏洞、给了什么修复建议——真实度极高，比所有虚拟项目都管用。

### 写简历技巧
- 别再写"我掌握了 XX 工具 / 学习了 XX 技术"。
- 按 **场景 + 动作 + 结果 + 证明** 的结构写：不写"我会用 Burp Suite 挖漏洞"，要写"使用 Burp Suite 对某授权站点进行渗透测试，独立挖掘逻辑漏洞……"。

### 两个雷区
1. **不要编造项目**：网安面试官全是实战出来的，有没有真做过两三个问题就能问出来（如"提交漏洞要付什么材料？厂商审核标准是什么？"答不上来直接 out）。
2. **不要写没有授权的测试项目**：哪怕真测过公开站点也别写，HR 会觉得你合规意识差、招进来风险太高；所有项目一定要强调是靶场环境、有正式授权。
