# Blueprint — 用自然语言生成全套造物方案的 AI 硬件设计网站

> [!abstract] 摘要
> 一个叫 **Blueprint**（blueprint.am）的网站，你用一句话描述想造的东西，它一分钟内生成**完整的硬件设计包**：物料清单（带采购链接）、接线图、3D 机械渲染、分步组装指南。被称为「硬件界的 Claude Code」，适合 Arduino / 树莓派 / DIY 创客。

## 核心功能

用自然语言输入想法 → 一分钟内生成全套设计包：

| 输出 | 说明 |
|------|------|
| 📋 **BOM 物料清单** | 完整零件清单，带采购链接 |
| 🔌 **接线图 / 电路图** | 电路连线示意图 |
| 🎨 **3D 机械渲染** | 外观模型示意图 |
| 📖 **分步组装教程** | 一步一步的详细安装指南 |
| 🔧 **所需工具清单** | 3D打印机、扳手、螺丝刀等 |

## 网站背景

- **官网**：https://blueprint.am
- **创始人**：David Feldt（11 年级打工攒钱买第一套 Arduino 套件的硬件爱好者）
- **定位**："The Claude Code for Electronics"（电子工程界的 Claude Code）
- **目标**：激励和培养下一代硬件构建者，让造物不再有门槛
- **口号**：Stop dreaming. Start building.

> 典型输入示例：
> "我想要一个土壤湿度传感器，土壤干燥时触发蜂鸣器和 LED"
> → Blueprint 生成原理图、元件列表（传感器、蜂鸣器、电阻、Arduino Nano）、接线步骤
