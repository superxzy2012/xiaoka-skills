# reverse-skill：AI 全自动逆向分析技能包

> 来源：抖音视频（约 5'52"）｜入库日期 2026-09-11｜置信度 B（口播有方言杂音，画面OCR清晰）

## 🎯 核心观点

GitHub 项目 **reverse-skill**（逆向技能路由包，约 12 万星，v1.0.1，MIT 协议）把原本要啃几年的爬虫逆向、渗透技术打包成一组 Skills + MCP，配合 AI（Claude/Codex 类 CLI）可以**一句话自动完成定位加密参数、断点调试、补环境、JS 还原**等传统逆向重活。视频演示了用它在拼多多移动端电商数据采集中全自动搞定加密/验证码的全过程。

## 📋 主要内容

| 环节 | 内容 |
|---|---|
| 传统痛点 | 手动抓包→分析加密字段→下断点定位生成位置→补环境→扣代码还原，任务量大（演示中补环境代码数千行） |
| 项目 | reverse-skill：Cybersecurity Skills Router·逆向技能路由包，GitHub 约 12w star，release v1.0.1，MIT |
| 环境配置① | 安装"CS位置"（类文件管理器工具）→ 从 CLIP/压缩包安装 Skills（.jsw 格式） |
| 环境配置② | MCP 配置：复制 JSW 配置文件→添加 MCP（演示命名 firm.tools）→名字冲突时改名重加 |
| 实战演示 | 以拼多多（mobile.pinduoduo.com）电商数据采集为例：AI 全自动完成加密参数定位与还原，替代手动 VPS/WSM/JSVMP 分析 |
| 配套项目 | ChromeDevTools/chrome-devtools-mcp（github.com/ChromeDevTools/chrome-devtools-mcp）、WhiteNightShadow/hellojs |
| 效果 | "一句话"让 AI 跑完整个逆向流程，生成的代码直接运行无报错，电商数据正常返回 |

## 💡 关键洞察

1. **逆向工程正在被 AI 技能包"平民化"**——加密、验证码、JSVMP 补环境这类高门槛活，现在 skills+MCP 路由后 AI 可以自动完成，安全与反爬对抗的门槛两端同时被拉低。
2. **Skills + MCP 双件套是部署范式**：Skills 管知识/流程路由，MCP 管工具执行，两者都是"配置文件一复制即可装"的轻量形态。
3. 对我们 13BIT 的价值：电商数据采集（拼多多/京东等）遇到加密反爬时，可评估此技能包替代人工补环境；需先过 SkillSpector 静态扫描再考虑引入。
