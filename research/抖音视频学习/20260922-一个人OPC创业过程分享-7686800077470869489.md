## 一句话总结

从**业务端（先有客户）**而非公司实体切入的一人 OPC 路径：先靠行业痛点积累意向客户 → 拿免费办公场地/创业园区 → 用 AI+Agent 搭自动化工作流降本 → 控制客户数量在 10–20 家保质量，小而美跑通。

## 三步 SOP（核心方法论）

### 第一步：业务端先入——先找客户，再注册公司
- **切入点**：从自己熟悉的行业（企业出海 + 电商）里挖痛点——传统企业想出海，没渠道、没方式、没人，自建团队成本极高。
- **关键动作**：在成立公司**之前**已有 2–3 个意向客户（最终 5 个里有一个来自老客户关系）。
- **反常识**：和大多数 OPC 先注册公司不同，他是先有客户再补主体。

### 第二步：办公场所——保证"上班状态"
- 一线城市 → 图书馆等免费场所
- 二三线城市 → 创业园区（面试门槛低，有项目即可），园区代办公司注册 + 工账开户 + 财税服务
- **理由**：没有稳定办公场所 = 没有正常工作状态，输出质量会掉。

### 第三步：用 AI + Agent 搭自动化工作流（降本核心）
- 服务内容包括：知识库搭建、关键词优化、投流、全渠道工作
- 一个人做很痛苦 → **用 Agent 搭整条调优工作流**，覆盖重复性日常工作
- **最重的成本是沟通**：搞清楚客户真实诉求、投流方向、要铺的渠道——这部分时间占大头
- 分工：自己只对接前端，找**一个小伙伴做后端交付**；客户不能多，保证服务质量。

## 为什么选 OPC 赛道

- 小而美：规模不必大，不跟大企业抢市场
- **长期稳定合作**：服务到位 = 客户长期续约，不用反复做痛苦的获客开发
- 个人现金流 + 公司开支都可控
