# 零基础漏洞挖掘开篇课：价值认知与五大模块学习路线

> [!abstract] 摘要
> 一条"开篇课"性质的长视频：前半段讲清漏洞/挖洞概念、挖洞的双重价值（副业赚赏金 + 就业加分项）和整套课程的五大模块学习路线；后半段进入第一课实操——文件基础操作与压缩解压（Bandizip）。

## 要点

### 挖洞的价值
- **副业收入**：国内头部互联网公司（腾讯、阿里、字节等）都有自己的 SRC（安全应急响应中心），常年征集有效漏洞；按危害分低危/中危/高危/严重，单条奖金从几百元到十几万元不等。新手可从业务逻辑漏洞或低中危入手，熟练后每月挖几个赚几千块副业收入可行；作者本人本职之外利用下班/周末时间挖洞，月入几百到上千。
- **职业发展**：网安人才缺口大，渗透测试与漏洞挖掘是安全行业核心且需求广的技能；可走甲方安全工程师、渗透测试工程师、安全服务工程师、漏洞研究员等方向。招聘岗位常明确"有SRC漏洞提交经验优先"。
- **非科班友好**：网安重实战经验，挖洞成果与提交的漏洞证明就是最好的简历；非科班出身只要手里有实打实的成果，一样能拿到不错机会。

### 什么是漏洞 / 什么是挖洞
- **漏洞**：把网站/系统比作带安保的大楼——侧门没锁死、消防通道窗户可撬、门禁系统缺陷（过期卡能开门）等设计/实现/运维缺陷，让攻击者绕过正常权限规则非法访问、篡改数据甚至控制整个系统。只要是代码或业务流程，就难免有疏漏。
- **挖洞（漏洞挖掘）**：在获得合法授权前提下，用专业技术主动找出系统安全漏洞，提交给厂商或正规安全平台，帮助修复漏洞，同时获得赏金或荣誉。

### 五大模块学习路线
1. **计算机基础与 Web 基础（地基）**：不追求快，先补底层通信逻辑——HTML 网页基本结构、表单提交、浏览器与服务器通信（从输入网址到页面显示的完整过程）；安装虚拟机 + 部署 Kali Linux（自带几百种挖洞工具，等于搭好专业工作台）+ 过一遍常用命令。
2. **信息收集**：高手大半时间花在信息收集上。流程：域名注册信息（摸清主体）→ 扒子域名分站（主站防护严密时分站易突破）→ 端口扫描（看开放入口）→ 目录扫描（后台页面与隐藏文件）→ 指纹识别（判断程序与服务器系统）。
3. **经典 Web 通用漏洞（核心正餐）**：SQL 注入（把自定义查询指令插入数据库执行，可能脱库拿账号/管理员密码）、XSS 跨站脚本（往页面注入脚本，盗登录状态/诱导操作）、文件上传漏洞（传恶意脚本）、远程命令执行 RCE（操控服务器执行系统命令）。
4. **业务逻辑漏洞**：问题出在业务流程设计本身而非代码——支付环节未校验订单金额（100 元改 1 元也能下单）、优惠券未做领取限制（可无限重复领）。不需要深厚代码功底，捋顺业务流程+细心就能挖；厂商认可度高、赏金不低，最适合新手拿第一个成果。
5. **系统与软件层面漏洞**：网站前端代码严密时，可下沉到底层运行软件——中间件（Apache、Nginx、Tomcat）历史经典漏洞；Windows 系统级漏洞（永恒之蓝，利用得当可远程拿到对方电脑控制权）。吃透后挖洞范围从网页应用扩展到整个服务器乃至内网。

### 合规红线（底线）
- 所有攻击技术只能在两处实操：**自己搭建的本地靶场环境**、**已获明确书面授权的测试目标**；未经授权绝不能擅自扫描/测试任何外网网站、公共服务器或他人设备——越线即违法，后果自负。

### 第一课：文件基础操作
- 文件 = 电脑保存数据的形式（Word/Excel/PPT/图片/视频/脚本等），文件夹=收纳盒。
- 五个基本操作：**创建、复制（原处保留）、移动/剪切（原处消失）、重命名（内容不变）、删除（进回收站可还原）**。
- 压缩与解压：两个核心原因——减小体积（节省磁盘与传输时间）+ 方便管理（几十上百个零散文件打包成一个包）；常见格式 ZIP/RAR/7Z；推荐安装 **Bandizip**（免费版够用），压缩选"压缩为.zip/.7z"，解压选"解压到此处"或"解压到指定文件夹"。
