## ⚠️ 视频/帖没说的坑（比榜单本身重要）

1. **Remotion 不是无条件免费商用**：GitHub 标记 NOASSERTION（自定义条款）。Remotion 对**达到一定规模的公司（员工数/资金门槛）要求购买 Company License**，个人和小团队免费。拿去做商业产品前务必读它官网授权条款，别看到源码就当 MIT 用。
2. **blender-mcp 的归属**：帖里叫 blender-mcp，真仓是 `ahujasid/mcp-for-blender`，作者明确写「**Community plugin… Not affiliated with** Blender」——非官方插件；另一个 `scenario-labs/blender-plugin` 是 **GPL-3.0**（注意与 MIT 版别混）。
3. **这些大多是「AI Agent 技能/skill」不是独立软件**：第 1/2/3/6/9/10 名本质都是给 Claude Code / Codex / Cursor 这类编程 agent 用的**技能包或 MCP**，要在 agent 环境里跑，不是下载安装就能用的 GUI；帖把它们讲成「装进电脑就能跑」略简化。
4. **星数 ≠ 质量**：榜单里好几项是 2026 年这几个月才暴涨的新仓（星高但年轻），而 Remotion(2020 起)、Penpot 是成熟项目。生产用要结合「最后 push 时间 / issue 处理 / 是否单作者」判断，别只看星。
