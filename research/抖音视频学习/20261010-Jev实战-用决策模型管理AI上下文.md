# Jev 实战教程：用决策模型管理 AI 上下文

> [!abstract] 摘要
> Jev 这类决策模型，把"一个具体问题 + 可选答案 + 相关材料"交给它做选择/打分/判断，在判断任务上比通用大模型快得多。视频借 OceanBase 开源的 **PowerContext**，演示怎样把上下文管理中的两个环节——**选哪些记录进任务、方案是否符合项目规则**——变成 Jev 的判断任务，并给出上手最小路径。

## 一、Jev 是什么
- 输入三件套：**一个问题 + 答案范围（A/B 选择 / 评分 / 判断） + 相关材料**。
- 输出受约束的判断（如 `yes` / `no` / `abstain`），让判断"有问题、有范围、有依据"。
- 在判断类任务上效率远高于传统大模型（非自回归、单次前向）。

## 二、要解决的上下文管理难题
- 历史对话、项目规则、任务记录积累越多，越要决定**给模型看什么**。
- 两类典型失效：①内容与当前任务无关；②旧结论还在，但适用条件已变。
- 思路：把"哪些记录该进任务""一条新记忆有没有足够证据"变成**明确判断任务**，交决策模型辅助。

## 三、载体：PowerContext（OceanBase 开源）
- 仓库：`github.com/oceanbase/powercontext`（local-first，Apache-2.0）。
- 1.2.0 版本提供**接入决策模型的接口（Decision Model）与示例**。
- 保存对象：团队约定（规则）、当时的依据、原因/适用条件/来源——避免只留结论、下次重问原因。

## 四、两个决策介入位置（核心）

### 位置 1：材料选择（放什么进上下文）
- 官方发布材料含 **LocomoPlus 问答对照**：相同资料和任务，原有流程会查相关记录，加入 Jev 后**多一次"哪些内容更有助于回答当前问题"的判断**。
- 公布结果：问答准确率 **60.37% → 68.97%（+8.58 个百分点，相对提升约 14.2%）**。
- 🔴 **视频明确限定**：数字只对应这组问答评测，**不能当作写代码的证据**；具体项目提升多少须自己验证。

### 位置 2：方案检查（用规则核对生成方案）
- 接口 **Decision Model**：应用把"问题 + 待判断内容 + 项目证据"放进**同一次请求**；相关依据必须明确传入，模型才知道按什么规则判。
- **退款任务示例**（团队约定 vs 通用实现易跑偏）：
  - 不足一分钱的金额如何取证？备款是否沿用同一套规则？非法金额怎么处理？
  - 先把这些规则保存 → 准备任务时找回相关记录 → 让同一 coding agent 跑两次：
    - 一次只给当前要求；另一次额外提供已有项目规则。
    - 比较"加上项目背景后有什么变化"。
  - 两份方案交 **Jev 或 Leia 检查**"程序运行后是否做对"，再由**独立测试**核对；模型意见与测试结果分别保留。
- 结果写回项目记忆，下次能查到"当时按什么规则检查"。

## 五、配套工程能力
| 能力 | 要点 |
|---|---|
| 代码调查（实验性） | 提供"实现/使用处"线索与可核对依据；实际改动影响仍需结合测试 |
| 分析时效 | 查询时检查代码是否变化，分析过期要先更新再用 |
| 历史 vs 当前 | 历史记录与当前代码分析分开保存，分别核对 |
| 规则修订 | 支持修订已有规则；过时内容退出日常检索但历史保留 |
| 经验/技能 | "当时情况→采取行动→实际结果"一起留，审核后可查阅；稳定方法可导出为技能指引 |

## 六、接入面与交接
- 可接入 **Codex、Cloud Code 等 AI 工具**（在对应环境里查背景、存记忆）。
- 扩展 **ZCode 社区集成**，覆盖命令行（CLI）与 Windows 桌面。
- 中途换工具：准备**交接材料**——目标、已确认事实、阻碍、下一步；接手 agent 先看结论再核对当前情况；已调查内容留线索可续查。

## 七、推荐最小上手路径（视频结尾）
1. 选一个**手头真实任务**，找一条**已确认的业务规则**，把规则和依据保存下来。
2. 方案生成后，**增加一次检查**：让 Jev/Leia 按这条规则给意见；原 coding agent 照常用，实际结果再用测试验证。
3. 从这一次检查观察两件事：团队定的规则**有没有被带到模型面前**；决策模型**有没有按依据给出判断**。

## 关联到本机
- **Jev 决策能力本机已具备**：`typesafe-jev` 技能（TypeSafe API+SDK）；另有 `laya-decision-local`（本地离线决策，M4 实测可用）。
- PowerContext 与本机 Hermes 记忆体系理念一致（durable + project-scoped + 带来源/版本），可作为跨会话上下文的参考实现。
- "先存规则再找回 + 决策模型核对 + 独立测试"与 BOSS 要求的"看实测、防做未做"闭环一致。
