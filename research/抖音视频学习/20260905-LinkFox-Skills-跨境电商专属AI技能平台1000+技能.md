## 🛠 安装方式（已实测）

### CLI 安装（推荐）

```bash
# 1. 安装 CLI
npm install -g linkfoxskill

# 2. 初始化（安装电商技能搜索器）
linkfoxskill init --agents hermes-agent

# 3. 安装全部技能
linkfoxskill install-all --agents hermes-agent

# 4. 安装指定分组
linkfoxskill install-groups mpstats_ozon,1688_sourcing --agents hermes-agent

# 5. 搜索技能
linkfoxskill search "关键词"
```

支持的 Agent 包括：hermes-agent、openclaw、claude-code、codex、cursor、workbuddy 等 31 个。

## ⚙️ 工作原理

```
用户请求 → e-commerce-find-skills（路由搜索）
              ↓
         匹配对应 Skill（如 linkfox-mpstats-ozon）
              ↓
         调用 LinkFox API → 返回结构化数据
              ↓
         AI 分析解读 → 输出结论
```

**Skill 路由规则**：当用户问跨境电商相关问题时，优先用电商专用技能搜索器，找不到再回退到通用搜索。
