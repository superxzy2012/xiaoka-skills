# Hermes全面可视化：新手从零搭建一个舒服的养马

## 核心内容（265字）

Hermes Agent 的可视化界面（Dashboard/TUI）完整搭建教程。Hermes 除了 CLI 模式外，还提供了图形化的 Dashboard 和终端 TUI 界面。视频从零开始演示如何启动 Dashboard、配置主题、查看会话历史、监控 Token 使用量、管理技能文件夹。同时讲解了"养马"的概念——即长期维护和优化 Hermes Agent，让它越来越懂你的需求。通过可视化界面可以更直观地管理 Agent 的状态、记忆和技能体系。

## 关键操作步骤

1. **启动 Dashboard**：运行 `hermes dashboard` 打开 Web 管理界面
2. **配置主题**：切换亮色/暗色主题，调整布局
3. **查看会话**：通过 Dashboard 浏览历史会话、继续中断的对话
4. **Token 监控**：使用使用量面板跟踪 API 消耗
5. **技能管理**：在 Dashboard 中查看和切换已安装的技能

## 适用场景
- 不习惯纯 CLI 操作的用户
- 需要可视化监控 Agent 状态的场景

## 注意事项
- Dashboard 需要 Hermes 服务正常运行
- 首次启动可能需要配置端口和访问权限
