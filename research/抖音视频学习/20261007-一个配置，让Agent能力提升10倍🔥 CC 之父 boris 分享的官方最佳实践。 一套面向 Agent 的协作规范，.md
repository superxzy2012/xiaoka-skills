- **持续改进**：把踩的坑变成可复用经验
- **完成前验证**：原问题是什么？原有功能有没有受影响？技术检查 + 体验检查

## 🔍 回源核实（2026-10-07，官方 X 线程 + 公开资料）

**✅ 核实通过**——三层结构和「自主修复」都对应真实内容，不是编的。

Boris 本人的核心表述（公开采访）：
> "1. Almost always use Plan mode 2. Give Claude a way to verify its output 3. Hold the same bar for human and Claude code."

**⚠️ 「能力提升 10 倍」是营销词，无出处**。官方可查的数字是：
- 他个人 30 天 **259 个 PR / 497 次提交**，其中 80–90% 代码由 Claude Code 写
- 「2–3 倍质量提升」出自 "give Claude a way to verify its work" ——**有 agent 做验证**时才是 2–3x，**不是任何配置都能 10x**
- 5–10 个并行实例、15+ 实例同时跑（git worktree 隔离）

**⚠️ 「CC 之父」说法不准**：Boris Cherny 是 Claude Code 的创建者与负责人（Head of Claude Code），「之父」是中文自媒体的习惯说法，不是官方头衔。

**⚠️ 视频把 Boris 和 Claude Code 混称「CC」**，CC 在编程语境里通常指 Creative Commons（知识共享协议）或 Command & Control，两者都不是。
