# 网络安全三个月入门：四阶段保姆级学习路线

> [!abstract] 摘要
> 面向 15-35 岁零基础人群的保姆级网安入门路线：四阶段递进（打地基 → 学核心 → 练武器 → 上战场），三个月即可具备挖洞赚赏金的实战能力；同时点明最容易踩的坑（一上来就想"黑网站"、只学不练）与职业方向（红队/蓝队/安全开发）。

## 要点

### 四阶段路线（快速版）
1. **第一阶段·打牢基础**：吃透网络原理（TCP/IP、OSI 七层、HTTP/HTTPS 区别、数据包传输）；Windows/Linux 十大常用命令；三大核心工具（浏览器开发者工具、Nmap 端口扫描、Burp Suite 抓包改包）。
2. **第二阶段·聚焦传统 Web 漏洞**：按难度从信息泄漏 → SQL 注入 → XSS 跨站 → 文件上传 → 命令执行；其中**信息泄漏门槛最低，是新手最容易挖到的第一个漏洞**。
3. **第三阶段·突破逻辑漏洞**：当前 SRC 平台赏金最高、出现频率最多的漏洞类型；重点功课：越权访问、密码重置、支付漏洞。
4. **第四阶段·实战出师**：在补天、漏洞盒子、先知三大平台提交报告，写明**原理、复现步骤、危害程度、修复建议**，细节越充分通过率越高。

### 保姆级路线详解
- **打地基（最重要，很多人在这放弃）**：
  - 网络：TCP/IP、OSI 七层、HTTP/HTTPS、"像送快递先知道路怎么走"，这是通信兵基本功。
  - 系统：Linux 命令行练到"指哪打哪"（ls/cd/grep/查文件/看权限/配网络），因为全球 90% 服务器跑 Linux。
  - 语言：入门 Python 即可，能写自动化小脚本（如批量扫后台敏感目录）——"Python 是你手中的自动步枪，别拿着大刀上战场"。
- **学核心（Web 安全）**：APP/网站/小程序全是 Web 技术，是黑客攻击最频繁的地方；对标 OWASP Top 10——SQL 注入（骗数据库吐出不该给的数据）、XSS 跨站脚本（往网页塞恶意代码）、文件上传（传一句话木马=服务器归你管）。
- **练武器（三大神器）**：
  - **Burp Suite**：手术刀，拦截/篡改数据包（把商品价格 100 块改成 0.01 看服务器认不认）。
  - **Nmap**：雷达，扫端口/系统指纹。
  - **Metasploit (MSF)**：重武器，漏洞利用框架，集成成千上万攻击脚本，一键打过去拿权限。
- **上手干（别光看书看视频）**：靶场练手——DVWA、Pikachu、Sikil Labs；每个漏洞类型亲手复现一遍；打 CTF 比赛（"网安人的奥数"），被虐就是长得最快的时候。
- **上战场（SRC 挖洞）**：补天、漏洞盒子、EDU 教育 SRC，合法且有赏金；一开始挖不到别灰心，哪怕一个信息泄漏或小逻辑漏洞也是职业生涯第一桶金。
- **写报告至关重要**：逻辑清晰、排版工整的漏洞报告就是你的求职简历，"比什么证书都好使"。
- **职业方向**：红队、蓝队、安全开发；四阶段是所有方向的必经之路。
