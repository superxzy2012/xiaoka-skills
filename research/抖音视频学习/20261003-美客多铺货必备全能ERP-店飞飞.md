## 小丽补充（**非视频内容**，本人判断，待核实）

> 以下不属于视频实证，是我基于美客多 CBT 成本模型做的对接提醒，**接入前必须实测**。

- **「净收益」口径必须自己对账**：视频里单品净收益（如 $4.86 / ¥32.63）是**它自己算的**。我方 CBT 模型是 佣金 12–16% + 支付 3.5%+R$2 + 低价附加费（<R$79 收 R$6）+ **国际运费 ¥55/kg 且计费重 = max(实重+0.15, 长×宽×高÷6000)** + 退货 12% + 汇损 2%。**它是否把体积重与国际运费算进净收益，是能不能用的生死线**——旧模型只按实重算曾把透明收纳盒整类误判为可做（40L 体积重 12.9kg、运费 ¥710，必死）。
- **「免站点服务费 / 零隐形收费」需打折扣看**：其公告里明确出现过「新增亚马逊店铺站点服务费」「义乌仓地址变动」等，说明收费项会调。签约/充值前要拿到书面费率表。
- **「绑定官方密钥提升成功率」= 要交出店铺 API 凭据**。按本机资金红线：可以给它**运营类 API 权限**，但**收款账户凭证（连连/PingPong）绝不给**；美客多凭据前缀归 `ML_`。
- **合规性不能外包给 ERP**：它的敏感词/侵权检测显示「侵权 0 屏蔽 0 风险 0」，但我方**食品接触红线**、**UV 宣称禁写**、**`Marca = Sem marca`** 这些是平台级铁律，ERP 不会替我兜底，listing 仍须过我方质检。
- **与我方现状的关系**：我方 200 品 listing 已就绪、待 BOSS 拍板上架。若真要上 ERP 铺货，建议**先拿 5–10 个已定品做 pilot**，比对它算的净收益与我方模型是否一致，再决定放量。
