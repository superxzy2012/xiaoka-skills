# SRC挖洞入门课：平台怎么选、要不要先学编程

> [!abstract] 摘要
> 系列课共两节：①新手如何挑选适配自身的挖洞平台（公益 SRC → 企业 SRC 的进阶路线 + 合规红线）；②"零基础能不能挖到洞"——入门不要求先学编程，熟练三款核心工具、专攻三类低编程依赖漏洞即可起步。

## 要点

### 第一节：新手挖洞平台怎么选
- **第一步明确需求**：练手打基础 vs 冲奖金，两者相辅相成（技术强→奖金多，冲奖金→基础越来越好）。
- **新手优先"公益类平台"**：风险低、规则清晰、积累实战经验：
  - 补天（常驻公益板块公益SRC，有明确漏洞奖励标准，酷币 KB 可兑换商品）
  - EDU SRC（教育行业，挖学校/机构漏洞换证书，求职面试加分项）
  - 漏洞盒子（无常驻公益项目，自己找站提交；无酷币，有积分排名，排名靠前有现金奖励）
- **平台规则 = 法律红线 + 平台红线**（引《网络安全法》第27条）：禁止公开漏洞细节、越权验证完不得保存用户信息；违反任一条企业有权报警，守规则非常重要。
- **结合自身水平匹配难度**：新手别一上来冲互联网巨头自建 SRC（腾讯/百度/华为），资产庞大但难度高；从补天/漏洞盒子第三方项目入手，再进阶中高难度平台。
- **平台分类**：互联网巨头（腾讯/阿里/先知/百度，资产大奖金丰富）、金融机构（平安等，难度最高，但高危奖励可达几万，举例单项目 6 万）、电商等（难度中高适合进阶）。
- **腾讯奖励体系示例**：1 安全币 = 5 元；高质量报告奖额外 10-50 安全币；奖励公式 = 积分 × 贡献系数（核心资产严重漏洞 9×286≈2574 安全币 ≈ 1.2 万+元）。
- **成长福利**：EDU 证书求职展示、补天 KB 兑换、大厂高额赏金——既激励坚持也积累履历。
- **总结**：先易后难、合规前提下进行；公益 SRC 打基础熟规则，再逐步进阶企业 SRC；选平台不盲目追高、偏差不要太大（技能不够硬上平安 SRC 挖不出东西）。

### 第二节：挖洞入门前要不要先学编程
- **结论**：编程不是入门必选项，但会编程能走得更远、看得更深。
- **入门只需熟练三款工具**：
  1. **Burp Suite**（核心中的核心，其他都是辅助）：三大功能点 = 代理 + Intruder + Repeater；插件商城生态强，"工具上必先利其器"。
  2. **dirsearch / 御剑**：扫描网站敏感文件、排查信息泄漏/接口泄漏。
  3. **子域名挖掘工具**：目标无头绪时扩大挖洞范围找突破口。
- **三类"编程依赖低、产出率高、正反馈强"的漏洞**：
  1. **业务逻辑洞**：任意用户密码重置、任意用户登录、优惠券叠加等；SRC 占比 50% 以上，奖励不低（作者案例：某平台任意用户登录严重漏洞赏金 1000 元）。
  2. **信息泄露洞**：dirsearch/御剑自动化扫隐藏目录文件，可能翻到电话号码、姓名、备份文件中的用户名密码。
  3. **弱口令洞**：admin/123456、root/password 等；用 Burp 爆破功能自动化批量测试，提前收集设备默认弱口令清单效率更高。
  - 这类漏洞考验的是**细心、逻辑、工具熟练度**，不需要多少编程知识。
- **编程的进阶价值**：代码审计（挖通用型漏洞，如 CNVD 原创证书）；理解漏洞底层原理（如 SQL 注入 = 参数直接拼接进 SQL 语句未过滤）。
- **不懂代码也能挖高危洞**（用现成工具自动化攻击如 SQL 注入），但敏感度低、容易错过深层利用机会、赏金也少。
- **入门阶段重点**：会熟练用几款核心工具 + 建立找漏洞的基本思路；进阶时再补编程，亡羊补牢为时未晚。
- **核心原则**：先行动起来，在实战中学习——"在干中学、在学中干"；工具和思路成为本能后，编程就是下一步要征服的高地。
