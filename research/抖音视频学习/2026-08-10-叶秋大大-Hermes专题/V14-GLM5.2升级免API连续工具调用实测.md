## 核心变化

- GLM 升级：最新从 5.1 到 **5.2**，且**以前连续调用工具会报错的问题已解决**
- Hermes 里 GLM5 模型显示 5.1，但内部实际跑 5.2（作者保留 5.1 未删）
- 让模型自我介绍，确认其自报为 GLM 5.2 大模型

## 实测（深度连续工具调用）

任务：「帮我把代码仓库里一个不用的项目删掉」

该任务需依次调用多个工具：
1. 调用（进入）网页
2. 执行搜索
3. 登录
4. 执行删除动作（含确认删除）

全程**无报错**，到代码仓库确认项目已删除成功。作者强调：这种免 API 调用方式与普通 API 一样，都是**标准的 XML 格式调用**。
