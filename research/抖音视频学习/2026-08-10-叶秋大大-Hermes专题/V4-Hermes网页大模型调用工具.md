## 视频核心观点

> 网页大模型（GLM）默认不擅长"调用工具"，需要**注入提示词**让它学会。

---

## 关键内容：工具调用协议两种格式

| 协议 | 优点 | 缺点 |
|---|---|---|
| **括号格式** | 通用（大部分模型能解析）| 容易歧义 |
| **XML 格式** | 严谨（结构清晰）| 模型需训练支持 |

**这是整批视频里**最有价值**的一个知识点**。它对应了 Hermes 端需要解析模型返回的工具调用指令的两种语法。

---

## 视频提到的具体操作

1. 模型本身需**具备 function calling 能力**（即"工具调用"）
2. 在模型管理 → 工具调用 → **注入配置**：始终注入 / 智能判断（视频选"始终注入"）
3. **协议格式选择**：括号 / XML
4. **启用"工具调用解析"开关**
5. **提示词设置**：把工具调用的提示词粘贴上去保存
6. **Hermes 端**：改配置文件，让它**主动解析 XML 传来的工具调用指令**
7. **演示**：查询桌面文件 → 工具被正确调用

## 💡 真实可复用部分

**概念值钱**：

1. **工具调用本质**：让模型输出**结构化指令**（XML/括号）→ 客户端解析 → 调本地工具
2. **GLM 网页版**支持工具调用（前提是注入提示词）
3. **括号 vs XML 协议选择**：通用性 vs 严谨性

**对你这的潜在价值**：
- 你今天 13 bot webhook 用的就是**火山方舟 API**直接调，没用工具调用协议——所以这个**和你现状无关**
- 如果未来你想让 GLM 也接工具调用（比如本地模型走 oMLX 替代火山），这套协议是**必学**的

## 🎯 视频没贴的关键代码（你需要自行研究）

实际工具调用提示词类似：
```xml
<tools>
  <tool name="query_desktop">
    <description>查询本地桌面文件</description>
    <parameters>...</parameters>
  </tool>
</tools>
当你需要调用工具时，输出：
<tool_use>
  <name>query_desktop</name>
</tool_use>
```

**视频没贴这种格式的完整示例**——所以你**只能去查 OpenAI function calling 文档**学。
