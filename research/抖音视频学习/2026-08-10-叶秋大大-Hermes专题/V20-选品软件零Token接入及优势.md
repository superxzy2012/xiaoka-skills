## 软件操作

- 比传统选品平台强「100 倍」；平台若在预设的 4 个之内直接选，否则填任意地址
- 填商品、选排序方式（销量 / 价格 / 综合）、选排前范围（10～100）
- 勾选关心的数据维度（含商品**图像**，可一键获取）
- 指定**存放位置**，设**定时采集**（每天 / 每周某时点）
- 点「开始采集」→ 表单和图片自动存好

## 零 Token 接入（关键）

- 更策略的功能是**自动分析数据**：按标准 AI 的 API 格式填入
- 填入的是「之前网页大模型转 API 用过的 API Key」（演示用了 DeepSeek / GLM）
- 作者强调：**从头到尾用这个软件没有任何 Token 消耗**

## 相比智能体方案的优势

- OpenClaw / Cloud Code 这类智能体，每执行一次定时任务都在**消耗 Token**
- 这套软件**完全不消耗 Token**，且输出更**稳定**，更适合需要反复执行的**应用场景**

## 与你项目的关系

- 与 V19 是同一款选品软件的两期介绍：V19 讲能力/案例，本集讲操作 + **零 Token 的 AI 分析接入**。
- 对 OPC 跨境选品：**采集（零 Token）+ AI 分析（接免费网页大模型，零 Token）= 全链路零成本选品调研**，且比用智能体定时跑更省钱、更稳。
- 落地到 WorkBuddy：可把这款选品软件的「定时采集 + 标准 AI API 接入」思路，做成你 agent 蜂群里的一个「选品调研 agent」——定时抓 Ozon/美客多/亚马逊数据，用免费模型出选品报告。
- 提醒：智能体方案（每次耗 Token）适合一次性复杂任务，零 Token 软件方案适合**高频重复**的采集分析，两者可按场景搭配。
