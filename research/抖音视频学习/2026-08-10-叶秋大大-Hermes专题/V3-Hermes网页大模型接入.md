## 视频原方案

> 用"网页大模型转 API"工具（视频里是 Windows .exe 文件），把**智谱 GLM** 网页版登录态转为本地 API，然后接入 Hermes。

---

## 视频操作步骤（按视频顺序）

1. **Windows 用户**：下载 .exe 文件安装包
2. **主界面设置**：文字改简体中文
3. **供应商** → 添加大模型 → 选"智谱"
4. **登录方式**：OS 登录（用浏览器登录智谱官网）
5. **代理设置 → 基础配置**：绑定地址用默认
6. **API Key**：新建（名称可自动生成）
7. **填入 API key + 模型名称**
8. **Hermes 配置**：找到"自定义入 API 方式" → 填入 base_url + API key
9. **验证**：查看可用 API 列表 → 看到智谱 GLM

## 💡 真实可复用部分

**概念正确**：
- 网页大模型 → API 是**0 成本**调用 GLM 的可行路径
- 智谱 GLM 的网页版有免费额度（每天登录送 tokens）
- 工具核心原理：抓浏览器登录态 → 反代为 OpenAI 兼容 API

**对你这的潜在价值**：
- 你已经用火山方舟 Coding Plan（deepseek-v4-flash）够用
- 但如果**火山限流/挂了**，智谱网页版 + 转 API 是兜底方案
