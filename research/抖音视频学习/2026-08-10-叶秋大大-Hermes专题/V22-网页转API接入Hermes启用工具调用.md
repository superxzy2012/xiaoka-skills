## 前提

接入的模型本身要**具备调用工具的能力**（视频称「方舟 Q 能力」）。先到管理模型里确认接入的模型都带工具调用能力。

## 配置步骤（已纠正音译）

1. 模型管理 → 最后一个「工具调用」项，已预设好可**注入提示词**的工具调用方式
2. **注入配置**：可选「始终注入」或「根据判断注入」（作者选始终注入）
3. **协议格式**两种：
   - **括号格式**：更通用
   - **XML 格式**：更严谨（推荐用于工具调用）
4. 打开「**启用工具调用解析**」开关
5. 关键是**提示词设置**：按自己需求把工具调用的提示词填上去，保存
6. 到 **Hermes** 修改配置文件，让它主动**理解 XML 传来的工具调用指令** → 即可执行

## 实测

- 指令：「查看本机桌面有哪些文件」
- 结果：正确查出桌面目录，**调用了查询目录的工具** ✅

## 与你项目的关系

- 这篇是 V21（通用转 API）在 **Hermes 上的工具调用落地**。核心就两步：客户端侧注入工具调用提示词 + 用 XML 格式 + 打开解析开关。
- 对 WorkBuddy：WorkBuddy 的自定义 API 接免费网页模型后，若要做工具调用（读文件 / 执行命令 / 调 MCP），同样需要确认模型支持工具调用、并配置好提示词注入与解析格式。可把这篇当配置 checklist。
- 括号格式 vs XML 格式的选择，建议生产用 XML（更严谨、少歧义）。
