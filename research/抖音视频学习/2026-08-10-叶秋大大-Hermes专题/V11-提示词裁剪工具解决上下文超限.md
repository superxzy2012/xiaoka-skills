## 背景问题

网页端大模型转成标准 API 后接入 Hermes / Codex 等客户端，可以免费使用；但**系统提示词过长会导致上下文窗口超限**。

## 解决方案：提示词裁剪工具

- 在「网页端大模型转 API」之后、接入 AI 引擎之前，加一个**类似剪刀的裁剪工具**拆截提示词
- 工具启动后自动打印当前所有大模型；开启「裁剪状态」开关即可
- 可配置裁剪策略：在「保留关键词 / 丢弃模式」里已预设好默认规则，也能自行增删字段 / 关键词
- 把它当作一把「小剪刀」，灵活适配不同场景

## 实测（Hermes 环境）

- 用裁剪工具处理后，问题前**仅携带极少量提示词**
- 验证「裁剪后还能不能调用工具」：在 Hermes 窗口用「查看本地文件」指令，**上方确实调用了查看文件的工具**，下方给出完整清晰结果

## 与你项目的关系

- 这是「0 token 方法」的**重要配套**：免费网页端模型普遍上下文窗口比付费 API 小，接 WorkBuddy 后系统提示词 / 长上下文容易超限崩溃。
- 裁剪工具让 WorkBuddy 在零成本模型上仍能稳定调用工具（如读文件、执行命令），是生产可用的关键一环。
- 建议把「网页大模型转 API 工具 + 提示词裁剪工具」作为一套组合部署到 WorkBuddy 的自定义 API 链路里。
