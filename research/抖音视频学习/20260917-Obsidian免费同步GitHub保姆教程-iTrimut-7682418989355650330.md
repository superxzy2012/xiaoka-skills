# Obsidian 免费同步 GitHub 保姆教程

> 作者：**iTrimut**（粉丝76 / 获赞427）｜来源：[抖音图文原帖](https://www.douyin.com/note/76824【手机号】330)

## 核心结论（先看这个）

| 对比 | 官方 Sync | 免费方案（本教程） |
|---|---|---|
| 价格 | ¥80+/年，年年续费 | **0 元** |
| 同步原理 | 官方云服务器 | GitHub 私有仓库（免费不限量） |
| 数据归谁 | Obsidian 公司 | **你自己** |
| 上手 | 开箱即用 | 一次性配置 30–40 分钟 |

- 手动拷 U 盘 → 会忘；网盘同步 → "副本/最终版"版本乱；官方 Sync → 花钱且数据在别人云上。
- 本方案 = **写完自动备份、异地冗余**：硬盘坏/电脑丢/误删/重装，笔记都在。

## 9 步全流程

| 步 | 操作 | 关键要点 |
|---|---|---|
| 1 | 建 `.gitignore`（UTF-8 无 BOM） | 排除 `.obsidian/workspace.json`、`.obsidian/workspace-mobile.json`、`.trash/`，否则每次标签页布局都变"改动"，提交历史全是噪音 |
| 2 | Vault 就地变 Git 仓库 | `git init -b main` → `git add .` → `git commit -m "vault backup: init"`；`git status` 显示 working tree clean 即成功 |
| 3 | GitHub 建 Private 空仓库 | github.com/new；Visibility 选 **Private**；README/.gitignore/license **全不勾**（勾了会和本地历史冲突） |
| 4 | Obsidian 装插件 | 第三方插件关限制模式 → 搜 **Obsidian Git**，认准作者 **Vinzent**（蓝底 Git 图标），别装同名仿冒 |
| 5 | 配自动同步 | 2.x 版本设置是分页的（Main / Automatic backup / Automatic pull）。自动备份间隔可设 10 分钟（最低 1 分钟）；commit 模板 `vault backup: {{date}}`；开启 **Pull on startup**（启动自动拉取） |
| 6 | 生成 SSH key（**最大坑**） | **别在 PowerShell 手敲** `ssh-keygen -N ""`——空参数会被吞掉，生成带密码私钥导致 `Permission denied (publickey)` 还查不出原因。用 Git Bash 跑脚本，看到 `OK: key is passphrase-free` 才算成功 |
| 7 | 公钥贴到 GitHub | Settings → SSH and GPG keys → New SSH key；**Key type 必须选 Authentication Key**（选成 Signing Key 会卡两小时 Permission denied） |
| 8 | 22 端口不通走 443 备用 | 编辑 `~/.ssh/config`（无扩展名）：Host github.com / Hostname ssh.github.com / Port 443 / User git / IdentityFile ~/.ssh/id_ed25519 / IdentitiesOnly yes。`ssh -T git@github.com` 看到 `Hi 用户名!` 即通 |
| 9 | 关联并推送 | `git remote add origin git@github.com:用户名/仓库.git` → `git push -u origin main` |

## 关键命令速查（macOS/Linux/Git Bash 通用）

```bash
# 第2步：初始化
git init -b main
git add .
git commit -m "vault backup: init"

# 第6步：生成无密码 ed25519 密钥（用 Git Bash，不要用 PowerShell）
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
cat ~/.ssh/id_ed25519.pub      # 复制这行到 GitHub

# 第8步：~/.ssh/config（22被墙/不稳时走443）
Host github.com
  Hostname ssh.github.com
  Port 443
  User git
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes

# 验证
ssh -T git@github.com          # 出现 Hi <用户名>! 即成功

# 第9步：关联推送
git remote add origin git@github.com:<用户名>/<仓库>.git
git push -u origin main
```

## 12 个坑（作者已踩平，OCR 可辨认的核心几条）

1. **`.gitignore` 不排 workspace.json** → 界面布局每次变改动，提交噪音。
2. **PowerShell 敲 `ssh-keygen -N ""`** → 空参数被吞，私钥带密码，`Permission denied` 查不到原因 → 用 Git Bash。
3. **GitHub Key type 选成 Signing Key** → 认证失败两小时 → 选 **Authentication Key**。
4. **建仓库时勾了 README/.gitignore/license** → 与本地历史冲突 → 空仓库。
5. **Visibility 选 Public** → 笔记公开泄露隐私 → 选 **Private**。
6. **22 端口被网络环境限制** → 走 `ssh.github.com:443` 备用通道。
7. **装了同名仿冒插件** → 认准作者 **Vinzent**。
8. **找不到自动备份设置页** → 2.x 是分页的，Automatic backup settings 在独立标签页。
9-12. 其余"现象→原因→一句话解法"见作者评论区置顶完整排查表。

## 小豆备注（对 BOSS 的可执行价值）

- BOSS 的主 vault 就在 `/Users/【BOSS英文名】/.hermes/obsidian_vault/`，本方案可**直接照搬**给它上 0 元异地备份（当前 vault 是否已有 git 远程，值得我查一下，避免 13BIT 知识资产只在单机）。
- macOS 上没有 PowerShell 吞参数问题，直接终端 `ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519` 即可；GitHub 在国内网络不稳时同样用 `ssh.github.com:443`。
- 需要的话我可以**直接帮 BOSS 给 obsidian_vault 配好这条 GitHub 自动备份**（建私库+SSH+首次推送），你给个 GitHub 账号/确认即可。
