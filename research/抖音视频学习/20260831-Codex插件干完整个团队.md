# Codex 装上这些插件，直接干完一整个团队

> [!abstract] 摘要
> 一条抖音展示：OpenAI Codex 装上一批插件后，几乎能干完一整个团队的活——从操控电脑、浏览网页、修代码 Bug，到设计 UI、解析 PDF、做视频动效、写文档报表、出 PPT。

## 插件清单（11 个，OCR 画面 + 口播双重实证）

| # | 插件 | 功能（实证来源） | 安装/鉴权需求（待核实） |
|---|---|---|---|
| 1 | **Computer Use** | 直接操控电脑，完成点选/输入/自动办公（口播+帧02） | 本地能力，设置开启即可 |
| 2 | **Chrome** | 给 Codex "眼睛"，浏览网页、查资料、测试网站效果（口播+帧03） | 本地浏览器连接器 |
| 3 | **GitHub** | 读取 PR、修复 Bug、快速定位处理项目代码问题（口播+帧04，口播音近"Gatab"=GitHub） | 需 GitHub 账号 OAuth 登录 |
| 4 | **Figma** | 主动设计 UI，把 UI 设计直接转成前端代码（口播+帧05） | 需 Figma 账号 / token |
| 5 | **PDF** | 快速解析论文/报告/合同，提炼核心要点输出摘要（口播+帧06） | 本地解析为主 |
| 6 | **Remotion** | 用代码批量生成短视频、动画、各类动效（口播+帧07） | 本地工具/MCP，可能需 Node 环境 |
| 7 | **Hyperframes** | 制作动画、字幕、网页视频，让视频节奏表现力拉满（口播+帧08） | 本地工具/MCP |
| 8 | **Documents** | 撰写报告、编辑文档、优化排版（口播+帧09） | 多需账号（Google Docs / MS Word）|
| 9 | **Spreadsheets** | 生成带图表演示效果的电子表格，数据分析与汇报一次性搞定（口播+帧10，音近"Spreadseats"） | 多需账号（Google Sheets / MS Excel）|
| 10 | **Canva** | 直接制作封面、海报、设计配图（口播26行，音近"Kanwa"=Canva） | 需 Canva 账号 |
| 11 | **PPT** | 演示文稿（口播28行；帧11 标题卡汇总结尾提及） | 多需账号（Google Slides / MS PPT）|

> ⚠️ **核实说明**：上表"安装/鉴权需求"为按常识推断，Codex 实际插件机制需在本机核实（见下方"落地待办"）。其中 GitHub / Figma / Canva / Documents / Spreadsheets / PPT 大概率要 BOSS 本人授权登录或填 token，**不能由我代填密钥**（密钥安全铁律）。
