# VibeCoding大赏：给Hermes搭建一个可扩展的插件体系

## 核心内容（248字）

VibeCoding（氛围编程）——用自然语言驱动 AI 编写代码——的实际应用展示。视频演示了如何利用 VibeCoding 方式为 Hermes Agent 搭建一个可扩展的插件体系。通过自然语言描述需求，让 AI 自动生成插件代码，实现 Hermes 功能的快速扩展。展示了从需求描述→AI 生成代码→测试→集成的完整流程，以及如何将社区已有的插件适配到 Hermes 生态中。

## 关键操作步骤

1. **需求描述**：用自然语言清晰地描述要实现的插件功能
2. **AI 生成**：让 Codex/Claude Code 等编码 Agent 生成插件代码
3. **测试验证**：在隔离环境中测试插件功能
4. **集成部署**：将插件注册到 Hermes 的 plugins 目录
5. **社区适配**：从开源社区寻找可适配的插件

## 适用场景
- 想要快速扩展 Hermes 功能的用户
- 对编程不熟悉但需要自定义功能的场景

## 注意事项
- AI 生成的代码需要人工review安全性
- 插件可能引入兼容性问题
