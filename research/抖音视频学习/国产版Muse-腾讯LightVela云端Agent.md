# 腾讯 LightVela：国产版「Muse」

## 核心内容（一句话）
腾讯轻量云团队推出 **LightVela**——云端托管 **开源 Hermes Agent** 的 Personal AI Agent，7×24 在线、有长期记忆，可直接**接入微信/QQ/企业微信/飞书/钉钉**，被视作对标 Meta Muse（接入 WhatsApp）的国产版，且推出时间更早；启航版新用户免费体验一个月。

## 对标关系
| | Meta Muse | 腾讯 LightVela |
|---|---|---|
| 底层 | 个人 AI Agent（云端虚拟电脑/浏览器） | 云端托管开源 Hermes Agent |
| 入口 | WhatsApp | 微信、QQ、企业微信、飞书、钉钉 |
| 特点 | 长期记忆、后台持续干活 | 长期记忆、自进化技能、模型/人设/技能可配 |
| 上线热度 | 上线约2-3周下载 250-340 万、美国免费榜第一，日活约为 ChatGPT 同期 3 倍 | 免费1个月（送积分），云端开好无需服务器/代码 |

## 使用方式（视频所述）
1. 不用买服务器、不用写代码，云端已开好；
2. 网页上挑好模型、装上技能；
3. Agent 被"注入"国民聊天软件，一接入即记住你聊过的内容、偏好与习惯，跨 App（上午微信、下午飞书）记忆连续，支持图片/文件/语音。

## 视频观点
- 有人一句话让它接播客，有人让它盯版本更新，连会都少开；
- 本质判断：**腾讯卖的不是更聪明的 AI，是"装 AI 的房子（入口/托管）"**；
- 隐忧：AI 进入聊天工具、记录"和谁聊、聊什么"，是贴心助理还是手机里的"监工"，隐私值得警惕；
- 趋势论：以后比的不是谁家 AI 更聪明，而是谁家在你手机里"住得更久"。

## 免费套餐（公开资料，以官网为准）
- 启航 Launch 版：限时免费 1 个月；约 2核4G、独立隔离环境、专属存储、月流量、模型体验积分（默认模型可自选，可用自带 API Key）；
- 官网入口：`lightvela.tencent.com`（以腾讯云官方为准）。

## ⚠️ 背景与风险
- 相关 OpenClaw/QClaw 生态在 2026 年 9 月出现关停/12 月停运消息，具体服务持续性以腾讯官方公告为准。
- 聊天记录级长期记忆 = 强隐私授权，接入前看清数据范围与关闭/删除入口。
