# <数据源> 数据约定

本任务必须有 <数据源> 的 <平台> 数据。没有可用权限或合格导出时，交付补数清单与 HOLD；**不能改用模型猜数据后标为完成**。

## 接入

1. **已配置 MCP**：先列出真实工具和参数，不要发明工具名。
2. **官方 API**：核对当前方法和字段。令牌只从私有环境读取，**不能写进文档、日志、公开仓库或截图**。401/403 停止；429 按服务提示退避，不能无限重试。
3. **文件导出**：记录原始文件哈希、列名、筛选和时间。不能拿其他来源改名充当 <数据源>。

## 数据清单

每份文件记录 `provider` / `marketplace` / `module` / 卖家地区和模式 / 报表或端点 / 抓取时间 / 报告实际起止 / 时区 / 币种金额单位 / 粒度 / 过滤与覆盖率 / 字段映射。

把原始数据与分析表分开保留。结果行带数据清单ID、对象ID、日期和计算式；记录缺失，**禁止把 null、破折号、no_data 或失败响应填成 0**。

## 解释边界

- 外部订单/金额是观察与估算：标 **ESTIMATE**
- 自家已核订单与费用：**FACT**
- 自行设定参数：**ASSUMPTION**
- 无法证实：**UNKNOWN**

金额单位未确认时不做金额运算。代理指标（如可见性、频次）不能充当实际曝光或点击。

## 交付验收

至少展示一条从原始字段到本任务判断的证据链，并列出反例。数据齐全只代表可以分析；发布、调价、投放、采购或联系买家属于**另一个明确授权的动作**。
