## 十个模型速查

| # | 模型 | 卷 | 一句话 | 原文金句 |
|---|---|---|---|---|
| 1 | 矛盾分析三步 | 一 | 抓主要矛盾 → 抓主要方面 → 具体问题具体分析 | 「事物的性质，主要地是由取得支配地位的矛盾的主要方面所规定的」 |
| 2 | 实践检验真理 | 一 | 判对错看结果，不看感觉 | 「真理的标准只能是社会的实践」 |
| 3 | 利益机制 | 一 | 群众跟不跟你走，看日子过得下去，不看觉悟 | 见 ch02「星星之火」章 |
| 4 | 持久战三阶段 | 二 | 先画轮廓，让事实校正；别用终局指标考核阶段 | 「为战略指导所必需」 |
| 5 | 教条 vs 主观 | 三 | 有框架没内容＝教条；有热情没根据＝主观 | 「具体地分析具体的情况」 |
| 6 | 领导三方法 | 三 | 集中→解释→行动→检验；一般号召+个别指导；骨干+群众 | 「两个方法是必须采用的」 |
| 7 | 局部压倒性 | 四 | 至少 3 倍优势，软柿子优先，方法主次随条件重排 | 「情况改变了，作战方法也应改变」 |
| 8 | 班长与一班人 | 四 | 领导效能是团队的；没准备就别开会 | 「动作不整齐，就休想带领千百万人」 |
| 9 | 不要四面出击 | 五 | 敌人多时先减目标；拉中立者比消灭反对者省力 | 「绝不可树敌太多」 |
| 10 | 两类矛盾 | 五 | 先分类再选手段；「人民」是相对概念 | 「性质完全不同的两类矛盾」 |

## 五个最常被误用的

| 常见错引 / 误解 | 原文实际 | 出处 |
|---|---|---|
| 「实践是检验真理的唯一标准」 | 原文是「真理的标准**只能**是社会的实践」，「唯一」是 1978 年后转述 | 卷一 |
| 「星星之火，可以燎原」当口号用 | 原文是在批评当时对红军前途的悲观估计，是**战略判断**不是励志语 | 卷一 |
| 持久战 = 拖时间 | 错。三阶段每阶段任务不同，第二阶段任务是「**准备反攻**」，评判标准不能提前 | 卷二 |
| 团结 = 睁一只眼闭一只眼 | 错。是「**辩证的** vs 形而上学的」——辩证的会分析、不因一次错误否定一个人 | 卷五 |

## 典型场景 → 用哪几个

| 场景 | 组合 |
|---|---|
| 项目半年没进展，该不该砍 | 矛盾分析 + 持久战三阶段（是不是拿终局指标考核了）+ 教条vs主观 |
| 要同时推三个项目 | 不要四面出击 + 局部压倒性（至少 3 倍） |
| 团队内部有分歧 | 两类矛盾（先分类）+ 辩证vs形而上学（不因一次错误否定人） |
| 老板要「着眼未来」 | 长期算账（论十大关系：几十年后算总账）+ 真想还是假想 |
| 招不到人/留不住人 | 利益机制 + 论持久战（民众无组织状态） |
| KPI 越做越细，指标都达标但业务下滑 | 反对官僚主义（执行服务于什么） |
| 战略要放弃了 | 持久战三阶段（描画轮廓是必需的，不画轮廓才是不负责） |
| 借鉴别人经验照搬失败 | 教条vs主观 + 方法主次随条件重排 |

## 第零步：框架适用边界自检（先做这一步）

**在分析任何问题之前，先判断毛选框架适不适用。** 毛选的核心能力圈是「以弱胜强的竞争策略」。

| 问题类型 | 适用？ | 该用什么 |
|---|---|---|
| 弱者 vs 强者的竞争 | ✅ 核心能力圈 | 集中优势兵力 / 持久战 |
| 团队与人际冲突 | ✅ | 统一战线 + 群众路线 |
| 个人成长与突围 | ✅ | 持久战 + 根据地思维 |
| 组织效能与团队管理 | 🟡 部分（群众路线/整风） | 管理学框架更系统 |
| 已是行业第一要守业 | 🟡 部分 | 补治理/经营框架 |
| 合作共赢 / 正和博弈 | ❌ 毛选偏对抗 | 平台/生态思维 |
| 纯决策质量（A 还是 B） | ❌ 不擅长 | 决策理论/逆向思维 |
| 快速变化的 AI/互联网 | 🟡 需打补丁 | 叠加 OODA/精益/网络效应 |

**若判断不适用，诚实告知**：「毛选对你这个问题的适用性有限，因为〔原因〕。我会用适用的部分分析，但建议补〔其他视角〕。」
