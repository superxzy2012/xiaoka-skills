# PDF 交付验收门禁

PDF **生成成功 ≠ 可交付**。版式错误和内容缺失都不会报错，只会在用户打开时暴露。
下面六项是硬门槛，**一次性跑完，全部通过才发**。

## 一次性脚本

```bash
uv pip install --quiet --python /opt/data/.venv-browser/bin/python pypdf pymupdf
python3 scripts/verify_pdf.py /path/to/报告.pdf \
  --keywords "定位" "详情页" "复盘" "90 天" \
  --probes "资产唯一特征串1" "资产唯一特征串2" \
  --out /opt/data/cache/scratch/pdf_text.txt
```

退出码 0 = 全过；非 0 = 看 `FAIL` 行。

## 六项判据

| # | 项目 | 通过条件 | 为什么必须查 |
|---|---|---|---|
| 1 | 内嵌字体 | 每个字体的 ext 非空 | 未内嵌 = 换台机器就变豆腐块 |
| 2 | 无乱码 | 无页含 U+FFFD | 缺字在中文字体里常常静默变方框 |
| 3 | 无正文溢出 | 排除页脚后，0 个块越出裁切框 | 长表格/Prompt 行被裁掉，且看不出来 |
| 4 | 右边距 | `页宽 - 正文最大 x1 >= 25pt` | 贴边 = 打印机会切掉 |
| 5 | 内容完整 | keywords 与 probes 全部命中 | **最重要的一项** |
| 6 | 书签 | `get_toc()` 非空且层级合理 | 长报告没有书签就没法跳读 |

## ⚠️ 验收脚本自己骗自己的三个坑

这三条都会让脚本**全绿但交付物是坏的**，或者**全红但其实没问题**。

### 1. 页脚被算成越界

页码在 `y ≈ 页高 - 16`（A4@72dpi 即 y≈826）。任何 `y1 > 页高 - 20` 的判据都会把**每一页**都报越界。

**判据**：先按 `y0 > 页高 - 40` 剔掉页脚带，再判溢出。别硬编码 810 —— 换纸张尺寸就全错。

### 2. 空串恒真

```python
if "" in text          # ← 永远成立，每一页都报乱码
if "\ufffd" in text    # ← 正确
```

写判据时永远先在终端 `print(repr(marker), txt.count(marker))` 确认 marker 非空且确实会出现。

### 3. 「字数少 = 有问题」不成立

封面、目录、章节起始页字数天然少。用「排除已知版式页后仍存在空页」判，不要用绝对字数阈值。

## 内容完整性 > 版式

版式六项过了只说明「能看」，没说明「对」。**必须再做内容探针**：

- **长文报告里的资产**（Prompt / 模板 / 字段表 / 阈值表）：为每个写一个唯一特征串，逐个检查命中。少一个就是抽取漏了，而漏掉的往往正是最关键的硬约束行。
- **敏感信息反向扫描**：`cookie` / `token` / 内网 IP / `密码` / 邮箱 —— 报告类交付物默认不该含这些，命中即需处理。
- **不可得指标要显式声明**：若源文明说某项数据接口拿不到（成员级互动、留存、转化率），报告里必须单列说明，否则下游会拿去伪造看板。宁可写「这项拿不到，需后台导出」，也不要留白。

## 归档校验

```bash
md5sum 源文件 NAS副本        # 两个 hash 相同才算 cp 完整
```

长报告固定落三份：PDF + 从 PDF 抽出的可搜索全文 + 带双链的索引笔记。
全文那份是「Obsidian vault 内可搜」的关键 —— PDF 在 vault 里搜索不了。

## 交付说明里如实写验收方式

没有 vision provider 时**不要写「已目检」**。写清用了什么：几何校验（字体/溢出/边距）+ 文本抽取（关键词/探针）。
把没做的事说成做了，比少一项检查更糟。
