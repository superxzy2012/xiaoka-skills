# Prompt K · 长内容拆条

**来源**：《WorkBuddy + 知识星球：一个人自动化的做课赚钱手册》第 08 章（袁六伟，2026-09-14）
**模式**：Agent（先声明切法）
**产出文件**：我的-帖子包2个.md（3 条独立短帖）

## 原文 Prompt（完整照抄，未改写）

```text
【角色】知识星球内容运营，负责把一条长内容拆成可独立分发的短帖。

【输入】长内容全文：{粘贴}；目标条数：3

【任务】
1. 先声明用哪种切法：A 按动作切 / B 按人群切 / C 按反常识切，并说明为什么选它。
2. 拆出 3 条，每条：标题 + 300–600 字正文 + 一条落地动作。
3. 每条必须能单独读懂——不许出现「上篇/中篇/下篇」「承接上文」「详见前文」。
4. 三条之间互相引流一句（放末尾），但不依赖彼此。

【自检】把任意一条单独拎出来读一遍，读完能不能知道「这是在说什么、我该做什么」？不能就重写这条。操作步骤：每周一用 Agent 模式跑 Prompt I，直接落文件 我的-一周内容日历.md。日历定了，这一周的供给就不再靠临场想。周二那一条专栏连载，直接从第 05 章的逐字稿里改——把逐字稿的「讲」改成「读」，把口头语改成书面语，一讲能直接变成一条帖。同一次投入，出三个产物：直播讲一次、星球发一条、拆出 2–3 条短帖。帖子包用 Prompt J 出。发到星球之前，最后过一遍下面这张检查表：标题 6 个里有没有 4 个不同公式、正文有没有 ** 和竖线、配图清单每张图有没有写清是真实截图还是示意、最后一句有没有给动作。拆条用 Prompt K。拆完随手把 3 条中任意 1 条单独读一遍，读不懂就重写那一条。我踩过的坑我有一个月，星球里从周一到周日全是互动帖：投票、提问、晒作业。那一个月评论量挺好，但我自己心里发虚。到第二个月，新增成员开始掉，而且评论区的问题质量开始下降——从「这个流程怎么做」变成了「今天有活动吗」。这就是六格里那条红线的意义：连续两周只有互动帖没有内核内容，说明课程线断了。 互动帖制造的是热闹，内核内容制造的是「非来不可」。热闹退下去，人就走。第二个坑更琐碎，但更常见：我把一张 Markdown 表格直接复制进了星球的帖子编辑器，发出去一看，竖线全露在外面，排版乱七八糟，看着像乱码。这里必须分清通道，别一刀切。发帖子时，星球编辑器不认 Markdown，表格不渲染——所有表格、加粗符号、标题井号，发帖前都要转：表格转成一「行」一条的列表，加粗用编辑器自带的加粗按钮，标题用编辑器的字号。但发长文章（article）时，表格可以直接用，会渲染成真表格。 我自己就没分清过通道，把一篇长文里的表格全拆成了列表，纯属白费功夫。所以这一条我改成了：先确认这条内容走的是帖子通道还是长文章通道，再决定要不要转格式。今天就动手：跑 Prompt I，出一张你自己的下周内容日历。出完之后只检查一件事：周二那一格是不是专栏连载，另外六格有没有缺格子。今天排表，明天开始填。本章你该交出的东西：我的-一周内容日历.md（七格填满）+ 我的-帖子包2个.md（每个含四件套）自检三问：1）周二是不是专栏连载，有没有被活动挤掉？2）内容供给密度够不够 1？3）帖子包的四件是不是都齐了，正文里还有没有 Markdown 残留？下一章要用到：本章产出的那两条帖子——第 09 章讲的社群动作，就是围着这两条帖做承接和巡场。第 09 章 · 社群承接：新人 24 小时和每天巡场一个人进圈，3 天没说过话，第 4 天基本就消失了。这句话不是我的判断，是我自己盯了三批新人之后看出来的规律。他不说话，说明他没找到地方待；他找不到地方待，就不会再来；他不来，你前面所有的工作都白做。所以社群这一章的目标只有一个：把人按住，让他开口第一次。 开口一次的人，留下来的人数是没开口的好几倍。01 新人入圈 24 小时，动作要排到小时新人承接容易犯的错是「一条群发欢迎语」。我在星球上收到过太多这种：「欢迎新成员加入，请先阅读群公告，有任何问题随时联系管理员。」这句话的效果等于没发。它没有任何信息告诉对方「你来对地方了」。我现在的做法是把 24 小时拆成几个时间点，每个时间点只干一件事：时间点谁做什么T+0（入圈即刻，≤10 分钟）运营先确认入圈 / 入群状态：看他进没进群、信息对不对；没进群的先解决入群，再谈欢迎T+0（同一次处理里）运营发欢迎语：昵称 + 一句跟他行业或来源相关的话 +「不会用也没关系」T+0 ~ 30 分钟系统把新成员信息推给运营：昵称 / 入圈时间 / 来源渠道 / 入群状态T+2 小时系统（模板化自动发）私信「入圈三件套 + 第 0 步 + 3 步行动清单」T+6 小时系统（模板化自动发）邀请发自我介绍（给模板，不逼）T+12 小时星主（抽人发）对自我介绍完整或带明确问题的人，回一句 + 邀请把问题发进「提问」区T+24 小时运营若仍未开口：发一次「具体提问」轻触（不问「在吗」）T+24 小时运营把新人的回答和画像录入《成员画像表》这张表里要紧的是谁发什么，别搞混。运营负责全量欢迎、入群状态处理、问题收集、画像录入——这些是流程动作，必须覆盖到每一个人。星主只做高价值抽发：回那些自我介绍写得完整、问题写得具体的人，把他引到提问区。星主的时间稀缺，让他去做全量欢迎是浪费。系统那一步只做推数据、提醒、批量生成待审草稿、按模板自动发流程消息。分界线就一条：这条消息是不是每个人都收一样的？ 是，就交给系统模板化自动发；不是，就人发。为什么这么分？算一笔账。 9 月那期 14 天新增 274 人，平均一天约 19 人。如果欢迎语、三件套、自我介绍邀请、24 小时轻触四条都靠手打，一天就是 76 条私信——一个人干不完，干到第三天开始拖，拖到第五天干脆不发了。拆成两类之后是这样：系统模板化自动发（不需要个性化）：入圈三件套 + 第 0 步清单、自我介绍邀请。运营亲自发（必须有人味）：T+0 的个性化欢迎、T+24h 的轻触。一天约 38 条，一个人接得住。还有一条纪律：按入圈当天批量处理，别攒到周末。 攒五天再一次性欢迎，那批人早凉了；而且「攒着」这件事一旦开始，就永远攒不完。欢迎语的关键是「个性化」。我给的样子是这样：> {昵称}你好，欢迎进 Workbuddy一人公司营 👋 > 看到你是做{行业/身份}的，星球里正好有同行的伙伴交过作业，你待会儿可以搜「{关键词}」看看。 > 不会用也没关系，这里大部分人一开始都是零基础，跟着一步步来就行。 > 先别急着刷，我一会儿私信你一份「入圈三件套」，照着走就行。反面例子就是那句「欢迎新成员加入，请先阅读群公告」。区别只在一件事：你的那句话说没说中他。补一句我最常加的话：「不会用也没关系」。新人最大的心理负担不是「不会」，是「怕自己太笨、问出来丢人」。你先把这句话说出来，他才敢开口。这句不是客套，是我刻意放在欢迎语里的。第 0 步：先确认他进群了没有。「入圈三件套」里的第 0 步就是这个。很多人付完钱就卡在这儿：进了星球，但没进群；或者压根不知道自己还有个群。这件事必须排在所有动作之前——他不在群里，你在星球里发再多他也不看。入口口径（袁总确认过）：付款后系统会自动推送入群链接，点开就能进群。 推送的具体形式我不写死（平台可能调整），你只要记住一句话：第 0 步是「确认他在群里」，不是「欢迎他」。02 每天巡场：六个地方，一个优先级社群不是「等有问题再答」，是每天固定巡一圈。我固定在看这几处，每天 20:00 前完成第一轮（对应「每晚 20:00」的内容节奏），次日早上补一轮：新入圈成员——有没有 24h 内没被欢迎的评论区——有没有没被回复的提问或留言「提问」区——有没有未回答的提问新帖子——有没有值得加精、值得接话的风险内容——广告、抱怨、疑似纠纷、违规沉默名单——有没有该唤醒的巡场不是平均用力，有优先级，从高到低：风险内容 → 未回复的提问 → 24h 新成员 → 冷场帖救场 → 精华沉淀 → 沉默唤醒。风险内容排第一，因为它拖不起。一条投诉挂在评论区三天没人管，损失的是一批人。冷场有个明确的判定：一条互动帖发出 4 小时，评论数还是 0，就算冷场。 冷场的根因通常不是内容不好，是参与门槛太高，或者没有具体可答的钩子。我救场就用三种办法：抛一个真实的两难让人选边（门槛低，起量快）、点名请一位活跃星友展开说说（把「大家说」变成「有个人先说」）、把大问题拆成一个能立刻答的小问题。点名之前有一条铁规矩：先私信征得本人同意再 @。 不同意公开的，就只讲做法、隐去昵称。03 答疑分三级：哪一级你一个字都不能自己答问题不能一视同仁地答，得分级，因为有些问题答错了是要赔钱的。级别问题类型谁答时限L1 自答工具操作、学习路径、资料在哪、作业怎么交运营直接答24h 内L2 需判断方法选择、行业适配、内容诊断运营起草 → 星主抽检48h 内L3 升级退款/订单/发票、纠纷/投诉、合作/商务、折扣/名额、结果承诺、负面舆情只由星主回立即转，24h 内告知「已转」有三条被问得最多，答案直接抄：> Q0：我付完钱了，怎么进群？加不上怎么办？ > A：付款后系统会推送入群链接，点开就能进。要是没收到、或者点不进去，把付款截图发我，我这边帮你查——这类问题不用等，看到就回。> Q1：我从哪开始学？ > A：三步。先看「新人必读」里的路径图；再从和你行业最接近的那篇实战拆解开始（搜你行业的关键词）；最后跟着做一个小动作，别只看不做。看 10 篇不动手，不如做 1 个小动作。> Q2：学完能干啥？能赚到钱吗？ > A：结果这件事我不能替你承诺——能做多少取决于你做什么、投多少时间。我能告诉你的是：星球里有人把「做内容 → 接单」跑成了固定流程。你先定一个小目标，做完我们再聊怎么放大。注意 Q0 和 Q2 的分界：Q0 是流程问题，看到就回，越快越好；Q2 是结果类问题，一个字都不能承诺。L3 那一条我讲死一点：运营一个字都不许自行答复。 不是不信任，是这类话一出口就变成了承诺。我给我的团队定的话是「这类事我不做主，我 10 分钟内转给袁总，他今天会回你」。禁语清单也要背下来，运营回复里绝不出现：保证、一定、百分百、绝对；「学完就能月入 X」「包接单」「包出结果」；「可以退」「给你打个折」「这个名额给你留」；未经同意就贴出其他学员的昵称、头像、截图。危机处理我固定三句话：> 用户情绪激动：先接情绪，不辩论——「这个我理解，是我这边没跟上，我马上查。」 > 涉及钱或纠纷：不表态、不承诺、马上转——「这类事我不做主，我 10 分钟内转给袁总，他今天会回你。」 > 群里有人公开质疑：不删不吵，私信解决——「群里说话容易误会，我私信你，我们把它弄明白。」社群里值钱的东西不是答案，是口径一致。 同一个人问两次得到两个答案，他就不再信你了。04 沉默成员唤醒：轻触 → 给价值 → 给台阶醒着不说话的成员，分三层处理，不做无差别群发：A 层（近 7 天入圈、0 互动）：趁还有印象，轻推一把B 层（30 天未互动）：给一个只有你能给的价值，重新接上C 层（长期潜水的老成员）：给台阶 + 低门槛动作，不逼话术统一走三段式结构：轻触（不带目的）→ 给价值（具体到一件事）→ 给台阶（一个 1 分钟能做完的动作）。A 层的话可以这样说：> {昵称}，前几天看你进圈了，还没顾上聊。不催你，就问一句：你最近是不是在忙{行业相关的事}？我这有{一篇/一个模板}可能正好你用得上，要的话回我个「要」，我发你。C 层要给他台阶：> {昵称}，你是老成员了，一直没怎么说话，我猜你可能是「潜水看你需要的」——完全没问题。 > 就想请你帮个小忙：{一个超低门槛动作，比如下条帖帮我们投个票}，一句话的事。唤醒有一条红线：唤醒不是为了让他马上续费，是为了让他重新开口。 不许在唤醒话术里夹带卖课。开口之后再谈别的。续费关怀也是同一套逻辑：只提醒价值，不制造焦虑，不硬推销。但它现在不是你每天要干的事——它是一份先备好的框架。时间点排 T-15 / T-7 / T-3 / 到期当天 / 到期后 3 天，分层调语气——活跃的帮他看见自己的成长，一般的接上他断掉的那条线，沉默的先不推。不承诺「续费送 XX」这类没拍板的权益，也不制造「马上涨价、名额没了」的紧迫感。什么时候启动？先查有没有对象。 我那个星球在圈成员的到期时间集中在 2027 年 8 月（最早 2027-08-04），距 2026 年 9 月 14 日还有 11 个月——现在启动续费关怀是没有对象的。所以正确做法是：话术框架先写好存着，2027 年年中再启动，第一个真正的触发窗口在 2027 年 6 月到 7 月。（口径：成员记录的到期时间字段，2026-09-14 抓取。）顺带说清一件事：平台不暴露成员级的互动明细，所以「按活跃度给到期成员分层写话术」这件事目前做不到，只能按「到期时间 + 入圈批次」分层。我一开始还想着按活跃度分三层各写一套，查完接口才知道这条路走不通——能做和想做是两件事，先确认数据有没有
```

## 填法

把 `{花括号}` 换成真实情况。填不出来的照写「没想清楚」—— 原书规矩：让 AI 标「待你确认」，**不许替你编**。

## 本环硬门槛

切法三选一说明理由：A 按动作 / B 按人群 / C 按反常识。**三条各自独立成立**，不许「上篇/中篇/下篇」「承接上文」。
