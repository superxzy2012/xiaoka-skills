# Prompt J · 帖子包四件套

**来源**：《WorkBuddy + 知识星球：一个人自动化的做课赚钱手册》第 08 章（袁六伟，2026-09-14）
**模式**：Agent
**产出文件**：我的-帖子包2个.md（每个含四件套）

## 原文 Prompt（完整照抄，未改写）

```text
【角色】知识星球内容运营，负责把一件事写成一条能被接话的帖子。

【输入】
- 栏目：{专栏连载 / 实战拆解 / 答疑合集 / 工具模板 / 话题互动 / 活动帖}
- 选题：{主题}
- 真实素材：{真实操作路径 / 真实提问原文 / 真实数据及其来源，没有就写「无」}
- 阵地：知识星球「Workbuddy一人公司营」

【任务】按四件套交付，缺一不可：
1. 正文：可直接粘贴的纯文本，600–1200 字（互动帖可更短）。结构 = 第一句痛点或反差（≤30 字）→ 中间 3–5 段 → 落地：此刻能做的第一步 → 动作指令。
2. 标题 6 候选：至少覆盖 4 个不同公式，选 1 主 2 备，逐个标注公式名。
3. 配图清单：每张图写「放在哪一段后面、证明什么、真实截图还是示意」。
4. 话题标签 + 引导语。

【自检后再输出】
① 红线扫描：有没有「AI」「自动化」、极限词、收益承诺
② 有没有一个能被带走的东西
③ 有没有 AI 腔（禁「首先其次最后」、禁空泛方法论）
④ 正文里有没有 Markdown 语法残留（`**`、表格竖线）——**这条只针对发帖子的场景；发长文章时表格可以保留**

【最后一行】写它的依据是什么（哪次真实动作 / 哪条真实提问）
```

## 填法

把 `{花括号}` 换成真实情况。填不出来的照写「没想清楚」—— 原书规矩：让 AI 标「待你确认」，**不许替你编**。

## 本环硬门槛

每帖必须能接话；四件套 = 标题 / 正文 / 配图清单 / **最后一行写依据**（哪次真实动作或哪条真实提问）。
