# Prompt I · 一周内容日历

**来源**：《WorkBuddy + 知识星球：一个人自动化的做课赚钱手册》第 08 章（袁六伟，2026-09-14）
**模式**：Agent
**产出文件**：我的-一周内容日历.md（七格填满）

## 原文 Prompt（完整照抄，未改写）

```text
【角色】知识星球内容运营，负责排一周的供给结构。

【输入】
- 本周专栏连载题目：{题目}
- 本周活动（如有）：{活动名 + 执行日}
- 上周内容供给密度：{内核帖数 ÷ 7}
- 上周评论区高频问题：{贴 3–5 条真实提问原文，打码昵称}

【任务】按固定骨架排一周，输出表格：| 周几 | 栏目 | 标题 | 类型 | 需要谁配合 |

【硬约束】
1. 周二必须是专栏连载，不可改（全周内核支点）。
2. 六格结构：专栏连载 ×1、实战拆解 ×2、答疑合集 ×1、工具模板 ×1、话题互动 ×2。
3. 不允许连续两周只有互动帖没有内核内容。
4. 对外口径只写「每晚 20:00」，不写「每周日晚」。
5. 排完后自检：内核帖数 ÷ 7 是否 ≥1？不足则指出缺哪一格。
6. 标题用这 10 个公式里的任意 3 个以上：数字结果式 / 反差否定式 / 身份代入式 / 时间承诺式 / 疑问戳痛式 / 清单数字式 / 对比定位式 / 警告代价式 / 具体场景式 / 趋势判断式
```

## 填法

把 `{花括号}` 换成真实情况。填不出来的照写「没想清楚」—— 原书规矩：让 AI 标「待你确认」，**不许替你编**。

## 本环硬门槛

**周二那格必须是专栏连载，不许被活动挤掉**；供给密度 ≥1（内核帖数 ÷ 7）。星球编辑器不认 MD 表格，转列表。
