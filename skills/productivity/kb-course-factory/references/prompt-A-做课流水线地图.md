# Prompt A · 做课流水线地图

**来源**：《WorkBuddy + 知识星球：一个人自动化的做课赚钱手册》第 01 章（袁六伟，2026-09-14）
**模式**：Plan（先出方案，不用 Agent 模式）
**产出文件**：我的-流水线地图.md（9 环地图 + 2 个卡点 + 2 个今日动作）

## 原文 Prompt（完整照抄，未改写）

```text
【角色】你是我的做课流水线教练，服务对象是一个人做课、一个人卖课、一个人管星球的独立创作者。

【我的现状】
- 我是做什么的：{一行，比如「做了 6 年企业内训，现在一个人接商单」}
- 我手上已有的东西：{比如「12 篇公众号旧文 / 一套用了 3 年的课件 / 一场直播回放」}
- 我打算做的课：{一句话，还没想清楚就写「没想清楚」}
- 我上一次做课卡在哪：{凭印象写，写不出来就写「没做过」}

【任务】
1. 按「定位 → 标题 → 详情页 → 大纲与逐字稿 → 发售 → 活动 → 内容 → 上星球 → 复盘」9 环，生成一张我的流水线地图。每一环写清三件事：这一环的输入是什么、输出是什么、判断它做完没做完的标准是什么。
2. 结合我的现状，指出我大概率会卡在哪两环，并说明理由。
3. 给我这两环各一个「今天就能做完」的动作，动作要小到 30 分钟内能完成。

【输出格式】一张 Markdown 表格（列：环节 | 输入 | 输出 | 完工标准 | 我是否已具备）+ 卡点结论 + 两个今日动作。

【禁止】
- 不许给我方法论清单，每一环都必须和我的现状挂钩
- 我填「没想清楚」的地方，不许替我编，直接标「待你确认」
- 不许承诺任何收益、涨粉、阅读量操作步骤（照着点，别跳）：打开 WorkBuddy，模式切成 Plan（先出方案）。做规划这件事，别用 Agent 模式——Agent 会直接动手改你的文件，方案还没看完它就写上了。把上面那段整段粘进输入框，把 4 个 {花括号} 换成你自己的真实信息。填不出来的那一格就照实写「没想清楚」，别硬凑。等它出表。出完先别急着采信，对着第 1 节那张自测表交叉看一眼，两边的结论对不对得上。对不上，就把它指出的卡点怼回去问一句：「我卡在这里的判断依据是什么？」确认之后，把结果存成 我的-流水线地图.md，放在你自己的工作目录里。以后每做一门新课，回来改一次这张图。我踩过的坑我第一版是反着做的。我先花了两个多星期，把能装的工具、能配的连接器全装了一遍，装完觉得自己准备好了，坐下来写大纲，写到一半发现不知道写给谁，停下来重写。那两周是纯浪费。不是工具没用，是我把「准备」当成了「进展」。工具装得再齐，也替不了你回答「谁掏钱」这一个问题。后来我给自己定了一条死规矩：任何一门新课，定位没写成一句话之前，不许打开大纲文档。今天就动手：把你手上那门课（哪怕只是个念头）的代进去，跑一遍上面的 Prompt，圈出你的两个卡点，写进 我的-流水线地图.md。今天只做这一步，不写课。本章你该交出的东西：我的-流水线地图.md（含 9 环地图 + 2 个卡点 + 2 个今日动作）自检三问：1）地图里有没有写上你自己的真实现状，而不是通用模板？2）你有没有带走一个能存下来的文件？3）今天那一个动作，是不是 30 分钟内能做完？下一章要用到：本章圈出的「第 1 环卡点」——它就是第 02 章的输入。第 02 章 · 定位：先想清楚谁会掏钱先说一个我常拿来举例的场景（示意，不是某个具体学员）：课件做得比我还认真，一章一章改了好几个月，上线那天去星球发帖，一个下午过去，没什么水花。多数人的第一反应是——标题不够吸引人。我的答案是：不是。你先把「把课卖给谁」这件事说清楚，说清了你就会发现，你那张详情页打不到任何人身上。定位这件事反直觉的地方在这儿：它不问你擅长什么，它问谁会在什么场景下付钱。01 「我想讲什么」和「谁会掏钱」是两件事我做课做到现在，关键的一个认知转变是这个：我擅长什么，只是我的原料。它会决定我能不能做出来，但它不决定有没有人买。我自己有 10 多年咨询经验，服务过 100+ 商单客户，覆盖近 20 个行业，得到和华为都请我去讲过。这些是我的原料。但如果我按着「我懂什么」去排课，我会排出一门「我的方法论大全」，然后没人买。因为买课的人不关心你懂多少，他关心的是：我现在手上这件事，你能不能帮我解决掉。我 8 月那批课为什么能一次交出去 1400+ 份？不是我讲得比别人好，是我把定位一句话说清了：给一个人做生意的独立创作者，让他能把自己的经验做成能卖的产品。这一句话里，「谁」和「什么场景」都在里面。有人会反驳我：定位写窄了，是不是就把人筛掉了，买的人更少？恰恰相反。定位写窄，是把「可能买的人」变成「确定要买的人」。 你写宽了，写的是「所有人都能学」，那在读者眼里就是「跟我没关系」。6000+ 学员里，成交得干脆的那批人，都是因为在标题里一眼认出「这说的就是我」。定位不是缩小市场，是把泛泛的注意力，换成具体的订单。02 定位三问：谁、什么场景、他已经在为什么花钱定位不用憋，它就是三个问题的答案。三个都答得具体，定位就成了。第一问：他是谁？ 不能写「想做副业的人」，要写到一个具体身份上，比如「做了 5 年企业内训，想把自己的课搬上线」。身份越具体，后面每一环越好写。第二问：他卡在什么场景里？ 不是「他想学做课」，是「他课件做完了，发出去没人点，正在怀疑自己」。场景要带画面、带情绪。我写定位时一定会写这一句：「他在什么时候会想起来要找这门课？」第三问：他现在已经为什么花钱了？ 这一问容易被跳过，但它是定价的全部依据。他去买谁的东西、花了多少钱、为什么觉得值。他已经在花钱的那个地方，就是你的锚。我自己的锚是这样的：他愿意花 1999 元进 WorkBuddy 百倍增长营，愿意为一次咨询付费。那我要做的不是跟这个价位打价格战，是按更高一档的标准交付，按更低一档的价格成交。这就是我一直在用的三层锚定：交付层对齐更高一档产品的密度（目录、作业、模板、点评、证书都给齐），锚定层给他一个客观参照物（不贬低同行），成交层定一个闭眼能买的价。低价档负责进人，高价档负责赚钱。我不指望 99 元档赚钱，我要的是把人拉进来、把信任建起来。03 定完位，顺手把定价带划出来定位写完，下一步不是写标题，是把定价带划出来。三段就够：入门档：让人闭眼能买，负责把人拉进来（我的一人公司实战课走的就是这档）主力档：陪跑营这档，负责赚钱（我的 WorkBuddy 百倍增长营 1999 元档）商单档：按项目交付，负责客单价（我额外承接的十几个商单客户）三条定价纪律，写在这里给自己看：第一，价格必须挂一个理由。名额、时限、或者参照物。没有理由的价格，用户会一直等。第二，不搞「原价 XX 现价 XX」的假打折。我只做真涨价。我那个星球的定价规则原样写在简介里：「原价 1999 元，限时 50 元，每满 100 人涨价到 99、199、299」——这是阶梯涨价，不是一次性改价，每一档都比上一档高，规则提前摆在所有人面前，谁早进来谁便宜。（来源：星球简介原文。）假打折被识破一次，后面全是信任成本；阶梯涨价给的是一个理由，不是一套套路。第三，涨价要涨得有尊严。涨的是正式价，不是惩罚迟到的人。话术重心放在「早鸟是给先到者的」，不放在「你错过了」
```

## 填法

把 `{花括号}` 换成真实情况。填不出来的照写「没想清楚」—— 原书规矩：让 AI 标「待你确认」，**不许替你编**。

## 本环硬门槛

出表后拿第 1 节自测表交叉看一眼；对不上就问它「我卡在这里的判断依据是什么」。**定位没写成一句话之前，不许打开大纲文档。**
