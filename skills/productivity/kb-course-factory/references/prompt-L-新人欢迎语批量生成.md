# Prompt L · 新人欢迎语批量生成

**来源**：《WorkBuddy + 知识星球：一个人自动化的做课赚钱手册》第 09 章（袁六伟，2026-09-14）
**模式**：Agent
**产出文件**：我的-新人欢迎语.md

## 原文 Prompt（完整照抄，未改写）

```text
你是社群运营。按下面的新人列表，为每个人生成 3 条内容：
1) 一条欢迎语（60 字内，必须包含对方昵称 + 一句和他行业/身份相关的具体话 + 一句零基础安抚（如「不会用也没关系」），禁止「欢迎加入」这类群发感开场）
2) 一条「入圈三件套 + 第 0 步 + 3 步行动清单」私信（第 0 步 = 确认已进群；步骤清晰，带填空模板）
3) 一条「未开口时的 24 小时轻触」私信（必须是一个具体选择题，不能问「在吗」）

要求：全程口语、像一个真人在说话；不承诺任何结果。**这三条都是学员要原样发出去的对外话术，不出现「AI」「自动化」两个词。**
输出格式：按人分组，用 Markdown 小标题，每条前面标【欢迎语】【三件套】【24h 轻触】。

新人列表：
昵称 | 入圈时间 | 来源渠道 | 行业/身份 | 入群状态 | 备注
{逐行粘贴}
```

## 填法

把 `{花括号}` 换成真实情况。填不出来的照写「没想清楚」—— 原书规矩：让 AI 标「待你确认」，**不许替你编**。

## 本环硬门槛

输入**只放昵称和行业，不放手机号/微信号**；三段式 = 轻触（不带目的）→ 给价值（具体到一件事）→ 给台阶（1 分钟能做完的动作）。
