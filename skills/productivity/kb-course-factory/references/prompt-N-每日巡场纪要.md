# Prompt N · 每日巡场纪要（星球接入 + 上架十步）

**来源**：《WorkBuddy + 知识星球：一个人自动化的做课赚钱手册》第 10 章（袁六伟，2026-09-14）
**模式**：Agent
**产出文件**：我的-星球接入操作单.md

## 原文 Prompt（完整照抄，未改写）

```text
你是社群运营。下面是我今天的星球巡场原始素材。请生成一份「今日待办清单」，要求：
1) 分 6 类归档：① 风险内容 ② 未回评论 ③ 未答提问 ④ 新成员未欢迎 ⑤ 冷场帖 ⑥ 精华候选
2) 每条给：优先级（高/中/低）｜对象（脱敏）｜建议动作（一句话）
3) 风险内容单独列，标级别（广告 / 抱怨误解 / 疑似纠纷 / 违规）和处理口径，严重的标「需负责人处理」
4) 最后给「今日必做 3 件事」，按优先级排序

输出格式：Markdown 表格 + 一个「今日必做」列表。
红线：脱敏昵称；不下无法验证的结论（拿不准写「待确认」）。

素材：
{粘贴当日新帖正文、评论原文、提问原文}操作步骤：新人名单从星球后台导出来，整理成「昵称 | 入圈时间 | 来源渠道 | 行业/身份 | 入群状态 | 备注」五行一行的格式，喂给 Prompt L。注意：输入里不要放手机号、微信号这类信息，只放昵称和行业。生成的欢迎语，逐条核对昵称和行业有没有说错，然后再发。批量生成的东西里，昵称串位是常见的错，发错一次比不发更伤。每天巡完一圈，把新帖正文、评论原文、提问原文粘进 Prompt N，出「今日待办」。这份纪要照着做完就行，不用再自己梳理一遍。答疑用 Prompt M 出分级表。L1 直接回，L2 转抽检，L3 只回一句「已转给袁总」。发布纪律：所有对外要发出去的话，人看过再发。 机器负责把量铺开，人负责把人味补上。涉及加精、收录、批量发帖这类「写入动作」，先出一份候选清单，过一遍再执行。我踩过的坑我用批量生成的欢迎语，犯过一次串位的错。那批新人里有两个人昵称只差一个字，我批量发的时候看漏了，把「做外贸的」那句欢迎语发给了做本地餐饮的那位。他回了我一句：「我不是做外贸的。」那一下很尴尬。后来我给自己加了两道动作：一是批量生成的文案，昵称和行业两列一定要单独核对一遍；二是欢迎语里绝不写我不能确定的身份信息，不确定就只写昵称，把「你是做 XX 的」留到他自己开口之后再说。第二个坑是唤醒话术夹带卖课。我早期给沉默成员发的唤醒私信，结尾加了一句「顺便说一句，我最近新出了一门课」。发出去三条，收到一条回复：「又卖东西。」唤醒是重新建立联系，不是第二次推销。他愿意回你一个字，这一轮的目的就达到了，别贪。今天就动手：把最近入圈但还没说话的 5 个人列出来，先确认这 5 个人都进群了没有（没进的今天先解决入群），再用 Prompt L 生成欢迎语和 24h 轻触，核对完昵称再发。今天只做这 5 个人，别一次群发全部。本章你该交出的东西：我的-新人欢迎语.md + 我的-答疑分级表.md + 一份「今日待办」巡场纪要自检三问：1）新入圈的有没有先确认进群，没进群的有没有当天解决？2）L3 类问题有没有一个字都没自己答？3）唤醒话术里有没有夹带卖课？下一章要用到：本章的巡场和答疑产出的问题清单——第 10 章要把这些内容归档进星球，并且以后不用每次手动来一遍。第 10 章 · 把课搬进星球：连接、发布、专栏、改稿课做完了，帖写好了，然后我卡在最后一步。不是不会写，是我不想每次都手动来一遍：打开星球，新建帖，复制正文，一张一张传图，调格式，发出去，再回来改错字。一讲内容发到星球，来回二十分钟。一周四讲就是八十多分钟，全花在搬运上。这一章讲的就是把这二十分钟省掉。配一次，之后说一句话就能管星球。先把阵地写清楚：这门教程的发布阵地是星球「Workbuddy一人公司营」，group_id = 88884585518442。别搞混——我名下不止一个星球，另一个是 AI 指令俱乐部（group_id = 48884852481548），两个的定位不一样。发错星球这事真发生过，下面讲
```

## 填法

把 `{花括号}` 换成真实情况。填不出来的照写「没想清楚」—— 原书规矩：让 AI 标「待你确认」，**不许替你编**。

## 本环硬门槛

**发错星球真发生过**：核对 group_id（Workbuddy一人公司营 = 88884585518442，AI创收私研社 = 48884852481548）。文章 ≠ 卡片帖 ≠ 专栏；改稿用 **PUT 不用 PATCH**；专栏归属**全量替换**。
