# 知识星球发帖（编辑器约束 + API 要点）

## 发布前必做

Markdown 表格 → **转成列表**（一行一条，用「·」开头）。星球编辑器不认 MD 表格，贴进去会显示成一坨乱码。

## 三个实体别搞混

| 实体 | 是什么 | 关键点 |
|---|---|---|
| **文章** | `articles.zsxq.com/id_xxx.html`，承载富文本正文 | 发文章**不会**自动进信息流 |
| **卡片帖** | 信息流入口 | 文章必须**另发一张卡片帖**挂载 |
| **专栏** | 目录 / 集合 | 归属设置是**全量替换** |

## API 要点

- 文章字段：`group_id` / `title` / `content` / `original_content`（**不用 `topic_id`**）
- 卡片帖正文必须按特定 `req_data` 结构包装并携带 `article_id`；直接传简单标题/正文 → **`code 1004`**
- 修改文章用 **PUT**，**不要用 PATCH**
- 专栏归属：**读现有 → 合并去重 → 整表回设**。传空数组会移出全部。
- 频率限制：发文章间隔 ≥25–30 秒，PUT ≥28 秒，专栏归属 ~2 秒
- 定时任务：每星球最多约 10 个，且必须落在**未来 14 天内**

## 已知未验证

- 专栏内主题的排序规则（作者未验证）
- **CDN 图片签名会过期** —— 首章发出约两周后回读检查一次

## 数据纪律

平台 API **不暴露成员级互动明细**。活跃率、互动转化率、新人 7 日留存都拿不到，必须后台导出。
做自动化看板前先确认数据源，**不能伪造这些指标**。
