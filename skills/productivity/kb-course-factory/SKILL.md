# 知识付费做课工厂

单人做课 / 卖课 / 管知识星球的执行流水线。全部 Prompt 原文照抄自袁六伟《WorkBuddy + 知识星球：一个人自动化的做课赚钱手册》（49,457 字 / 11 章）。

**核心心法**：做课死在哪不是内容，是顺序。必须倒过来 —— 先定谁掏钱 → 再出标题 → 再写详情页 → 最后才做大纲。

## 触发条件

用户要：做课 / 写网课 / 出课程标题 / 写详情页 / 做大纲 / 逐字稿 / 排发售节奏 / 写发售话术 / 排内容日历 / 写星球帖子 / 分级答疑 / 发布到知识星球 / 做复盘表 / 90 天计划。

## 三条不可破的红线

1. **内容红线**：对外文案不出现「AI」「自动化」。改写为「WorkBuddy」「把流程跑成一条流水线」「一键生成」。B 端写「商单客户」。
2. **价格红线**：教程正文可写真实数字（须带时间/口径/来源，不许写成收益）；对外详情页/海报/朋友圈/星球帖/私聊一律占位 `¥××`，不许出现价格推导。
3. **极限词红线**：禁「最 / 第一 / 绝对 / 保证」；不承诺收益、涨粉、阅读量、接单数量。

## 关键阈值速查

- **标题**：20 个起步（作者实际出 26 个，最后用第 19 个）；6 维度加权满分 100（承诺清晰 25 / 正文兑现 25 / 人群指向 15 / 反差点开 15 / 红线安全 10 / 换字对比 10）；主标题 ≥85、备选 ≥75；红线安全度 = 0 直接淘汰；6 个候选须 ≥4 个不同公式
- **详情页**：七段，每段 150–300 字；≥10 条质疑回应
- **讲次**：5–11 讲；逐字稿 1500–2500 字/讲
- **发售**：预热 7 + 开售 4 + 追单 4 + 收尾 3 = 18 天；追单期 ≥2 次中途催场
- **活动**：主指标只能一个（新增关注数）；参与路径 ≤3 步、每步 ≤1 分钟；≥2 次中途催场
- **内容**：供给密度 ≥1（内核帖数 ÷ 7）；周二专栏连载不许被活动挤掉
- **涨价**：一个周期只用一个变量（时间或人数）；只涨不返；不做假打折
- **星球 API**：发文章间隔 ≥25–30s，PUT ≥28s，专栏归属 ~2s；每星球 ≤10 个定时任务且须落未来 14 天内；卡片帖必须带 `article_id`，否则 `code 1004`；修改用 PUT 不用 PATCH；专栏归属**全量替换**，传空数组会移出全部

## 三条最贵的坑（原文原话）

- **标题党的代价**：「标题是承诺，正文是交付，这两个东西对不上，你赚到的是一次点击，赔掉的是一年的信任。」
- **AI 腔**：「录出来听了五分钟听不下去了 —— 那不是我在说话，那一个模板在说话。」土办法：**第一段里没有「我」这个字，整篇退回重写**。
- **别用 Agent 模式做规划**：它会直接动手改你的文件，方案还没看完它就写上了。规划用 Plan 模式，定位答疑用 Ask 模式。

## 输出纪律

- Prompt 里的 `{花括号}` 换成真实情况；填不出照写「没想清楚」，让 AI 标「待你确认」，**不许替用户编**。
- 原文标注「示意」的案例是方法示例，**不是真实学员业绩**，转述时必须保留这个标注。
- 星球发帖把 Markdown 表格转成列表（一行一条用「·」开头）—— 编辑器不认，贴进去是乱码。
- 数字类指标拿不到就写「无」，**不许估、不许编**。平台 API 不暴露成员级互动明细，活跃率 / 互动转化率 / 新人 7 日留存必须后台导出。
- 交付前跑该章的 `references/self-check-ch01.md` … `self-check-ch11.md` 三问（按章取对应文件）。
